# 橡胶斜切项目负责人审查与本轮决策

日期：2026-10-31，日本时间

性质：源码、方法、文档证据与局部核验审查；供用户及两个现有执行 agent 使用。

## 1. 本轮结论

目前应继续保留“本地完整体基线”和“远程断裂”两条工作线，但改变两者下一轮的验收重点：

1. 本地：先统一实验比较口径，补全能量审查，再用有明确适用窗口的共同参数校准解释多角度 Fz。不能把完成 2 mm 当作实验验证，也不能把一次拟合所得参数包装为唯一真实物性。
2. 远程：面级内聚和端点事件控制已经实现。下一轮围绕摩擦时间功与接触进入开展有停止条件的方法验证；先验证刀具进入给定裂缝，再恢复裂纹扩展、完整材料起裂和斜切。
3. 两者立即建立模型版本和证据交接；远程可先用明确标记的示例参数验证机制，不需要等待本地完美拟合。接收新材料前，必须核对模型与历史变量兼容性。

本轮没有证据支持“必须重写整个 Maxwell 本构”，也没有证据支持“换成某一种冲量算法必然解决进入”。已有数值不变量、回滚、接触身份与失败记录应保留；把新增工作集中到能改变下一步判断的少数检查。

## 3. 科研目标与模型边界

研究主线仍是：斜切几何改变变形和接触，进而影响受力、相对滑动与起裂。当前实际角度为 0°、33°、57°，加载速度为 0.2 mm/s。刀具实验室竖直行程 d 的初始表面投影为 d cosθ、d sinθ；后者不是实际界面滑移。Fz是实验室竖直力，不能直接当初始表面法向力。[R1、B1]

当前仅有 Fz 也足以评价 Fz 复现好坏。额外位移、滑移、接触或材料试验用于区分原因；缺少这些观测不应成为忽视明显 Fz 偏差的理由。力曲线匹配则不足以唯一确认材料和摩擦机制。

两条工作线不是相同几何中的一个断裂开关：

| 项目 | 本地完整体 | 远程当前断裂控制 |
|---|---|---|
| 试样 | 30×5 mm截面、20 mm面外宽度 | 同名义尺寸，0°镜像半域 |
| 刀位 | s=7 mm，偏心 | s=15 mm，居中 |
| 倾角 | 0/33/45/50/55/57° | 当前核心仅0° |
| 时间处理 | 完整体有限应变 Maxwell 加载 | 动力学、离散功与端点摩擦候选 |
| 裂纹 | 无 | 预设直裂路、面级连续内聚或旧FFM候选 |

因此无损伤回归必须先统一几何、边界、时间积分和材料，再讨论差异。[B1、F1、F3]

## 4. 结果审查

### 4.1 本地完整体：算得完，但多角度解释不足

最新交接报告六角度各完成 2 mm、201态并通过已有全路径审查；1206个保存态哈希复核是文件身份核验，不是本轮重新装配力学残量。[B1]

| 实测角度 | 0–2 mm RMSE | relative L2 | 0.5 mm仿真/实验Fz |
|---|---:|---:|---:|
| 0° | 3.8730 N | 19.11% | 11.3751 / 8.2700 N |
| 33° | 4.4184 N | 23.64% | 11.5414 / 7.6100 N |
| 57° | 0.5393 N | 2.92% | 9.0335 / 7.9700 N |

这些是所列试次、所列处理方式下的文档结果。0°和33°早段已经偏高，不能只归于晚段实验断裂。全程误差仍混有完整体模型适用范围问题，不能把晚段全部误差归给模量、摩擦或网格。

必须保留的限定：

- 参数历史上参考过57°切割力，57°不是独立留出验证。
- 45°、50°、55°没有对应授权实验，完成计算不等于实验验证。
- 0°约1 mm起裂估计来自a1，不能套给当前a2。
- 33°约1.2–1.3 mm仍是近似信息。
- 57°到2 mm未裂为工况级右删失；不是起裂恰在2 mm。
- 小应变制造解提示P1近不可压缩误差，但未证明实际切割偏高由锁定主导。
- 部分局部J很低，应检查空间位置、体积权重和网格响应；J>0只排除翻转，不能独立认证局部物理。[B1、B2]

### 4.2 远程：最新进展已超过指定快照，但基本刀具进入仍未完成

| 最新路线 | 已接受末行程/态数 | 当前裂面证据 | 资格 |
|---|---|---|---|
| C1，0.5 mm面级预裂，端点事件 | 0.468422401381 mm / 2275 | 完全失效面仍仅原始预裂；刀具接触均为原顶面 | 前缀审查通过；进入、完整事件、时间/网格验证未通过 |
| C2，完整材料，端点事件 | 0.517955765798 mm / 1777 | 有模型激活，无完全失效表面通道 | 同上 |
| 遗留FFM生产路径 | 最远1.210936593388 mm | 旧虚拟裂纹问题仍未完成 | 不作为本轮新路线突破 |

C1/C2最终按约2990 s内部预算停止；不能将超时当无根。之前分别有765/656次负端点摩擦功拒绝。最新文档已区分真实端点耗散和算法位移功，且没有把更平滑的短前缀升级为实际切割成功。[F1、F2第28节]

C1某保存态顶端已释放、内聚力为零，却由压向物理合力保持闭合。这否定了该现场“仍被完整面锁死”的解释；换接触时间方法后也不能预先保证当前实际C1必然进入。[F2]

## 5. 代码审查的优先发现

### P1-A：公开实验比较入口与当前零点约定不一致——已复现

当前约定为仅实验减首值，仿真不归零。run_material_candidate.py第64–89行仍使用原始实验力计算主要RMSE；其increment RMSE又同时扣除了仿真首值。plot_experiment_angles.py仍保留57°原0.51 N。[B2、B3]

合成数据中，原始实验[0.51,1.51] N、仿真[0.2,1.2] N：

- 当前主要RMSE为0.31 N；
- 同时扣双方首值的增量RMSE约0；
- 按当前约定应为0.20 N。

这能证明公开比较入口不一致，不能证明本地最新误差表错误；其统计工具可能尚未提交。

任务：保持原始读取不变，在共享适配层构造派生目标、记录offset和hash，统一拟合、图和汇总口径。

### P1-B：完整体全路径审查没有逐态认证全部能量/耗散字段——已复现

ipc_viscoelastic.py第176–184行比较材料度量与Fz；material_case.py第171–175行由保存耗散增量核对保存累计量。后者能发现累计不一致，但不能排除一套自洽却错误的增量。[B4、B5]

隔离控制流测试中，新鲜材料储能/耗散为1/0.1，保存记录改为999/888，原audit_state仍返回passed。这是审查覆盖测试，使用测试夹具供给力学返回值，没有声称实际FE产生了错误能量。

选定导出帧另有总储能重算，所以不应概括成“能量从未核验”。缺口是全路径分项和耗散的审查覆盖。[B6]

任务：从同一已接受父态与真实dt独立重算各分项，累计量从新鲜增量构造；增加自洽篡改反例。未覆盖字段显式标注资格。

### P0-F：最新主要数值阻塞是端点摩擦与位移功配对

端点摩擦使用 h v(n+1)=2Δu−h v(n)，位移运动学仍为中点。face_cut.py第237–248行分别计算：

D_f = g_f · h v(n+1)，W_alg = g_f · Δu，R_f = W_alg − D_f。

二者可异号。生产纯函数代数反例：h=1、v_old=1、Δu=.1得到v_end=−.8；耗散梯度g=−1时，D_f=.8>0而W_alg=−.1<0。这不是一个已求解FE现场，但证明报错不能自动解释为负物理耗散。[F3、F4]

任务：将位置、速度、动量、摩擦冲量、刀具功和材料更新作为一套离散关系验证。不能仅更换一个速度公式或取消负算法功检查。

### P1-F：激活见证和被回退试探证据不完整

激活前位置目前保留在内存，最终快照缺少逐次激活前的完整状态；独立审查装回face_events，不能重新认证每一次候选排序。可回退拒步仅记分类和标量，外层最终停止才保存一个failed_trial。大量早期负功现场已不可逐位重放。[F3第148–173行、F5第57–64/91–102/180–201行]

任务：保存逐事件见证；按失败签名保存首个、最严重和停止前代表试探，复用父态引用，避免无限增加输出。

### P1-F：机器资格字段需要更精确

当前initiation_predicted可仅因无预裂且出现released_nodes而为真；surface_connected也包含初始预裂。建议拆分模型激活、事件见证、已有裂长、新增连通长度和已验证物理起裂预测，防止上层把“模型触发”写成“预测通过”。文档目前谨慎，机器字段仍值得修正。[F5第133–149行]

## 6. 理论与方法裁决

### 6.1 本地允许共同参数校准，结论按证据命名

本轮用户明确说明本地正在拟合实验。该授权用于当前完整体工作，优先于旧交接中的禁止Fz选参文字。保留旧参考配置，新建校准研究配置并明确授权范围；无需再次询问用户。

允许拟合并不消除不可辨识性。先冻结数值形式、试次与窗口，选择小参数集，报告共享参数能否同时解释各角度。刀尖半径、宽度、深度零点和网格误差不能作为逐角度补偿项。

### 6.2 远程保留一个主候选，不把所有理论叠加

最新面级路线是连续外插型内聚模型；它不是旧强度—能量FFM的等价修复。两者保留为替代理论候选，不能在面级路线再次叠加未验证的虚拟能量门。[F2、F3]

黏弹断裂中，强度、断裂能、可用储能和历史的关系需要明确选择。Kamarei等给出一种准静态平衡储能框架，Dammaß等讨论不同驱动力；文献并不自动证明本项目冻结瞬时总储能加CZM的组合。当前优先解决接触与基本分离，而非凭Fz形状选理论。[T1、T2]

### 6.3 冲量法值得作为参考，但不能宣称已经解决

Acary与Collins-Craft的能量时间离散结论有线性体动力学、冲击律及参数条件；论文未完成当前有限变形Maxwell、内聚软化、大滑移的推广。Siconos可作独立子问题参考，不等于把整个项目迁入该软件就得到正确模型。[T3、T4]

新候选必须通过纯摩擦停滑、运动刚壁滑移/接触与真实质量的基准，同时检查速度、停止时间、冲量和功。只验证耗散非负仍可能漏掉伪反向。

同一接触不能同时承受IPC法向屏障力与新的硬接触法向冲量。若替换模型，保留碰撞候选、CCD/J安全，但定义新的互补条件、冲击假设与完整功账。旧IPC保存态含屏障储能，不能删除后拼接为连续生产路径；条件诊断与新初态路径分开。
