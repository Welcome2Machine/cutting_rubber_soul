局部表面基向量为 eₛ=(cosθ,−sinθ)、外法向 eₙ=(sinθ,cosθ)。竖直行程 d 的法向、切向投影大小为 d cosθ、d sinθ；这不是实际界面滑移。Fz 始终为实验室竖直反力，不以法向反力替代。

深度零为理想圆鼻相对未变形平面的名义首触。原生正间隙屏障可在几何首触前作用；计算包含分离初态至零深度的准备历史。实验首触、屏障激活与最低点相触不能混作一个事件。

## 本构和历史

平衡等容 neo-Hookean 支路与单支路有限应变等容 Maxwell 并联，体积响应不松弛。

| 参数 | 数值 |
|---|---:|
| G∞，长期剪切模量 | 0.14 MPa |
| Gv，非平衡支路剪切模量 | 1.24 MPa |
| G0=G∞+Gv | 1.38 MPa |
| q=G∞/G0 | 0.1014492754 |
| τ，松弛时间 | 1.7 s |
| K，体积模量 | 23.34333333333331 MPa |

平衡能 `W∞ = G∞/2 (Ī₁−3) + K/2 (J−1)²`，其中 `Ī₁=J^(−2/3)tr(FᵀF)`，二维 F 嵌入三维平面应变。非平衡支路采用乘法分解、对数主应变局部后向 Euler 更新；逆黏性度量保持对称正定且行列式为1，每个P1三角形保存一个材料点历史。

物理时间步 `Δt=Δd/0.2`。每次非线性迭代固定上一接受态的材料度量和位置，仅在物理步接受后提交新状态及耗散。PTC稳定化不增加真实时间。2023论文复现的 `paper2023` 流动律独立保留，不等同于本主线 `isochoric_maxwell`。

参数为探索选择，尚非当前样品独立标定值。K固定意味着小应变泊松响应随松弛变化，瞬时约0.471、长期约0.497；不能把单一配置ν当作全程常数。二次J体积能在J→0不发散，须报告局部压缩而不仅是平均J。

## 接触与求解流程

1. 原生 improved-max IPC，完整保留刀具接触、本体自接触、EV/VV及CCD；激活距离 `dhat=0.0025 mm`。
2. 正则库仑摩擦 `μ=0.35`，位移平滑尺度 `εu=1e−5 mm`。系数未经独立摩擦实验标定；不是黏性摩擦模型。
3. 以刷新接触几何、法向载荷和摩擦的真实非对称切线求PTC方向；稳定化度量只用于方向，不替代物理残差。
4. 名义增量0.01 mm。基线先用割线初猜，40次无进展则回滚并以仿射初猜重试同一增量；仿射尝试没有40次提前终止，每次尝试仍受500次上限和共同墙钟约束。两次尝试均失败才允许原自适应二分到0.000625 mm。已有三条完整基线均未发生物理二分。
5. 通过自由力残差≤1e−4 N、J>0、无穿透、刀具/底部边界和耗散检查后提交准确双历史，再独立重组整条路径审查。

原实现为SuperLU；可选性能实现为材料分批2048/PARDISO4/IPC2/BLAS1，默认物理保持。性能策略单列签名，禁止跨策略直接续算；加速路径由独立未分批原生对象核验。

可选直刃离散对照`--blade-spacing`只在原直线边上插点，圆鼻64面片和全部原顶点坐标不变，橡胶网格不变；近端刀身细分后向远端渐粗。原刀尖/圆鼻编号保留，碰撞边显式连接新增点。该选项改变接触积分权重和碰撞拓扑，属于待验证的离散选择，不能从原离散的接受场直接续算；默认仍使用原分段。运行报告单列实际刀具节点数和间距，需独立初态路径与分段收敛检查。

## 输出和适用边界

输出包括Fz、当前位移/应力、J与平衡误差、材料耗散、[刀尖接触参考坐标及整刃支撑区间](tip_contact.md)。`Fz=N cosθ+T sinθ`是坐标分解，不是改变摩擦参数的因果敏感性。参考材料位置迁移也不等于累计滑程。

已知限制：有限屏障间隙下共同刚体转动可产生表观摩擦功；受压相邻表面节点可能产生额外排斥；固定εu对应的平滑速度εu/Δt随物理步长改变。直接删除相邻VV会破坏原组合连续性，不能当修复。接触力平衡和材料切线测试通过不消除这些限制。

实验全宽贴合不证明压力沿宽均匀或平面应变成立。1–3 mm时单侧面外外鼓不到约1 mm只作定性约束，不施加硬截断。当前模型不描述裂面、裂后力或恢复；完整体2 mm后段仅作计算对照。有效历史见[研究历史](research_history.md)，外部依据见[统一文献导读](../references/README.md)。
