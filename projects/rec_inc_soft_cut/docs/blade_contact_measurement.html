刀尖附近的材料运动、切开线索和表面地址

输入为完整视频中固定材料 ID 的保存轨迹、逐时刻图像支持状态、刀具语义区域、图像登记的刀尖和初始斜面。保留去阴影图像、全部采样时刻和材料 ID，不重算本轮光流，不重训网络。观测与预测分别处理。

1. 不让材料点被刀具吸附

在匹配候选中先排除刀具不透明内部，再从剩余候选中选择。连续观测之间的短路径不能穿过前后两帧共同的刀具内部；不对跨遮挡间隔的两端画一条直线来判定穿刀，材料可能绕过有限长度的刀尖。刀具边界约 2 px 单独视为边界不确定带。

被遮挡的材料保留原 ID 与潜在预测，不把坐标推到刀边，不将预测当成摩擦滑移。当前视频中全部材料图层在刀具掩膜内被遮挡。新测量只使用位于材料像素、未在刀具区域且有图像支持的观测；退出刀具后的恢复仍需纹理支持。显示隐藏不表示隐藏轨迹已被纠正或真实身份已经确认。

2. 刀具与材料怎样相对运动

vrel,i(t) = d xi/dt − d b/dt

先对每个固定 ID 的连续支持轨迹作局部时间拟合，再减去刀尖平移速度。使用物理采集时间；播放 12 fps 不参与速度计算。拟合半窗为 0.075 s，缺失点、刀尖登记缺失或无效运动边不跨越拟合，端点不外推。当前没有独立刀具转角测量，因此只是平移补偿，不声称已补偿刀具转动。

在刀尖 60 px 邻域，按当前刀具左右和初始表层 0–12 px、次表层 12–48 px 分四组，输出相对 x/y、刀具轴向、外向以及初始斜面切向分量的中位数、四分位数和参与点数。邻域成员可随材料流动改变，但速度先按固定 ID 求出；相邻成员重叠率同时保存，防止把换组选点误当成加速度。

刀面外 0–4 px、距刀尖 90 px 内的支持点另输出沿局部刀面切线的相对速度。刀面切线来自最近刀具边界像素，是几何近似；像素阶梯、分割误差、油膜和二维投影都会影响它。这个子集称为接触候选，几何接近不是独立机械接触证据。图中使用统一比例的趋势压缩便于看方向，完整物理数值保存在 NPZ/CSV。

3. 材料点怎样提示切开

qk(t) = √mean(i,j)∈k[ ln(lij(t)/lij(0))² ]

固定材料块由初始相邻的 6–10 个 ID 组成，不按后续运动或存活情况换成员。指标 q 是成对点距相对初始状态的变化程度，对整体平移和刚体转动不敏感。它不是应变能。

仅在块全部成员有支持、位于刀具同侧近区、刀具继续下压且块已经变形时，查找 q 明显下降并持续至少 0.05 s 的区间。阈值取接触前波动 MAD 的 5 倍与最小下降速率的较大者；至少两个不共享材料 ID 的块同时恢复，另列为多块恢复候选。候选包含起点与确认时刻；时间拟合含未来样本，不能当作瞬时物理起裂界限。

这些量用于定位需要检查的深度，不把左右运动差、回弹或 shape change 自动判为裂纹。滑移、接触切换、黏弹性、出平面运动及光学误差也可能造成恢复。需结合原视频新表面/裂口的可见证据，或力数据，才能加强切开判断。某些弹性体可从压入平滑过渡到切开，没有清晰突变；因此候选缺失也不等于没有切开。Moreno-Mateos 与 Steinmann，2026，实验与模型。

4. 每时刻刀尖接触的是原先哪一点

x = χ(X,t)，  Xc(t) ≈ χ−1(b(t),t)

当前图的接触环始终画在登记的刀尖。使用初始材料标签构建两种局部映射：其一以同一初始表面站点内的法向点列，重建弯曲的原始表面；其二以相邻的固定表层/次表层材料块拟合局部形变，再把刀尖逆映射回初始构型。映射不能跨刀具、拼接不相容的材料分支，不能向无纹理区无限外推。

只有逆映射靠近初始自由表面，并有相邻站点、局部残差与留出检验支持时，才输出初始弧长地址 sc。直接使用当前表层图像支持的结果标绿色，依靠相邻内层块/法向点列推断的标粉色。两者都是算法支持程度，不是真值证明。对刀尖位置和局部邻域扰动得到的包络是敏感性范围，不是统计置信区间。

高残差、原始内部或表面外的逆映射点保留为独立 raw 诊断，未知区间不补成平滑滑移曲线。若切开后接触的是新裂面，Xc 可以位于初始材料内部，它没有原始自由表面地址；不能强行投到旧斜面。原始图灰菱形仅显示条件逆映射，不连接到当前刀尖；位于表面外的诊断也不是已找到实际材料点。

χ(sc(t),t)=b(t) ⇒ vrel,tan = −λs d sc/dt

在确有持续接触、同一表面分支且二维映射有效时，初始地址迁移率与材料滑动速度通过局部表面伸长相联系。换地址表示“换成哪块材料”，并不等于这块材料自身的位移。程序另外把相邻时刻的同一个中间材料地址分别映射到当前构型，减去刀具移动并投影到当前表面切线，得到材料相对刀具的切向运动；只在相邻推断共享材料 ID、分支未变且未中断时计算，不跨空缺累计。

5. 标定、文件与限制

长度比例使用约 3 mm 的接触至回退竖直刀具行程除以图像对应像素行程。已知名义刀宽为 0.245 mm，但当前几何文件的 shaft_width 位于尖端收窄区域，不能拿它当作完整刀宽标尺。压入深度是相对接触时刻的竖直刀尖位移；退刀时下降，登记缺失时为空。当前不是精确标定实验，微米数继承约 3 mm 输入的不确定性。

文件用途
measurements.csv每时刻深度、物理时间、阶段、四组相对速度、接触候选切向趋势、表面地址/敏感性区间/状态/原因；source_frame 仅供溯源，视频横轴为深度
motion_measurements.npz / motion_summary.json逐点运动、每组统计、固定块成员和恢复区间；physical_fracture_onset 为空，避免自动冒充物理起裂点
surface_address.npz原始地址、当前刀尖、原始图标记、raw 内部逆映射、表面转角、地址迁移率和同地址相对切向运动
measurement_support.npz本轮测量可用标记；原始 tracks.npz 没有改动
blade_contact_geometry.npz刀具内部/边界/图像范围、几何接触候选、最近刀面方向
measurement_summary.json / complete.json支持覆盖率、未知原因、输入与方法哈希；后者含视频编码及最终帧验证信息

这套方法给出可复核的运动量与切开线索。相邻点共同漂移、油膜折射和出平面运动可能同时骗过跟踪与局部拟合，不能仅凭“点没丢、线很平滑”宣称实际材料身份准确。建议优先检查接触地址变化与局部相对运动是否一致，再结合原视频核查恢复候选。
