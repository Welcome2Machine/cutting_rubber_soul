# 刀尖邻域材料跟踪：方法选择、依据与验收

日期：2026-10-25。本文解释本轮四个模块为什么这样选择、实现到哪一层，以及什么证据能否定这些选择。总体部署计划见 [优化方案](material_tracking_optimization_plan.md)，论文阅读入口见 [reference/READING_GUIDE.md](../reference/READING_GUIDE.md)。真实数据效果、运行配置、模型版本和失败数量以本轮正式 report 为准；本文不预填成功率。

本文保留首次四模块部署的设计与结果；此后的边界准入、初始根关键帧连接、累计风险修正及五组连续前缀验证，见[近表面身份优化](surface_identity_optimization.md)。

目标仍是固定材料身份的运动及原始表面接触地址。**采用高水平公开方法，不等于本实验已经获得高可信测量。** 当前视频含刀具遮挡、液体、强压缩和可能的离面运动，这些条件没有被下述论文联合验证。

## 1. 先区分测量对象与证据

初始表面记为 `Γ₀(s)`，材料映射为 `φₜ`，刀尖为 `b(t)`。只有在原始表面仍然存在且接触关系可辨认时，才可求接触地址集合：

$$


$$

\mathcal S(t)=\{s:\|\phi_t(\Gamma_0(s))-b(t)\|\leq\varepsilon_b\},\qquad
\Delta s_0(t)=\alpha[s_*(t)-s_0].
$

`𝒮(t)` 是几何候选集合，不是自动成立的物理接触证据。多个候选、遮挡或压缩到无法区分身份时应保留歧义。深层点只能约束映射，不能直接法向投影成表面滑移；起裂生成的新表面也不能强行重新编号成原表面。

输出需分别保留图像匹配支持、网络预测、本构条件推断、不可用/歧义状态。前后向一致、模型平衡或曲线平滑各自只验证一个条件，都不能单独将预测提升为真实材料观测。

## 3. A：接触与刀尖的交叉复核

刀具几何保留三个结果：既有配准刀尖、与刀杆连通的语义刀尖、原图亮刀杆的几何端点。后两者分别计算，但共享视频像素，不能当作统计独立的测量。原图亮度端点可能因阴影或尖端变暗而截短；语义掩膜也可能切掉尖端。

对两种可用端点计算到材料语义边界的有符号距离。连续接近帧与此前明确分离帧给出候选时间区间；没有观察到分离的一侧标为左删失。边界上的灰度梯度只作掩膜边缘对比诊断，并不是第三个独立轮廓真值。

材料响应使用初始表面附近的固定 ID 群，减去远场固定材料群的平移；同一审计窗口采用共同受支持集合，避免丢点或换邻居本身造成中位数跳变。响应模型使用源帧对应的实际时间。该集合选择使用整个短审计窗口，是离线审核，不宣称每帧在线无未来信息。

材料响应候选与几何候选区间重叠时，输出跨证据候选，仍保留 `contact_observed=False`。不重写旧刀尖、标定和深度；不能把接近材料边缘的刀尖自动吸附到边缘。像素阈值控制审核灵敏度，不是物理精度，亦不限制滑移总量。[iDICs 官方指南](https://idics.org/guide/)

## 4. B：固定 ID 双参考与单侧有效像素

同一材料 ID 分别匹配初始参考和近期参考。近期参考帮助处理大外观变化，初始参考检查累计漂移；近期参考本身必须有可追溯支持。两条路径一致只是必要检查之一，油膜纹理也可能在两条路径中一致。初始参考失败时，不能借近期匹配把“材料身份恢复”写成确定事实。

匹配的基本形式为：

\[
W(\xi)=q+A\xi,\qquad
E_{\rm img}=\sum_{\xi\in\Omega_{\rm valid}}
\rho\!\left[I_t(W(\xi))-gI_r(p+\xi)-c\right].
\]

保留局部平移、旋转、拉伸、剪切和亮度增益/偏置；有效集合由两帧材料支持、刀体排除、像素采样路径及插值模板决定。归一化卷积只在有效材料内计算：`Ī = Gσ*(mI)/(Gσ*m)`，避免刀具亮度进入模糊和归一化统计。有效像素不足就保留失败状态，不能把裁剪边缘当纹理。

前向匹配后，从当前图重新拟合回参考图，检查 `e_cyc = ‖p_back − p‖`；不是直接使用前向矩阵的逆就宣布通过。多个初值/邻域得到相似得分但不同位置时保留歧义，不按“靠刀尖最近”决定身份。双参考比较位于调用层，单次验证核只处理一个明确参考。

文献界限需要特别说明：SSDIC 原文让分割线两侧各有独立形变参数；作者还报告了其问题中单纯裁掉另一侧可能诱使算法缩小保留区域以降低残差。当前采用外部掩膜，不能据该论文声称“单侧裁剪一定正确”。因此必须同时保存有效像素数量/比例、位移误差和匹配残差，进行掩膜扰动与边界亮度反事实测试。仅残差下降或受支持点平均误差下降不够。[Poissant–Barthelat，2010，作者全文](https://barthelat-lab.mcgill.ca/files/papers/EM2010.pdf) · [DOI](https://doi.org/10.1007/s11340-009-9220-2)

## 5. C：两个现代预训练候选的分工

**CoTracker3（ICCV 2025）**作为较紧凑的联合短窗候选。它利用点间及时序信息，输出位置、预测可见性与预测准确性分数；本项目使用公开 scaled offline 权重。窗口内允许使用后面的图像，因此该分支不是逐帧因果估计。截止帧外的视频不能送入模型；查询坐标被钉住的查询帧也不能用作独立验证样本。[论文](https://openaccess.thecvf.com/content/ICCV2025/papers/Karaev_CoTracker3_Simpler_and_Better_Point_Tracking_by_Pseudo-Labelling_Real_Videos_ICCV_2025_paper.pdf) · [官方代码](https://github.com/facebookresearch/co-tracker)

**TAPNext++（CVPR 2026 Findings）**作为递归在线候选。论文针对长序列、遮挡后重检测进行了训练设计，并单独评价重检测；这与刀尖邻域失去可见纹理后重新出现的需求相关。它并非为橡胶、润滑或高压缩专门训练。采用现成 PyTorch 权重，无需为了部署重做论文训练。[作者项目页](https://tap-next-plus-plus.github.io/) · [论文](https://arxiv.org/abs/2604.10582) · [官方实现及权重说明](https://github.com/google-deepmind/tapnet/tree/main/tapnet/tapnextpp)

截至本文编写：CoTracker3 和 TAPNext++ 均已完成本地 GPU 执行验证；TAPNext++ 使用官方 256 分辨率权重，源码与权重指纹已登记，新增依赖隔离在其本地资产目录，不修改共享环境。TAPNext++ 后端逐帧前向处理首帧查询，不使用未来帧；只输出预测可见性，不伪造独立准确性分数。两个后端的原始 `observed` 均为假，需等待图像验证。实际视频结果见正式 report。不得把论文基准数值、官方高端 GPU 吞吐量或模型可见性分数写成本机精度/速度。CoTracker3 资产的非商业许可与 TAPNext++ 的 Apache 2.0 许可分别保留；源码和权重指纹写入本地资产记录。

两者只提供候选坐标，不自动增加观测数。评价时分别保留网络原始结果与图像验证后的结果，列出网络新增正确点、错误吸附刀具点、未验证预测、被拒绝点及时间信息使用范围。高分但匹配到油膜或刀具仍是错误；两个网络同意也不构成独立物理真值。

## 6. D：有限应变内部平衡 gap

原来的相邻 `C = FᵀF` 平滑只控制运动学变化。本轮新增的力学分支使用平面应变嵌入 `F₃ = diag(F₂,1)`，采用可压缩 Neo-Hookean 势：

\[
\frac{\psi}{\mu}=\frac{\operatorname{tr}(F_3^TF_3)-3}{2}
-\ln J+\frac{\lambda}{2\mu}(\ln J)^2,\qquad
\frac{\lambda}{\mu}=\frac K\mu-\frac23,
\]
\[
\frac P\mu=F_2+\left(\frac\lambda\mu\ln J-1\right)F_2^{-T}.
\]

只组装已通过材料、刀具、断开边和有效几何检查的三角单元。对内部节点组装内力，所有未知外力边界行置零：

\[
R_i=\sum_{e\ni i} A_e P_e\nabla N_i,\qquad
E_{\rm eq}=\frac{1}{2\mu^2}R_b^TM^{-1}R_b.
\]

`M` 是一致 P1 质量矩阵。实际采用 Cholesky 白化和解析切线；图像项保持鲁棒损失，力学残差保持二次范数，避免分量鲁棒损失破坏其旋转客观性。数值迭代在低 J 区使用有限延拓，最终不接受翻折或低于几何下限的映射；延拓结果不是应力。

这是 Genet 论文 Eq.14–15 的**内部项**，没有复现其边界牵引梯度项。均匀受载形变允许有非零应力及边界力，只要求内部平衡；不会把切割接触面错误当作零牵引自由边界。[Genet，2023，原文](https://comptes-rendus.academie-sciences.fr/mecanique/articles/10.5802/crmeca.228/) · [官方 Neo-Hookean 推导](https://docs.fenicsproject.org/dolfinx/main/cpp/demos/demo_hyperelasticity.html) · [平面应变示例](https://jsdokken.com/dolfinx_mpc/main/python/demos/demo_periodic_homogenization_nl.html)

本构与平面应变是待检验条件：3 mm 厚橡胶的表面未必满足该二维约束，也未建模预应力、黏弹性、损伤、液体载荷及离面运动。力学分支必须从明确声明近似无预应力的原始参考出发，不能把相隔 12 帧的已受载参考直接当无应力态。不强制 `det(F₂)=1`；`K/μ` 与权重做敏感性对照，不用用户 FE 或显微镜目标拟合这些参数，否则会形成验证循环。

## 8. 部署与验收边界

复用既有材料匹配核和共享掩膜灰度函数，不新增第二套基本光流实现；网络后端共享候选接口、ID/坐标检查和资产追溯；力学放在现有有限变形模块，默认权重为零。新模块先写独立结果，原默认和既有滑移曲线不因部署自动替换。具体代码入口、参数及实际结果随正式 report 一起交付。

验收按同一材料 ID 集合，同时报告全节点、共同受支持节点及覆盖率。已知真值合成测试负责算法正确性；后续精度验收仍需独立人工可见片段、静止段、遮挡后重现段和表面整带留出检查，本轮五组历史开发截面不能替代它们。图像残差及循环误差是内部一致性，不能代替物理真值。每一步都应允许被证据否定，并保留失败原因；不能以删点、扩大接触容差、强制平台或接近显微镜数值作为成功标准。

统一入口为 `python softcut.py optimize --stage reliability --config configs/optimization.reliability.json --out results/new_reliability`；先加 `--check-only` 可检查配置和来源。使用已部署本地模型，加载时核查官方源码、权重 SHA；不会自动下载、训练或更改已有轨迹。当前结果：[五组统一报告](../results/20261025_reliable_pipeline/final/index.html)；计数及数组验证：[validation.json](../results/20261025_reliable_pipeline/final/validation.json)。模型安装来源、许可证与本地复现说明在各 `models/point_tracking/*/README.md` 和 `provenance.json`。

完整网格优化步最初在 30 次真实拟合中全部被安全检查拒绝。诊断指出少数单元越界或翻折会否决整步。现提供显式 `feasible_backtracking=True`：尝试原步长，再逐次减半，最多 12 次；要求 Jacobian、材料/刀具边界和特征支持全部保持原标准，目标值不增加。保存未缩短的原始候选、每次失败数量、目标和接受步长。它使有限更新可用，但不是约束问题的完整最优解，也不能消除本构与观测误差。默认关闭，既有结果不变。

本轮五组各约 0.5/1.0 mm 的结果和阶段判断见[总计划第 13 节](material_tracking_optimization_plan.md#13-四模块部署与统一复核2026-10-25)。边界掩膜与两网络尚未改善原始身份恢复；力学修正有图像内部一致性收益，未证明真实位移更准确。这些负面结果是方法选择逻辑的一部分。
