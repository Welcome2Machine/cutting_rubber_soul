# 0915 应变“虎皮分层”的排查与修复

## 原因链

原始 l60a5 AVI 中有相机叠加的固定网格：竖线 x=170、341、511、682、853；横线 y=127、255、383、511、639。四个抽样原始帧的这些像素灰度均为 85，线宽为 1 px。网格静止于图像坐标，材料纹理则随切割运动。

旧 0915 光流入口直接读取原始 AVI，再裁剪并做 BGR→RGB 转换。固定网格既进入跟踪模型，也进入以局部 Laplacian 方差选参考帧的清晰度评分。分割模块里的网格预处理不会自动作用于这个独立入口。模型由此可能将固定线和真实材料纹理混用，产生随位置变化的位移偏差。

此前 l60a5 的 uy/Eyy 出现约 128 px 周期，而光流分组 y 边界间距为 192 px。周期结构已存在于保存的位移中，不是应变色标才生成的。相对较小的周期位移误差经过求导，会放大成正负交替的应变条带。

例如仅作误差传播说明：若纵向位移误差是 a·sin(2πY/L)，其对纵向位移梯度的贡献为 (2πa/L)·cos(2πY/L)。

| 符号 | 含义 |
|---|---|
| Y | 初始参考图像中的竖直位置，px |
| a | 示例中的周期位移误差振幅，px |
| L | 周期长度，px |
| π | 圆周率 |

a=3.6 px、L=128 px 时，梯度伪影振幅约为 0.177，即 17.7 个百分点量级。这里是简化传播示例，不是把实测应变分解成已知真值；实际计算仍使用包含横、纵位移的 Green–Lagrange 有限应变。

## 修复

新增 `src/tracking/fixed_grid.py`，用原始坐标两侧未覆盖的像素插值替换确认的单像素行列。交叉点使用清洁四角的信息。仅处理 8935 个像素，占整幅图的 1.136%；网格以外逐字节不变，输入文件也不改变。CPU 单帧中位耗时约 0.562 ms。

处理放在 `FrameReader` 顺序解码后、写入短窗口图像缓存前。因此每个原始帧只处理一次，参考帧评分和后续模型裁剪看到相同的去网格图像。确认网格坐标必须在裁剪前使用；不能在裁剪后的局部图像上按六等分重画网格掩膜。

该配置显式用于本批 1024×768 原始 AVI。它不自动套用于其他分辨率、无网格视频或压缩后带振铃的任意图像。插值去掉了人工叠线，但无法恢复被网格遮住的真实纹理。

0915 批入口已经接入该处理。跟踪继续使用现有模型、FP32、全部原始时间帧、固定材料点身份、原重叠融合策略和原分割。应变的 R48、自由截距、IRLS、初始参考以及残差门限均保持一致。

## 缓存与复现

旧 chunk 只绑定前一窗口的位置/可见性，首窗口全 NaN 时不能充分区分改变后的输入。现在 v7 schema 绑定源路径/文件大小/修改时间、初始点字节、原始帧映射和预处理签名；独立修复运行还核对全部分割掩膜内容及模型/核心代码指纹。

旧结果保留在 `results/20260918_0915_native_v6`。本次修复使用 `results/20260919_grid_fix`，不会混用原缓存。短测试采用完整 mapping 的前 20 个窗口，共 309 帧；比较前 300 帧，排除未来窗口尚未融合的末尾 9 帧。后续全片计算直接继续这些已验证的修复窗口。

## 对照设计和验证

原始首窗口使用当前代码重算，与原结果的 3438 个点、24 帧坐标完全相同，可见性也完全相同。这排除了非预期模型/数值路径更换。

已知运动测试先移动合成纹理，再叠加静止网格，使用同样模型和点集合：

|---|---:|---:|
| 无叠线 | 0.16562 | 0.32358 |
| 固定叠线 | 0.20745 | 0.45369 |
| 固定叠线后修复 | 0.16622 | 0.32375 |

各支模型支持率均为 100%。这是已知平移纹理上的因果对照，不能直接当作真实橡胶的绝对测量精度。

真实视频比较使用同一批从初始持续受支持的材料点；两支局部拟合和显示再使用共同有效节点、共同网格单元，另列各自覆盖率。检查固定网格周期振幅、位移运动量、局部残差、严格支持比例和色标饱和，避免用少显示点或压缩运动量制造改善。

结果及完整视频验证写入 `results/20260919_grid_fix/comparison/verified.json`；逐帧数据保存在同目录。`preflight/` 保存原图修复证据、已知运动和原始首窗复现。

## 真实视频的 300 帧结果

2026-09-19 完成 l60a5 前 300 帧（25 s）匹配对照，使用相同材料点身份、相同局部求导方法和相同 ±10% 色标。修复前后的区别来自跟踪输入；没有对应变结果做额外平滑。第 299 帧的结果如下：

| 指标 | 原输入 | 去固定网格后 |
|---|---:|---:|
| ROI 内 uy 的 128 px 周期振幅 | 1.5734 px | 0.0731 px |
| ROI 内 Eyy 的 128 px 周期振幅 | 4.6941 个百分点 | 0.2590 个百分点 |
| 局部位移拟合 RMS 中位数 | 0.8304 px | 0.4868 px |
| uy 中位数 | 11.7779 px | 12.6326 px |
| 拟合 RMS ≤ 0.5 px 的节点数 | 481 | 1345 |

这里的周期量在参考坐标 ROI（x=60–300、y=90–710 px）中，扣除共同定义的二维二次趋势后拟合正弦与余弦，计算其合振幅。Eyy 周期振幅下降约 94.5%，位移拟合残差中位数下降约 41.4%，整体运动量没有被压平。全段严格残差门限的覆盖比例从 66.39% 提升到 81.30%。

图中仍展示部分超过残差门限的拟合以便公平观察伪影，明确标记为 exploratory；严格门限标记另存于数值结果中。修复显著消除了规律横条，但接触区仍有高残差，Exx 也仍有较宽竖带，不能将本次改善解释为全部区域已达到绝对测量精度。

另外检查了 0915 全部十个原始 AVI 的首帧：上述 8935 个网格像素均严格为灰度 85，处理后的所有非网格像素均逐字节不变。当前已完成的真实运动因果对照限于 l60a5。
