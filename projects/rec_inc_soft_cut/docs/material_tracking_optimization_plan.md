## 1. 要解决的实际问题

系统需要回答三个层次的问题：材料可见纹理移动了多少；原始表面怎样变形、怎样绕刀具运动；每个下压深度对应的刀尖接触材料最初位于哪里。
第一层有图像对应可直接验证，第二层需要边界和材料身份，第三层还需要真实接触与表面拓扑证据。前一层结果平滑，不代表后一层自动成立。
本轮重点是补齐这三层之间的证据链，并将默认计算、研究候选和模型推断分开保存。

具体目标如下：

- 保持材料 ID，不把刀具纹理、液体运动或新的裂面接成原材料轨迹。
- 对旋转、拉伸、剪切和压缩使用有限变形描述，并避免跨刀具耦合。
- 表面地址来自原始表面的材料映射；深层材料只能提供有明确限制的辅助约束。
- 对遮挡、压缩下的地址合并、候选冲突与模型失配分别给出原因。
- 输出可追溯到源帧、接触零点、尺度和质量状态的数据，供有限元独立校对。

现阶段不把“起裂检测”“所有点高置信度”“微米级精度已验证”列为已实现成果。

## 2. 物理量、坐标与符号

像素坐标为右向 x、下向 y。有限元交接中的实验坐标可以取右向 x、上向 y，但必须显式保存变换，不能只改轴标签。
初始材料参考帧与首次接触帧可以不同；位置、位移和接触偏移都必须说明各自参考。

| 符号 | 含义与单位 |
|---|---|
| t、t_c、t_r | 当前时刻、首次接触时刻、退刀开始时刻；帧映射可进一步换算物理时间 |
| X_i、x_i(t) | 固定材料 ID i 的初始和当前图像位置，px |
| b(t) | 配准后的刀尖图像位置，px |
| α | 像素尺度，μm/px；当前条件来自接触到回退约 3 mm |
| d(t) | 从首次接触为零的竖直压入深度，mm |
| Γ₀(s) | 按初始弧长 s 标记的原始自由表面，s 为 px |
| φ_t(X) | 材料从参考构型到当前构型的映射 |
| s_*(t)、s₀ | 当前接触材料在初始表面的地址、首次接触地址，px |
| Δs₀(t) | 当前与首次接触地址之差换算成的原始表面距离，μm |
| F、C、E、J | 二维形变梯度、右 Cauchy–Green 张量、Green–Lagrange 应变、det(F) |
| λ_s | 映射表面段的当前长度/初始长度，无量纲 |
| I、Ĩ | 原灰度图与局部亮度标准化后的图像特征 |
| ε_b | 刀尖与映射表面的几何接近容差，px；不是允许滑移量 |

深度使用 `d(t) = α × [b_y(t) − b_y(t_c)] / 1000`。
当前接触前后的约 3 mm 行程用于尺度标定，不是独立精密标尺；零点变化也会改变标定，必须一起复核。
截取 1 mm 采用刀尖位移首次越过阈值前的完整帧前缀，不用视频时长的三分之一，不删除中间的深度小波动。
压缩视频的显示 fps 与原始采集时间不是同一个量；原始 AVI 帧号由 `frame_mapping.npz` 对应，不能按显示 fps 直接计算实验速度。

所求偏移是 `Δs₀(t) = α × [s_*(t) − s₀]`。
它表示“接触材料身份在初始表面上的变化”，不是同一个材料点在空间中的总位移，也不是刀尖向初始斜面的最近法向投影。
深层材料点反映到初始位置后再法向投影，只有在经验证的形变模型支持下才能近似此量；不能直接当作定义。
在起裂后，刀尖可能接触新生成表面，此时原始自由表面的地址未必存在。本轮仍遵守既有明确截止深度，不更新用户规定的起裂值。

## 3. 当前基础与主要差距

现有默认方案已有去阴影、局部形变纹理匹配、历史参考、前后向核对、材料 ID、刀具几何与质量状态。这些构成了可工作的实验处理流水线。
与高质量计量研究相比，主要差距不在“是否用了 DIC 或神经网络”，而在独立真值、有效空间分辨率、复杂边界、外推可辨识性和实验标定。

| 环节 | 当前基础 | 需要补齐的证据或能力 |
|---|---|---|
| 图像预处理 | 去阴影后纹理更可见 | 反光、油液折射、饱和和遮挡不能靠增强恢复 |
| 局部材料跟踪 | 固定 ID 与仿射纹理匹配 | 强弯曲区内单一仿射模型可能混合不同层运动 |
| 刀具约束 | 已有分割与刀具参考 | 掩膜边缘误差和跨界小块仍会影响身份 |
| 大变形场 | 局部运动可计算 | 客观性、翻折、局部可逆性与跨区域约束需独立检查 |
| 表面地址 | 有 MMT/OBT 及质量标记 | 深层映射与原始表面实际接触的关系仍不充分 |
| 精度验证 | 有回归检查和视频审查 | 尚无本场景完整外部真值与标定不确定度 |
| FE 校对 | 已有数据交接格式 | 统一坐标、参考深度、空间尺度和滤波后再比较 |

首要原则是将“图像有支持但模型不适配”与“图像本身没有信息”分开。接触估计失败不能直接解释为全部材料点丢失。

## 5. 有限变形候选的实际算法

每个局部试验先取保存轨迹中刀尖附近的固定材料 ID，以这些 ID 的参考帧位置构建 Delaunay 三角网格。
本次真实试验最多 100 节点，当前刀尖半径 100 px，参考帧距当前帧 12 个处理视频帧；它只修正局部时段的增量映射，不是从初始到当前的累计形变。
材料与刀具掩膜同时检查单元内部和边缘；跨刀体、出画面、退化或已指定断开的单元不参与耦合。
这种保守单元剔除会降低刀尖边缘覆盖，不能把未参与图像拟合的保留节点称为新观测。
当前亮度标准化的高斯统计窗口仍可能混入邻近刀具像素；单元采样排除刀体并未完全消除此影响。后续需单独比较按材料掩膜归一化的统计窗口，检查边界误差和有效纹理支持，不能将刀具干扰视为已经解决。

每个三角单元采用仿射映射，计算 `F = ∂x/∂X`、`C = FᵀF`、`E = (C − I)/2`、`J = det(F)`。
相邻 C 的差异用于运动学平滑，因此叠加共同刚体转动不会被当作应变。这不是相邻位移相等约束。
概念性残差向量由三部分组成：图像标准化亮度差、加权相邻 C 差、J 低于下限的惩罚。
当前通过 `soft_l1` 鲁棒最小二乘优化上述残差，使用稀疏解析 Jacobian 与两级平滑图像，单节点修正限制为相对初值每坐标 ±5 px。
Jacobian 下限默认 0.08 是数值防翻折条件，不是橡胶的物理可压缩性或接触压力阈值。

候选只有在几何安全且优化目标未变差时才数值接受；`accepted` 与 `optimizer_converged` 分开记录。
停止条件达到或目标下降都不能证明材料身份正确。失败时位置保留旧值，质量状态可更保守。
新 `supported` 必须同时满足输入支持和当前图像残差检查；推断不能升级成直接观测。
另外使用未参与优化的采样位置计算图像残差，但这些采样来自相同图像且相互相关，因此是泛化诊断，不是独立测量真值。

**该模块不是 Genet 的平衡间隙法，也没有本构、边界牵引、摩擦定律或三维不可压缩方程。** 二维 J 不能解释为材料三维体积变化。
下一步如果引入力学正则，应单独命名、配置、做本构敏感性，并始终保留未使用待校验 FE 模型的图像分支。

## 6. 表面构建与接触地址求解

当前表面模块保留初始折线的顺序和弧长标签，以局部材料对应关系将整条原始表面向当前帧正向映射。
局部邻域尝试 12、20、32、48 个材料点，检查空间秩、条件数、鲁棒拟合误差、凸包外推距离和正 Jacobian。
留一法检查被留出的材料点；当存在足够表面与深层支持时，再用深层拟合预测被整体留出的表面点，暴露层间模型失配。
支持点先排除刀体和不可用图像区；连接表面段也不能穿过刀体、跨越缺测段或已提供的侧别边界。
当前试验没有独立侧别标签，语义材料掩膜也不等同于独立验证的纹理可见性，因此结果至多是条件候选。

仅对有效映射表面段求满足 `‖φ_t(Γ₀(s)) − b(t)‖ ≤ ε_b` 的地址集合。
默认接近容差 3 px，歧义邻域 0.5 px；它们限制图像几何吻合，不限制最终累计偏移，更不意味着滑移最多几十微米。
分离的地址区间保持分离；缺测区域不直接连线补成唯一接触点。
当多个地址靠近刀尖或 `λ_s < 0.03` 时标为歧义/压缩下不可分辨，不自动冻结为零滑速。
该区间是几何容差反演集合，不是统计置信区间。模块始终保留 `contact_observed=False`、`topology_verified=False`，防止把图像接近当成接触证实。

目前表面失败的主要障碍之一是局部二维仿射模型覆盖了弯曲不同的表面与深层，而不是每次都缺少表面材料点。
例如 n33 在约 0.75 mm 时仍有原表面 ID 到刀尖约 0.3 px，但有效映射曲线的最近间距约 20.9 px；该冲突提示模型适配问题，应先检查邻域和曲率。
已追加初始表面坐标中的 `[1,t,n,t²]` 模型；此处 t、n 分别为局部切向、法向空间坐标，不是时间。邻点限于初始表面 18 px 带内，独立检查留出误差，没有在失败时悄悄回落到仿射结果。
该版本通过曲面真值和仿射一致性等模块测试；n57/n33 在约 0.75、1 mm 的四个共同输入快照中，仿射与二次版本仍全部 `unavailable`，没有为输出数值而放松门限。
不能仅扩大刀尖容差、允许任意深层投影，或按显微镜预期值调节曲线来“修复”缺失接触点。

## 7. 本轮已运行结果与负面结果

结果入口：[局部优化对照 HTML](../results/20261024_optimization_deployment/index.html)；机器可读结果为同目录 `summary.json`，配置与解释器保存在 `run_config.json`、`execution.json`。
以下表格对应这次已保存运行；报告中共同支持点误差和两幅图各自的表面映射已补齐，位置优化没有因此重算。

| 合成场景 | 全节点平均位置误差：基线 → 候选，px | 支持率：基线 → 候选 | 判断 |
|---|---:|---:|---|
| 平移 | 0.0042 → 0.0000 | 100% → 100% | 简单已知图像平移可恢复；不能外推至真实精度 |
| 拉伸剪切 | 0.1343 → 0.1163 | 100% → 100% | 均值下降，但 P95 从 0.230 升至 0.275 px |
| 旋转 | 0.1066 → 0.0815 | 100% → 100% | 此算例均值及 P95 改善 |
| 渐变阴影 | 0.1207 → 0.1107 | 100% → 100% | 均值下降，但 P95 从 0.244 升至 0.264 px |
| 移动高亮线 | 0.9502 → 0.3613 | 92.9% → 83.3% | 全节点均值改善，同时存在覆盖损失 |
| 刀具遮挡 | 2.2155 → 2.2155 | 81.0% → 66.7% | 候选被拒绝，固定节点位置误差完全未改善 |

遮挡场景的“受支持点平均误差”下降来自筛除更多点，不能宣传为找回了遮挡材料。报告同步给出共同支持点误差，避免样本选择造成虚假提升。
合成图像真值来自已知仿射变换，尚未覆盖真实裂面生成、三维压缩、油液折射和复杂纹理丢失。

真实试验是 `1014n57a1`、`1014n33a1`，各取约 0.25、0.50、0.75、1.00 mm 的四个深度；两组均声明为开发数据，不是独立留出工况。
8 个局部试验中 7 个数值接受；接受者在同一图像上的留出位置残差下降约 2.9%–7.3%。这只能说明图像一致性改善，不能说位移精度提升了相同比例。
n57 约 0.75 mm 候选被拒绝，保留原位置。各接受试验节点位置变化中位数约 0.17–0.24 px，不能据此声称实际误差只有该数值。
首轮局部仿射表面结果大多 `unavailable`；n33 约 0.25 mm 基线出现一个条件地址候选，网格修正后反而不可估计，表面接触这一层未得到稳定改善。
本轮有限网格单次求解时间约 0.16–1.80 s，不包括完整视频读取、分割、跟踪与表面分析，因此不能直接推算整条视频耗时或宣布全流程提速。

近表面曲率对照见 [surface_curve_ablation/index.html](../results/20261024_optimization_deployment/surface_curve_ablation/index.html)。
二次模型的有效表面节点数量在 n57 两深度由 20/11 增至 34/15，在 n33 两深度由 101/83 降至 50/49；四个快照都仍无有效接触地址。
这说明增加曲率表达并不能单独解决当前问题；限制到近表面后也可能暴露邻点秩不足或增加拟合失败。后续需要同时检查支持几何、侧别、局部身份和独立轮廓证据。

## 9. 验收规则与回退

下列是后续候选的建议工程验收门槛，不是本项目已经取得的计量精度：

- 在固定同一节点集合上比较平均误差与 P95，同时报告可见/遮挡分组、共同支持点和全节点结果。

- 静止段滑移不应系统增长；发生变化时先检查接触零点与映射，不用强制平台掩盖偏差。
- 性能评价使用相同分辨率、点数、CPU/GPU和完整流程范围，记录内存/显存、总时长和失败率。
- 未达到门槛的模块保持研究模式。拒绝时回到保存初值，输出拒绝原因，既有默认轨迹及滑移结果不覆盖。

本轮拉伸/阴影的尾部误差、移动高亮的覆盖下降、遮挡无位置改善和表面地址失败，已说明不应立即启用为默认。

## 11. 文献依据与使用边界

[iDICs 2025 指南](https://idics.org/guide/)和 [DIC Challenge 2.0](https://link.springer.com/article/10.1007/s11340-021-00806-6)支持计量验证、噪声与空间分辨率并重的路线。
[X-DIC](https://comptes-rendus.academie-sciences.fr/mecanique/articles/10.1016/j.crme.2007.02.003/)与 [Subset splitting](https://barthelat-lab.mcgill.ca/files/papers/EM2010.pdf)支持跨界面小块需要允许运动不连续的思想，不能直接作为本实验起裂判据。
[Genet 2023](https://comptes-rendus.academie-sciences.fr/mecanique/articles/10.5802/crmeca.228/)和 [Mendoza 2019](https://www.sciencedirect.com/science/article/abs/pii/S0045782519303457)用于规划机械正则化，当前代码没有复现其完整力学方程。
[Lava 等 2020](https://onlinelibrary.wiley.com/doi/10.1111/str.12350)支持将 FE 与实验统一到相同测量算子、分辨率和滤波后再比较；仅插值到同一网格不足以排除测量偏差。
[Moreno-Mateos、Steinmann 2026](https://www.nature.com/articles/s41524-025-01869-y)直接结合软切割 DIC、有限应变和计算对照；其[公开数据](https://zenodo.org/records/15873110)适合规划外部检验，不能代替本项目标定。
[Spagnoli 等 2019](https://www.sciencedirect.com/science/article/pii/S0167844218306323)提供斜切与摩擦背景；[Prevost 等 2013](https://link.springer.com/article/10.1140/epje/i2013-13017-0)提供局部粘着/滑动的直接位移观测思路，但透明接触实验不等同于遮挡刀尖。
[CoTracker3](https://cotracker3.github.io/)与 [TAPNext](https://openaccess.thecvf.com/content/ICCV2025/html/Zholus_TAPNext_Tracking_Any_Point_TAP_as_Next_Token_Prediction_ICCV_2025_paper.html)是尚待本地验证的现成候选，不是当前结果的精度背书。
完整 19 条书目、具体用途、全文可用状态和限制见 [reference/bibliography.json](../reference/bibliography.json)。本方案没有把与软切割条件不同的论文结论硬套为接触地址或起裂真值。

### 12.2 这次实际部署了什么

1. **前缀有效性修复。** `depth_prefix` 只检查目标深度首次越界之前和越界帧本身；越界后的缺测不否决完整前缀。越界前缺测仍拒绝，不跳帧补齐。
   真实例子是 `1014l57a2`：前 1 mm 连续有效，后面存在 51 个 NaN；旧检查错误地拒绝整组，新检查恢复了合法的 413 帧前缀。
2. **材料掩膜归一化特征。** `FiniteDeformationConfig(feature_mode='material-masked')` 从初始 3×3 平滑开始，对尺度平滑、局部均值/方差统计全部排除刀体和非材料像素。
   `min_feature_support=0.25` 是高斯核有效权重比例，不是物理置信度。插值边缘采用额外一像素保守支持检查；掩膜外像素由黑变白不会改变材料内特征或拟合位置，已用测试验证。
   该分支并未修正不准确的掩膜，也不隔离掩膜内的液体、反光和全部跨障碍邻域；保持可选，默认仍为 `legacy`。
3. **原始表面一维模型。** `SurfaceObservabilityConfig(model='surface-curve')` 只用初始表面 3 px 带内的固定材料 ID，沿初始弧长 s 拟合位移 u(s)，输出 `Γ₀(s)+u(s)`。
   s 是原始表面弧长，u 是同一材料条带的图像位移，均以 px 表示。它不要求表面点张成二维面积，也不把深点的初始位置投影成接触点。
   不可观测 ID、超过 12 px 的初始弧长采样间隔、刀体和可见性缺口均切断支持链；12 px 是采样连续性上限，不是允许滑移量。拒绝沿弧长外推和跨被模型拒绝的材料身份补桥。
   新模型使用独立材料 ID 留出检查。二维 Jacobian 和深层整带留出指标保持 NaN，分别注明不适用；不能把一维留出检查冒充深层验证。
   近表面条带仍不等于真实边界，未知法向位移梯度未被识别，因此输出始终是条件模型推断，`contact_observed=False`。
4. **统一对照与诊断。** `optimize --stage features` 比较相同初值的两种特征；`--stage surface` 支持配置多个表面模型，并加入零深度。
   报告表面连续弧长覆盖、有效段到刀尖的最近距离、当帧语义边缘一致性及失败分类。语义边缘来自相同分割流程，只用于一致性诊断，不标为独立真值。

### 13.1 接触与身份的实际证据

五组与前轮相同，仍是历史开发数据。接触审计每组131帧；共同受支持的近表面材料群为47–54个，并非材料点全部消失。几何原文件与准备输入的刀尖在所有有限重叠帧完全一致，排除了这两个文件之间的拼接错位。四组语义/亮度端点在原零点分歧约6–10px，亮度端点可能截短，不能当真值修正保存刀尖。材料响应候选帧与原零点依次为：n57 89/92、n33a1 176/164、n33a3 120/120、l57 153/153；n60a2接触前基线不足且几何区间左删失。不同证据共享图像，并非独立统计测量。

每组另取约0.5、1.0mm两个截面，四种身份验证方案使用同一240个点次（不是240个独立材料点），其中测量层在当前帧支持232点次。近期查询必须受支持，所以本轮只包含8个测量层当前不支持点次，不能代替长期遮挡后重现基准。后续逐点复核确认其中7个在原跟踪层仍受支持；不能把这8个统称为已跟丢的材料身份。

### 13.2 力学与安全回溯

初始完整步对照位于 `results/20261025_reliable_pipeline/validated/`，30次拟合均数值收敛但安全拒绝。针对真实违规加入可行回溯后，三分支各10/10接受安全更新；所有接受步的翻折、材料/刀具边界及特征支持违规计数均为0。两组力学分支各有67–75个内部节点，约束实际参与，不是空分支。

### 13.3 复现、简洁性与剩余工作

完整测试659 passed，另3 subtests passed；175个NPZ可在禁用pickle下读取，55条报告本地链接存在，源码哈希与运行记录一致。原材料跟踪文件12个既有类/函数的AST完全一致，只新增共享灰度与候选验证函数；两个网络合用一个适配模块，四分支合用一个workflow，无新增根目录任务脚本、无训练、无共享环境修改。默认关闭平衡及可行回溯；显式研究配置才启用。

后续优化的具体对象已经缩小：先在可见纹理小片段建立人工可复查身份，区分初始参考仿射模型失配和实际身份漂移；再评估具有明确原始锚点的分段/局部非线性参考映射，及长期重现时的网络重检测。不能通过扩大1.5px一致阈值、放宽刀体约束或强制平台来提高通过数。接触零点需要对端点截短和初始边缘冲突逐一复核；力学需独立材料参数、平面应变适用性和无预应力假设验证。部署完成不取消这些精度验收要求。

## 14. 近表面身份连接优化（2026-10-25）

第 13 节的“零新增”包含选择和准入限制：8 个测量未采用点次全部位于收缩材料掩膜外，网络近期查询也沿用旧位置。因此本轮分别部署中心/采样分离、初始根关键帧连接和初始查询网络，不把上一轮结果概括为网络无法恢复身份。方法依据、公式和决策过程见[近表面身份优化](surface_identity_optimization.md)。

入口为 `optimize --stage identity --config configs/optimization.identity.json --out results/new_surface_identity`。五组使用初始至 1 mm 的完整连续前缀，固定原始 ID 队列包含旧失败点，选择不依赖当前或近期是否受支持；TAPNext++ 从初始帧查询。复用仿射核和统一 workflow，新增模块只管理身份参考关系。旧零点、起裂截止、历史滑移和生产默认不变。

边界与身份链模块已有已知形变、缺测重现、歧义拒绝及数值隔离测试；首轮真实复测发现高分但已拒绝的参考仍可能影响位置选择，已主动中止、修复并补回归测试。新增图像准备缓存已通过逐数组等价检查，实际 68 ID、20 帧身份链约提速 1.15 倍；随后重新执行完整复测，中止输出不作验收结论。**部署及五组完整复测已完成，物理精度尚未得到证明**。关键帧路径共享祖先，新增链式支持只能称为条件图像证据，不能自动作为显微镜或有限元校准真值。

最终完整测试 717 passed、另 3 subtests passed；默认数值回归的 154 个数组一致，范围是六帧已知仿射合成纹理和两种既有核验模式，不是实视频，也不代表 AST 不变。严格周期纹理的单一错误候选反例仍可通过图像闭环，说明循环量不是物理位置误差界。

n57 的首个完整硬停止对照进一步发现：保存/网络候选分支终末失效的 66/61 个 ID 中，47/49 个的最后失效段从累计 8 px 预算拒绝开始，随后参考老化。该相关残差累加没有物理误差界或统计标定依据，因此默认改为 `cycle_budget_policy='diagnostic'`，保留超过阈值的风险标记；`'reject'` 仅作受控消融。逐边前后向、纹理、刀体、歧义和跨参考一致性门槛不变。此举纠正一个人为停链机制，不构成精度改善证明。原对照保留在 `final/`，修正后的五组完整复测放在 `validated/`；最终计数不混用两种策略，详细证据与图解统一见本轮技术文档。

正式结果见[五组视频与报告](../results/20261025_surface_identity/validated/index.html)：3024 源帧、340 个固定 ID，完成初始至 1 mm 前缀。原跟踪不支持而新链支持的条件点次为保存候选 24、加入初始网络候选 45；网络在全队列净增 2408 个支持点次，但刀尖 40 px 邻域净减 391，不能用外围增加掩盖关键区变化。五组末帧近刀尖支持均带累计风险，尚不能作高精度材料真值。边界配对回归近期通过 206→238、双参考一致 15→18，旧 8 个测量缺失的直接双参考恢复仍为 0。逐组表、判断限制与 2 倍速固定视窗视频在[技术文档第 8 节](surface_identity_optimization.md#8-五组完整复测结果)统一说明；默认跟踪、MMT/OBT 与历史滑移不替换。
