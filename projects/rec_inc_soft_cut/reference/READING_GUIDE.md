# 光流、材料跟踪与有限元校对文献导读

基础文献核对日期：2026-10-24；网络候选、TAPNext++ 与参考更新条目核对日期：2026-10-25。这里整理的是当前项目可借鉴的证据与实现思路。文献中的算法成绩不等于本项目的测量精度，下载到本地也不表示完成了逐式复现。

本目录收录 **19 篇论文和 2 版 iDICs 指南，共 21 条**。完整题名、作者、年份、DOI、一级来源、阅读范围、适用模块、下载状态与 SHA-256 统一保存在 [bibliography.json](bibliography.json)，避免在多份文件中维护不一致的书目信息。`papers/` 是公开来源的本地阅读副本，不上传 Git；没有获取本地全文的条目保留官方链接和原因。

## 先读哪几篇

如果目的是尽快把当前系统改成可用于有限元校对的测量工具，建议顺序是：

1. **iDICs 指南 → DIC Challenge 2.0**：先确定“准确”要怎样被证明，以及平滑、点阵密度、空间分辨率的区别。
2. **Moreno-Mateos 与 Steinmann 2026 → Lava 2020**：先读直接软切割的 DIC/有限元对照，再确定统一测量尺度和坐标变换的要求。
3. **Poissant 2010 → X-DIC 2007**：理解为什么靠近刀具、裂缝时不能把整个小块当成一个连续运动体。
4. **Genet 2023 → Mendoza 2019**：再研究如何在图像约束之外加入有限变形和边界条件，而不把假设当作观测。
5. **TAPIR → CoTracker3 → TAPNext → TAPNext++**：理解短窗联合跟踪、因果长时跟踪和遮挡后重检测；目前已部署 CoTracker3 与 TAPNext++ 现成权重，仍须通过本地独立验收。
6. **Spagnoli 2019 → Prevost 2013 → Spagnoli 2018**：分别理解斜切摩擦、局部粘着/滑动和切割变形；Zhao 2025 的分子损伤研究作为后续背景。

这一路线优先解决当前的测量可辨识性、刀具与材料混合匹配、误差验证，再考虑增加模型复杂度。

## 1. 测量验证：不能只比较视频是否顺滑

| 文献 | 本项目需要读出的内容 | 不能直接推出的结论 |
|---|---|---|
| [iDICs 2025，第二版](https://idics.org/guide/) | 采集、标定、相关计算、应变后处理及报告的统一实践；新版增加全局 DIC 内容。 | 通用实验室指南没有解决润滑油、遮挡和橡胶刀尖极端压缩。 |
| [iDICs 2018，本地 PDF](papers/idics2018.pdf) | 作为可直接阅读的基础教材，建立像素尺度、标定和测量不确定度意识。 | 第一版不能称为最新版；第二版下载入口要求登记，本次未代填。 |
| [Reu 等 2022，DIC Challenge 2.0](https://link.springer.com/article/10.1007/s11340-021-00806-6) | 同时评价测量噪声与有效空间分辨率，分别检查位移与应变；官方[挑战入口](https://idics.org/challenge/)。 | 更密的点阵或更平滑的曲线不自动意味着更高的实际分辨率。 |
| [TAP-Vid 2022，本地 PDF](papers/tapvid2022.pdf) | 长序列位置与遮挡状态分开评价；材料身份在恢复可见后是否一致。 | 通用视频的 AJ 指标不能换算成本实验的微米精度证书。 |

**本项目的落地检查建议：**保留静止噪声段、已知平移/旋转、仿射拉伸剪切、局部压缩、照明变暗、刀具遮挡、跨界面运动等独立算例。合成图像可以给出已知真值，但应由独立图像变换产生，不能只验证求解器自己生成的答案。真实视频另外保留人工可复查的少量纹理标记和重复测量；图像真值不足时报告覆盖率与不确定状态，不宣称所有点已获高置信度。

至少同时报告位置误差、静止漂移、可信覆盖率、刀具误吸附率、可见性误判和运行成本。单独“保留点数更多”可能只是增加了预测点。

## 2. 大变形与机械正则化

| 文献 | 借鉴重点 | 适用限制 |
|---|---|---|
| [Genet 2023，本地 PDF](papers/genet2023.pdf)；[出版页](https://comptes-rendus.academie-sciences.fr/mecanique/articles/10.5802/crmeca.228/) | 有限应变平衡间隙正则化，特别是大变形运动和边界牵引的处理。 | 论文展示的合成图像结果不直接覆盖刀具接触、断裂、油液和遮挡。 |
| [Mendoza 等 2019](https://www.sciencedirect.com/science/article/abs/pii/S0045782519303457) | 内部与不同边界条件分别处理，避免对自由表面、接触面套用同一正则化。 | 公开摘要明确使用线弹性参考；不能把它直接当作超弹性大压缩接触算法。 |

**本项目推导出的实现顺序，不是论文已验证的结论：**先稳定局部有限变形映射，检查形变梯度的可逆性与条件数；再添加跨材料邻域的弱一致性；最后才考虑带本构关系的力学正则化分支。每增加一项都要与纯图像基线做独立对照，并保留未正则化观测。

以下三个判断尤其需要克制：

- 纹理消失可以来自压缩、遮挡、反光、液体或失焦，不能据此直接判为“高度压缩后滑动停止”。
- 高度压缩可能降低接触地址变化，也可能伴随切向流动、挤出或局部滑动。零速度保持需要可见运动证据支持，不能仅靠缺测自动触发。
- 二维形变梯度的行列式表示所见平面的面积变化；它不是橡胶三维体积比。没有出平面信息时，不能把 `det(F_2D)=1` 当作严格不可压缩条件。

## 3. 刀具、界面与裂纹：连续性要分区域使用

| 文献 | 借鉴重点 | 适用限制 |
|---|---|---|
| [Réthoré、Roux、Hild 2007，X-DIC，本地 PDF](papers/rethore2007.pdf)；[出版页](https://comptes-rendus.academie-sciences.fr/mecanique/articles/10.1016/j.crme.2007.02.003/) | 位移表达中显式允许界面两侧不连续，避免把滑动界面抹平。 | 示例为螺栓连接界面，不是本项目的橡胶起裂检测器。 |
| [Poissant、Barthelat 2010，本地 PDF](papers/poissant2010.pdf) | 对跨越不连续面的局部小块进行拆分，分别匹配两侧。 | 拆块不会凭空恢复被刀具完全遮挡的纹理。 |

本项目可以先实现几何侧别明确的单侧匹配：材料小块只使用属于材料且采样路径不穿越刀体的有效像素；邻域约束不跨刀体，也不跨已确认裂面。侧别是局部可见性约束，不把刀尖两侧划成禁止绕行的固定半平面。未知界面可以保留多种候选并比较图像残差，不能因为两侧速度不同就断言发生断裂。

**刀具排除应作用于图像采样、候选匹配、邻域构建和质量判断，不能只在最后把显示点挪出刀体。** 后者可能让视频更整齐，却保留了错误材料身份。该部署建议是对项目误吸附风险的分析，不宣称 X-DIC 原文已解决本项目全部问题。

## 4. 长时材料身份与神经网络候选

原始身份连接本轮增加 [Pan、Wu、Xia 2012](https://doi.org/10.1016/j.optlaseng.2011.05.005)（[全文](https://www.ncorr.com/download/publications/panlargedef.pdf)）：条件参考更新用于大变形失相关，但更新会引入累积误差。iDICs 第一版第 5.2.1 节、印刷页 54 也讨论了分段相关。因此采用固定初始身份、经图像核验的关键帧和跨参考检查；这些新增检查是本项目设计，不是原论文已经证明的无漂移方案。具体实现与拒绝条件见[近表面身份优化](../docs/surface_identity_optimization.md)。

| 文献 | 在这里的合适角色 | 必须保留的限制 |
|---|---|---|
| [RAFT 2020，本地 PDF](papers/raft2020.pdf)；[作者代码](https://github.com/princeton-vl/RAFT) | 大位移的逐帧候选或对照基线。 | 稠密光流是图像对应；逐帧积分不保证长期材料身份。 |
| [TAPIR 2023，本地 PDF](papers/tapir2023.pdf)；[作者论文](https://arxiv.org/abs/2306.08637) | 逐帧重新匹配加时间优化，用于漂移后的候选重定位。 | 模型预测的遮挡位置不是图像直接观测。 |
| [BootsTAP 2024，本地 PDF](papers/bootstap2024.pdf)；[作者论文](https://arxiv.org/abs/2402.00847) | 理解真实视频与合成训练分布的差距，选择现成模型作对照。 | 训练方案不是无需成本的后处理；本项目不因此启动再训练。 |
| [CoTracker3，ICCV 2025，本地 PDF](papers/cotracker2025.pdf)；[官方项目](https://cotracker3.github.io/) | 联合点跟踪的独立候选，比较在线与离线版本。 | 邻点联系可能跨刀具传播错误运动，模型 confidence 不是本地计量置信区间。 |
| [TAPNext，ICCV 2025，本地 PDF](papers/tapnext2025.pdf)；[会议页](https://openaccess.thecvf.com/content/ICCV2025/html/Zholus_TAPNext_Tracking_Any_Point_TAP_as_Next_Token_Prediction_ICCV_2025_paper.html) | 因果在线跟踪，适合只允许使用起裂截止之前信息的计算。 | 因果性并不自动解决细纹理、压缩、液体和接触地址错误。 |
| [TAPNext++，2026](https://arxiv.org/abs/2604.10582)；[官方项目](https://tap-next-plus-plus.github.io/)；[官方代码](https://github.com/google-deepmind/tapnet) | 逐帧因果跟踪；长序列训练与重检测指标支持把它作为材料身份恢复候选。 | 论文表 1 中不同数据集和指标并非全面领先；不能将其自然视频成绩直接迁移成橡胶测量精度。 |

建议结构是“候选 → 材料侧别/刀具约束 → 局部图像验证 → 身份和状态输出”。先让现成模型提出可被拒绝的候选，避免直接替换现有固定材料 ID。任何跨时段优化都应明确是否使用未来帧；用于起裂前测量时，不允许拿断裂后的运动来修正此前的物理量。

这些论文没有证明任何一种现成模型能在本项目上稳定达到所需微米级精度，也没有直接解决润滑油的独立运动。保留去阴影处理有助于可见纹理匹配，但无法恢复饱和、遮挡或液体折射导致的真实信息损失。

### 已部署的两种网络候选（2026-10-25）

[CoTracker3 本地资料](../models/point_tracking/cotracker3/README.md)保存官方固定版本 `82e02e8` 与 `scaled_offline.pth`，按 384×512、6 次迭代运行；[TAPNext++ 本地资料](../models/point_tracking/tapnextpp/README.md)保存官方固定版本 `730cda1` 与 256 版权重，逐帧运行。完整下载 URL、SHA-256、许可证和源码哈希见各目录 `provenance.json`，书目中的 `deployment` 字段也保留固定版本。CoTracker3 的代码/权重采用 CC-BY-NC-4.0；TAPNext++ 的[官方 Google 模型页](https://huggingface.co/google/tapnet)与源码采用 Apache-2.0。第三方源码和权重均留本地，不进入 Git。

部署检查使用同一段 n57a1 的 13 帧、24 点：CoTracker3 推理约 3.34 s，TAPNext++ 暖机后约 0.39 s；末帧相对旧轨迹的差值中位数分别为 0.174 px、0.644 px。**这只是执行与一致性检查，旧轨迹不是真值，不能据此宣称前者精度更高或后者长时恢复已获验证。** 这些时间不含模型加载；TAPNext++ 已暖机，两者并非统一暖机条件的速度基准。完整独立验收以本轮统一报告为准。

两者都只提出可拒绝的候选：网络 visibility/confidence 不直接升级为材料观测；TAPNext++ 没有输出的位置置信度明确为 NaN。CoTracker3 使用窗内未来信息，截止帧之后的数据不允许输入；TAPNext++ 在本适配器中逐帧因果运行。只新增了项目本地隔离的 `einops==0.8.1`，未修改共享环境、重新训练或上传视频。256 版 TAPNext++ 已部署，单独的 512 微调版权重未部署。

## 5. 原始表面接触地址：不能由“最近点”直接代替

本项目求的是：**当前刀尖接触到的材料，最初属于原始表面的哪个地址**。它与刀尖在空间中的位置、最近深层材料点的位置、深层点向初始斜面的法向投影，是不同的量。

本目录没有找到一篇可直接套用、并已验证本项目条件的“橡胶斜切接触地址”论文。因此，不能把局部可逆映射、最近点或法向投影贴上文献名称后称为真实表面滑移。可借鉴的是上述材料身份、单侧运动与有限变形工具，而接触地址本身必须单独验证。

建议保留三类证据：可见原始表面点的直接接触；同侧邻近表面及次表面的条件推断；缺少几何可辨识性的不可估计状态。深层点可以辅助约束表面形变，但要说明外推距离和对形变假设的敏感度。断裂产生的新表面不能强行赋予原始自由表面地址。

## 7. 有限元校对：先让两边看到同样的量

[Lava 等 2020](https://onlinelibrary.wiley.com/doi/10.1111/str.12350)明确讨论 FE 与 DIC 在坐标、位置、应变定义、空间分辨率和滤波上的差异。其 levelling 思路是让 FE 结果经过相应的成像/测量算子，再做比较，防止把测量平滑造成的差异误判为材料模型问题。

当前项目可以按以下顺序实现：

1. 明确同一接触零点、同一刀具进入深度、像素到实验坐标的变换及其标定条件。
2. 优先比较材料位移与表面形状，并区分图像支持点、条件估计与预测点。
3. 比较应变时统一有限应变定义、计算邻域和有效空间分辨率。
4. 对 FE 位移生成合成纹理图，经同一测量流程处理；与原始 FE 场和实验估计分别比较，隔离测量偏差。
5. 保留一条未使用待校验 FE 本构/接触假设的图像测量分支。使用该 FE 做正则化后再称其“独立实验验证”，会形成循环论证。

这是建立公平对照的方法，不是要求实验曲线靠近仿真。若两者仍有系统差异，应检查几何、三维运动、材料本构、摩擦/接触、时间和标定，而不是优先调整图像结果。

## 本地资料与复核规则

- [bibliography.json](bibliography.json)：机器可读主目录；`local_status` 明确本地 PDF、仅链接或失败原因，`evidence_scope` 区分全文与仅摘要核对。
- `papers/*.pdf`：仅从出版社、作者机构、arXiv 或 CVF 下载的阅读副本；下载后核对 PDF 文件头、可解析页数和第一页题名，并保存 SHA-256。
- `execution_evidence.json`：2026-10-24 文献下载的来源、环境和内容校验结果；该轮未安装依赖或下载模型。2026-10-25 的网络部署另记在上述模型目录 `provenance.json`，两轮均未发送实验数据。
