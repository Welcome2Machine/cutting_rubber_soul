# 原生 IPC 三角度结果的材料核查（2026-10-18）

本轮范围是当前完整体、有限应变、等容 Maxwell 候选的实现一致性和后续可辨别试验。材料在各角度完全相同，这是用户已经确认的前提。没有启用裂纹、修改物理源码、按角度拟合或启动新有限元路径。此文补充已有 [2023 材料笔记](method_notes.md#r03--dammaß-等2023有限变形黏弹性及相场) 与 [前裂时间响应](prefracture_rate_response.md)，不重复收录论文。

## 1. 实现检查结论

审阅 `mechanics/finite_strain.py` 与 `prototype/ipc_viscoelastic.py` 后，未发现可以解释 33°偏硬的材料导数、坐标旋转、黏性历史提交或时间定义错误。这个结论有实际保存场的局部核查支持，但不等于材料、网格或接触模型已经得到实验验证。

现有方程是

\[
W_{eq}=\frac{G_\infty}{2}(\bar I_1-3)+\frac K2(J-1)^2,
\qquad W_v=\frac{G_v}{2}(\bar I_{1e}-3),
\]

\[
b_{trial}=F C_{v,old}^{-1}F^T,
\quad e-e_{trial}+\frac{\Delta t}{2G_v\tau}\operatorname{dev}\tau_v=0.
\]

应力由已局部消元的增量势导出；只有接受步才提交 `Cv^-1`，切步真实时间为 `Δdepth/v`，与 PTC 数值迭代时间无关。等容迁移矩阵在体积方向为零，故不存在未声明的体积松弛。论文默认 `paper2023` 流动律与当前显式候选 `isochoric_maxwell` 是两个选项，本轮保持二者不变。

主线借用了 2023 文献的乘法分解与预测—校正框架。原论文式 (23) 使用 `K/4*(J²−1−2 ln J)`，原论文也允许体积黏性；当前二次 J 能与仅等容松弛是项目明示的不同假设，不能称为该论文原模型的完整复现。[Dammaß 等，2023，第2.2、3.2节](https://link.springer.com/article/10.1007/s00466-023-02310-1)

极端场非常局部；仅报最低J会让人误以为整个橡胶都压缩到该比例，只报总体平均又会掩盖刀尖邻域问题。极小区域也可能控制接触和滑移，不能由其面积小直接判定其对Fz无影响。需检查对应接触边界、局部网格依赖以及能量/虚功占比，再决定是否影响目标观测。

对于当前体积能，压缩正压 `p=K(1−J)` 有上界K。`J→0`时体积能本身也有限；等容项与防倒置条件仍在。因此，这个选择与原论文发散的对数体积能在深压缩下并不等价。另一方面，二次J能也是成熟超弹模型的一种标准选择，不能把它本身判成编码错误。`d²W/d(ln J)²=KJ(2J−1)`在J<.5为负也不能单独证明材料失稳：它不是全部F切线或声学张量。[Abaqus超弹文档，Polynomial/Ogden形式](https://docs.software.vt.edu/abaqusv2025/English/SIMACAEMATRefMap/simamat-c-hyperelastic.htm)

## 4. 参数含义与可验证的疑点

当前共同参数 `G∞=.14 MPa, Gv=1.24 MPa, τ=1.7 s, K=23.34333333333331 MPa` 给出小应变瞬时 `G0=1.38 MPa`。固定K对应瞬时ν约.4710、长期ν约.4970；不能把它表述为全程ν=.49或严格不可压缩。长期K/G∞约166.74，瞬时K/G0约16.92。这里的变化是剪切松弛引起，体积模量没有变化。

这组很大的剪切松弛幅度仍是假设，57°力曲线选参并不能识别材料的独立模量/谱，更不能证明材料在刀尖新加载区域的瞬时可压缩性正确。Abaqus文档区分瞬时与长期模量；其传统有限应变Prony模型采用历史应力映射，与本项目乘法内部变量算法并非逐式相同。不能拿小应变同一G(t)就宣称大应变模型等价。[Abaqus时间域黏弹性](https://docs.software.vt.edu/abaqusv2025/English/SIMACAEMATRefMap/simamat-c-timevisco.htm)

官方超弹文档指出，平面应变、三维受限变形对压缩性敏感，接近不可压缩时通常应采用混合单元；多种均匀加载模式有助于约束超弹响应。由此支持检查离散/体积响应，但不能据文档给出的比值阈值断言本项目偏差必为锁定。本轮没有把实验材料同一性重新作为未知量。[Abaqus超弹文档](https://docs.software.vt.edu/abaqusv2025/English/SIMACAEMATRefMap/simamat-c-hyperelastic.htm)

## 5. 建议的共同材料验证顺序

1. 先做共同接触轨迹下的体网格对照，并保留原物理验收。33°在0.25–0.5 mm已经偏硬，故先在该范围判别，不需要先重跑深部。纯P1细化通过只说明当前有限压缩性离散对照，不能冒称已消除锁定。
2. 若体离散影响远小于实验偏差，优先做两组共同参数方向的加载全过程检查：保持G0固定而调整G∞/Gv分配；保持剪切分配固定而调整τ。参数必须对33/57同时使用，K固定，材料/摩擦历史各自从零演化。只做当前端点换参数得到的是条件再平衡，不是新参数加载路径。
3. 对每个方向用33/57各自实验的幅值、分段斜率、比值以及参考接触迁移联合判断。若只是两条曲线同比软化，不能解释角度迁移差异，停止该方向，不持续调到57失真。
4. 若基础时间/幅值方向均失败，再考虑同一正系数谱或共同Ogden形状自由度；先用保存的实际F历史作筛选，再对通过者做短FE独立路径。固定场应力/虚功改变只是筛选量，必须同时报告自由残差，不能称为候选FE切削力。已被排除的应力加速松弛候选不重复试验。
5. 只在真实物理理由和数值资格成立时单独评估体积能或K，不能为了降低33°力而任意增加可压缩性。换成论文对数体积能会改变深压缩物理且通常提高该局部体积反力，不能预设它会修复总力偏差。

目前可排除的是若干具体实现错误；仍不能排除离散、共同本构、界面或二维约束对实验迁移的贡献。Maxwell虚功大是能量记账结果，不是根因判定。
