# 宏单元混合离散：依据及本项目的验证边界

本轮只核查近不可压体积约束的离散误差，不改变橡胶本构、摩擦、刀具或底面约束，不加入断裂。

## 方法来源

- [Symfem 的 P1-iso-P2 定义](https://symfem.readthedocs.io/en/latest/docs/symfem/elements/p1_iso_p2/index.html)将来源追溯到 Bercovier–Pironneau (1979)，DOI [10.1007/BF01399555](https://doi.org/10.1007/BF01399555)。它在父三角形的四个子三角形上使用连续线性位移；不能因为名称含 P2 就称为二次多项式位移。
- Jonas Koko，[Uzawa conjugate gradient method for the Stokes problem: Matlab implementation with P1-iso-P2/P1 finite element](https://www.ljll.fr/~frey/papers/Navier-Stokes/Koko%20J.%2C%20Uzawa%20conjugate%20gradient%20method%20for%20the%20Stokes%20problem.pdf)，作者原文介绍细网格速度、粗网格连续线性压力及稀疏装配。Stokes 稳定性不能直接证明本项目有限应变、强畸变和摩擦接触全过程稳定；本项目也没有移植其流体 Uzawa 算法。
- [OpenGeoSys 有限变形 Cook 膜基准](https://www.opengeosys.org/stable/docs/benchmarks/large-deformations/cooksmembranefbar/)展示近不可压 Neo-Hookean 材料的离散锁死与 F-bar 对照。其体能拆分与本项目同类，但本地 Cook 型检查使用自己的 G、ν、载荷与三角形网格，**不是该页面数值的复现**，不将其 F-bar 结果当成本项目的验收真值。

## 本地离散与线性求解

位移用红细分网格 P1；压力用父网格连续 P1。仅压力平方项采用行和集中质量。消元后：

`E = Σ_e V_e W_iso(F_e) + K/2 Σ_i V_i (Jbar_i − 1)²`。

均匀变形的能量和应力与原材料一致；非均匀场的体积约束发生离散层面的改变。局部真实 J 仍逐子单元检查，不能用平均 J 掩盖翻转或局部强压缩。压力投影带来的跨单元切线必须保留。

PTC 的辅助正半定矩阵由修正后的局部块及正半定压力 Schur 项组成。为避免显式 Schur 项扩大矩阵连接，摩擦求解保留辅助压力未知量，求解稀疏非对称块系统。消元后严格恢复原 PTC 方向；代码另检验消元意义下的线性残差。压力未知量没有增加物理黏性，也没有改变最终真实力残差门槛。

## 验证范围

有限变形能量/梯度/切线、刚体转动客观性、有限压缩和剪切下畸变网格压力零模、解析压缩反力、弯曲收敛、块解与消元解一致性，以及真实 IPC 短程需要分别验证。小补丁和 Cook 型算例通过只支持继续进行斜切诊断，不是斜切问题的网格独立性或实验符合证明。

独立诊断入口为 `--element p1-macro-mixed --no-visualize`；同一位移与接触网格的全体积积分对照为 `p1-macro-full`。默认 `p1` 不变。混合压力应力不能用普通 P1 后处理直接渲染，现阶段显式阻止这种误用。实际运行证据及状态见 [求解状态](../docs/solver_status.md)；数值文件只在本地 outputs 保存。

## 2026-10-13：局部体积核查后的适用限制

重新核对Koko作者原文的弱连续性约束（式3.2）：离散压力测试函数能分辨的约束，不等于每个位移子单元逐点满足体积约束。本地独立积分证明，四等面积红细分子单元上的体积增量 `[1,1,1,-3]` 与父P1三个压力测试函数均正交。实际刀尖场含此分量，因此仅展示节点投影体积平均会掩盖局部压胀。该代数事实不是零总能位移模式或有限应变inf-sup失效的证明；Koko的Stokes分析也不能证明当前强接触局部精度。

补充阅读 [Fu、Neunteufel、Schöberl、Zdunek，A four-field mixed formulation for incompressible finite elasticity，CMAME 444 (2025), 118082](https://arxiv.org/html/2503.00989v2)，DOI [10.1016/j.cma.2025.118082](https://doi.org/10.1016/j.cma.2025.118082)。作者引入独立变形梯度和应力，通过混合化/局部消元形成全局位移系统；有限应变非线性体积约束需单独处理，论文也区分残差方程与只用于线性化的稳定化。该文提供替代设计思路，但本地尚未实现四场法，本文核查也未见当前库仑刀片接触任务的直接验收；不能声称换用它即可成功。当前优先完成较小范围的体积空间/稳定化对照，不据此整体换框架或添加任意物理黏性。

本地0.13 mm前缀按用户要求暂停，14态重新装配通过；实际0.12 mm固定场中，去掉压力质量集中只能恢复较小部分体积能，未解析压力空间部分更大。固定场比较没有完成新平衡，不能当作候选力曲线。完整数值证据只保存在本地 `outputs/mixed_validation_20261013/tip_constraint_audit/`。

## 剪切尺度体积方差稳定化诊断

显式选项 `--macro-stabilization-shear a` 只允许用于 `p1-macro-mixed`，默认a=0。所加离散能量为：

`E_stab = a G/2 [Σ_e V_e (J_e−1)² − Σ_i V_i (Jbar_i−1)²]`。

这是基于当前投影的数值候选，不宣称上述文献已经验证这一具体方案适合橡胶切割。投影权重为非负且归一，括号由加权方差恒等式非负，齐次J时为零；所以齐次本构及G/K不变。a=K/G时恢复逐子单元体积积分。a取剪切量级是为了控制未解析体积变化；是否重新引入锁死须用弯曲和细化测试评估，不能靠引入稳定化保证精度。

令 `f=1−aG/K`，修正后的残差和局部切线与剩余压力块一致。稀疏辅助压力系统使用 `sqrt(f) B`，消元结果才是 `f Bᵀ M⁻¹ B`；沿用a=0的B会产生错误方向。该缩放也用于PTC辅助度量；原真实残差验收不变。稳定化进入离散能量，并非只改求解器预条件，因此结果须独立标注，不能混入原零稳定化加载历史。

候选a=1/4采用固定值作机制检查，没有按实验力反演。先检查齐次响应、非均匀能量/导数、稀疏块方向、全积分极限及弯曲，再进行条件平衡和独立短程；没有默认推广到1 mm或3 mm。
