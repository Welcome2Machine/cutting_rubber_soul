## 方法依据与边界

### 2026-09-11：摩擦切换之后的求解设计

**当前开始求解核心重构。** 重构前代码/文档已提交为 `6b5419d`。新增 `contact_ipm` 的二维非关联库仑原始—对偶内点子问题，以及保留真实有限应变残差的外层。子问题固定接触框架，同时求所有法向、切向反力，不冻结摩擦容量为 Tresca。外层步模型的体 Hessian 先检查对称 LDL 正主元；需要时加数值对角项，使用缩放 Gershgorin 界兜底。原残差不含该项，拒绝将不对称矩阵静默对称化。信赖半径及回溯按真实残差的预测/实际下降比接受，不用稳定化后的模型残差夸大预测下降。

内点法在两个锥变量均严格为正的状态中迭代，de Saxcé 修正保留无剪胀条件；Mehrotra 预测—校正和中心 Newton 回退都有预算。当前没有 ANM 或中心路径折返续算，非光滑绝对值仍会影响 Newton 全局化。失败保存内层独立状态和外层锚点，不把内层试值提交为物理历史。该路线仍属重构验证，不能因解析基准通过替代旧失败增量验收；具体结果集中在 solver_status.md。

用户提出极端简化后，先增加 μ=0 的独立法向互补对照；原 μ=0.35 参数保持。第一层固定同一失败锚点、力学近似和接触几何，仅去掉切向接触力和黏滑关系。该层通过只能定位简化子问题的可解性，不能沿用含摩擦历史宣称完成无摩擦加载。下一层须从零位移、零历史生成无摩擦有限应变路径；只有它连续通过后，再逐项恢复摩擦并比较反力与场。无摩擦结果不能用于目标无润滑实验的起裂预测。

**几何拒收先区分平衡误差与空间离散误差。** 加权接触间隙满足互补关系，不保证每个几何点都严格不穿透；而力残差达标也不保证位移已足够准确。新 IPM 外层在整边验收拒收时，最多将内部力/投影求解目标逐级收紧三个数量级，仍受原迭代和时间预算限制。每次复核真实整边几何；材料、网格、物理历史和最终门限均不改变。充分求精后仍超限才将局部细化列为下一对照，不能从一次几何拒收直接断言网格必然不足。该规则源于本仓库同历史回放，不是新的材料模型或文献算法保证。

无摩擦新停点经充分求精仍几何超限，而单条越限边细化通过，下一阶段优先处理局部接触分辨率及网格变化后的历史/验收记录。固定网格基线故意禁止重网格，不能把该诊断策略误认为完整求解器已具备自适应空间推进。局部 P2 插值对照只证明离散敏感性；生产接续前须核查参考几何保持、前态场转移、接触状态初始化和原方程再平衡，并用连续路径检验。若持续依赖极细边界才可满足点值门限，再评估能直接控制局部间隙的接触离散；当前证据不足以先宣称必须更换本构或摩擦律。

**旧辅助路径保留作对照。** 分块迭代及回交原 Newton 均未跨过失败点后，实现 `H(x,a)=R(x)-(1-a)R(x0)` 的伪弧长预测—校正；R 包含完整有限应变体、真实移动接触框架和全部接触乘子。按原 N/MPa 门限缩放残差，列缩放和弧长度量在整条路径内固定。a=0 的初值精确满足辅助方程，a=1 恢复原方程；a 可以折返，但刀具深度、实际时间及物理前态始终不变。这条原残差路线不要求把完整 Jacobian 对称化或体刚度强改为正定，也不继承 R21 内点法的路径存在性结论。

普通伪弧长在当前黏滑尖锐转角仍失败。新增可选切换事件：定位 `|t+kt·slip|-μ·p_return=0`，同时校正辅助方程和该边界方程，随后按进入目标黏/滑分支的符号选择单侧切向。新旧切向可以在所选数值度量下近乎反向，不能强制它们点积为正。摩擦事件限于压紧且切向试算力符号不变的情况；现已另补法向开闭事件 `p+kn·gap=0`，在预测段内与摩擦事件共同选择首先到达的边界。压紧/开离切换同时更新法向返回和滑动摩擦限值对法向试算量的导数，不能只改法向方程行。仅抑制同一数值路径点刚处理过的事件，不用压力阈值屏蔽接近开离的节点。曲面接触的切换梯度及两侧 Jacobian 已以独立差分核对。法向开闭与零切向试算力同时发生的摩擦锥顶点仍需多分支处理，当前明确报出而不使用未验证的单侧方向；未宣称覆盖所有同时切换。方法依据与光滑性限制见 [R24](../references/method_notes.md)。

到达辅助终点还必须通过原方程独立验收；预算耗尽保存最佳原残差试值和最后辅助路径状态，二者分别标记。仅跨过某个数值切换或辅助参数转折不能当作物理增量完成，更不能称为起裂。

辅助路径可从保存末点恢复。恢复时核对物理配置、网格、前一位移/乘子、实际增量、初始残差来源和弧长度量，仍从原始试值重建同伦，不把末点当作新的物理前态或重新平移残差。新检查点保存完整切向以保持折返方向；旧检查点只在日志中的参数切向分量非零时重建方向，并重新检查辅助方程。若从已接受状态另起一条辅助路径，则明确作为不同初值对照，不称为原路径恢复。

已实现独立的非线性分块短测入口 `prototype.contact_partitioned`，尚未通过旧失败点验证，未替换默认主线求解器。依据见 [R17–R23](../references/method_notes.md)。已定位的非根切换面上两侧 Newton 方向均使实际残差上升，说明应改变非线性求解组织；它不证明物理无解。优先顺序如下：

1. **完整非线性分块，而非只改切线。** 内层固定摩擦阈值 `μ p_outer` 与切向框架，求解有限应变体平衡、法向接触及固定阈值的 Tresca 子问题；外层更新法向反力、接触框架并迭代至一致。局部—整体接口参考 LATIN，冻结摩擦参考 IPC。实施前必须推导现有 P2 半边积分、滑移和乘子虚功的对应，验证外层固定点严格恢复原接触方程。若不存在与当前离散一致的内层势，就使用一致的残差/局部关系求解，不能凭空把整个库仑问题称为凸能量最小化。
2. **稳定化先于加速。** 根据体—界面耦合响应设计 Robin/近端项，其在固定点应消失；不能把已验证的几何切线直接删除。先验证内层确实可收敛，再以受保护的 IQN-ILS/Anderson 加速外层，保留普通松弛对照。限制加速记忆并过滤相关历史（当前实现采用 SVD）；接触集合剧变时重置数值加速历史。必要时用位移块伪瞬态或修正 Hessian 生成内层方向，最终仍验原方程。软材料多孔介质文献的系数、正定性及收敛证明不能照搬。
3. **区分失败层次后再替换。** 内层失败就针对体平衡、法向几何及近端参数；内层成功、外层震荡就针对摩擦阈值/框架反馈和界面稳定化。保留精确接触关系的后备研究是 SCD 多值图算法；需要更完整替代时评估 Convergent IPC 的屏障、摩擦势及连续碰撞检测。IPC 要重新验证 P2 曲边几何兼容性或建立独立离散基准，并检查屏障/摩擦平滑参数敏感性。2026 内点路径跟踪现已核查用户提供的全文，适用性判断与新增门槛见下一段。

**R21 全文带来的调整。** IPM-ANM 从摘要级备选提升为有条件的短基准候选，可作为接触内层的另一条路线。先查明当前离散是否具有功共轭的 `H/H^T`、对称正定的力学子问题和 Slater 严格可行性；不能把带移动框架项的 `-C K^{-1} B` 直接当作论文半正定 `W`。若要通过正定近端模型进入论文框架，必须在有限应变外层收敛时恢复原方程。随后做二维开闭/黏滑解析基准和辅助路径转折基准；可先用伪弧长预测—校正验证路线，成功后再评估高阶 ANM 的成本。原文式 (34)、(41)、(48) 及算法伪代码的记号不一致须按 R21 的独立推导校核，不能照抄。原方程切换障碍尚不等于中心路径折返；论文也未证明所有 IPM-ANM 算例都收敛。真实加载及摩擦历史在辅助路径迭代中保持固定，最终仍通过旧失败增量和连续路径验收。

每个物理增量内冻结上一接受状态、实际时间步及滑移历史；所有内外迭代都从同一物理历史计算。只有原力平衡、库仑投影、整边穿透、体积映射及耗散通过时才提交。冻结框架的势、近端项或屏障近似都不能自行成为新的物理验收标准；固定正平滑参数也不能冒充精确黏着。

当前分块实现保留真实法向几何和法向几何切线；内层冻结外层切向框架及 `μ max(p_outer,0)`，以一致残差求解有限应变体。体平衡附加 `α D (u-u_outer)`，D 为体刚度对角绝对值的数值尺度；接触投影使用 `gap-c(p-p_outer)`、`slip-c(t-t_outer)`。其中 c 单位为 mm/MPa，默认取法向增广系数的倒数，α/c 均只用于数值迭代。外层固定点中这些差值全部为零，原法向关系、摩擦框架和库仑阈值恢复。冻结全部法向框架仅作为 `--affine-normal` 对照，不作为实际几何验收。已用曲面二次边有限差分检查完整位移/乘子切线及功共轭关系，并检查冻结与原始映射在固定点的等价性；这些检查不提供全局收敛保证。

外层用最多六个状态构造 Anderson 历史，只以界面变量拟合，所得系数同时更新全体位移及乘子。SVD 过滤后按实际界面更新量限制加速步，再对原方程回溯评估；不在更新后直接截断乘子破坏体平衡。内层达到更严的辅助容差也不自动接受，只能由独立原方程验收提交。运行预算耗尽与方程失败分别记录。它借鉴上述文献的求解组织，并非 IPC、LATIN 或 2026 IPM-ANM 的完整复现。

实施验收依次为：小型黏着/滑动解析基准与内外固定点等价检查；旧 `0.49875→0.5 mm` 同历史故障回归；有完整历史的连续路径跨越失败区并继续推进。日志分别记录内层/外层残差、原残差、接触切换、耗时及稳定化参数。单点通过后再后台运行完整工况，保持日志和状态记录；不以无限加迭代或只多走一个增量作为完成标准。

### 既有诊断与模型边界


失败定位先区分线性解误差、接触分支切换和几何切线效应：对相同历史审计原 Newton 步，记录第一个下降步及切换节点；再比较保留/去掉接触几何切线的凝聚响应，不能用辅助切线替代最终原方程。R15 的有界全分支检查只作可行性诊断，超时及有限范围内不可行都不能证明物理无解。生产修复须在保持原残差和历史的条件下通过失败区与连续路径验证。

进一步要求使用已收敛真实历史作为反例对照：正法向凝聚响应也可能出现在已接受状态，不能独立当作失效指标。R16 的单点切换审计应定位到真实切换面，检查两侧 Newton 方向与实际进入分支是否相容，并用原方程单边差分确认，排除其他同时切换。备用搜索按完整投影的实际切换函数选点，不用滑移量趋零代替；筛选修复本身不证明找到了非线性可行解。

区分局部分支与离散误差时，采用从零载荷独立生成历史的固定网格对照：先比较接触积分阶数，再在同一较高阶积分下改变局部三角形连接。保留每个接受增量的前后位移、接触乘子、实际时间步和网格/配置指纹；不能通过插值旧末态、零增量回放或改变历史来替代对照。单组提前失败或预算耗尽不能证明物理无解；接受状态的谱必须结合原方程复核、位置及路径的一致性解释。

实际约束谱采用非对称广义问题 Jv=λdiag(M,0)v，接触乘子行保持代数约束。既检查最近零的模态，也单独搜索负模态，避免正的全局柔性模态遮蔽局部负值；失败试值的负模态不是已收敛状态的失稳证明。沿模态的扰动只能作固定物理历史的数值初值。用变形梯度条件数、二次边切向伸长变化及局部压力中点对比定位体/表面分辨率问题；细化对照不自动成为生产策略。R13 的修正量线搜索本地未奏效，已撤除。R14 仅支持进一步区分局部折皱与数值软模态，不能据此添加损伤或人为表面硬层。

按用户要求恢复旧 P2 主线，以保留的 0.49875 mm 检查点为基准；FEBio 暂停计算并保留为独立参考。接触分支备用步必须通过原残差下降与独立物理验收。体刚度负曲率仅作为数值线索，后续需检查实际接触约束下的模态，不能把未约束体刚度的负特征值解释为实验断裂。平滑延续、分裂求解、互补函数替换均须经过同历史对照；当前试算没有证明它们解决旧失效，依据与边界见 references/method_notes.md 的 R12。

近不可压缩橡胶的局部剪切/弯曲使低阶逐单元体积约束容易锁死。节点体积平均可改善柔度，也可能产生局部软模式或压力振荡；固定父压力空间在位移细化后也需稳定性检查。P2 完整积分被选为当前 ν=0.49 下的较简单主线，对 ν→0.5 或任意大变形不作普遍免锁死保证。低层比较离散保留作真实失败回归。

[Khandelwal 等](https://arxiv.org/abs/2209.04906) 的二次边界节点和半边一次接触力空间提供参考，但其线性无摩擦假设不覆盖本任务；[Tian 等](https://arxiv.org/abs/2112.00294) 的有限应变混合框架也不能证明一种单元对所有问题最好。本仓库按实际 F、虚功、历史和整边几何独立验证。

修正版 FEBio 优先作为断裂前接触对照：[Zimmerman–Ateshian 模型库](https://repo.febio.org/permalink/project/68)、[官方节点—面接触](https://febiosoftware.github.io/febio-feature-manual/features/solid_surfaceinteraction_sliding-node-on-facet/) 和固定 v4.13 源码支持核查。Hex8 三场体积压力平均与 P2 完整积分不同；解析 patch 和短前缀成功不能替代应力场网格验证。已证实的切线及增广问题见状态页，不能把更多线程或罚参数变化本身称为物理改进。

网格窗口必须由实际坐标映射推导：e_s=(cosθ,−sinθ)，实验室刀具位移 (0,−d)，故 Δs=d sinθ；60° 时应向 s 增大方向细化。旧生成器符号相反，已按此修正，并给可能进入接触的材料点添加显式记录的变形余量。圆弧附近直边的弦高 r−sqrt(r²−L²/4)≈L²/(8r) 给出局部几何分辨率估计；减半网格间距和加密刀尖分面不会替代真实变形后的整边审计。刀尖半径保持原假设，未标定半径的物理敏感性应单独评价。

本地性能调整依据：2026-09-10 核对 [FEBio 求解器说明](https://febiosoftware.github.io/febio-feature-manual/features/solid_solver_solid/) 及 [quasi-Newton 参数说明](https://help.febio.org/Manuals3p2/FEBioUser/FEBio_um_3-2-Subsection-3.3.3.html)，max_ups=0 会逐迭代重建矩阵；非对称摩擦问题可试用 Broyden 有限更新来减少分解，但不保证接触分支切换时必然更快。本地对照中“5 次更新＋加倍增量”的组合因频繁回退反而变慢，因此最终均衡配置保留全 Newton 和原增量；这一组合试验不能单独证明 Broyden 在所有增量下都无效。输出策略按 [v4.13 FEAnalysis 源码](https://github.com/febiosoftware/FEBio/blob/v4.13/FECore/FEAnalysis.cpp) 将绘图场限于最终状态，节点与刚体历史仍逐步记录；缓存仅复用不变的参考几何，不缓存当前变形或省去验收。

若该对照不能稳定且可信推进，再评价 [GetFEM 大滑移](https://getfem.org/userdoc/model_contact_friction_large_sliding.html) 或 FEniCSx/PETSc 分块求解。已查看的 ASiMoV 摩擦圆柱示例采用小应变线弹性，不能直接替换本任务。任何替代都需保持有限应变、真实摩擦、历史与严格验收。
