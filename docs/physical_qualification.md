## 2. 实际材料状态和力学账本

用q30的0°/33°各0.1、0.25、0.4、0.5 mm八个保存场，核对冻结源码、准确材料与摩擦历史，
重新装配原残差。另选185个材料点，包含最强压缩、接触邻接和远场点，检验有限转动、
完整材料切线有限差分、等容黏性度量及非负耗散。检查通过；切线方向误差约10⁻¹⁰量级。
这支持实现与所写方程一致，**不等于这套Maxwell方程和参数已经代表真实CR橡胶**。

令虚位移为实际已接受增量除以竖直深度增量 `w=(x_k−x_(k−1))/Δd`。
刀具上w=(0,−1)，底面w=0。逐项组装验证

`W_eq_iso + W_vol + W_Maxwell + W_contact_normal + W_friction = Fz + r_free·w_free`。

这是同一个离散平衡态的虚功恒等式，不是有限步能量守恒式，也不是改参数后的因果贡献。
八场的闭合误差小于3×10⁻¹³ N，保留了原非零残差对应的功。

| 0.4 mm的虚功/深度，N | 0° | 33° | 33°−0° |
|---|---:|---:|---:|
| 平衡等容弹性 | 3.107743 | 3.059243 | −.048499 |
| 体积项 | .351225 | .440808 | +.089583 |
| Maxwell支路 | 4.159457 | 4.190905 | +.031449 |
| 法向接触势 | .006680 | .008208 | +.001527 |
| 摩擦 | .031392 | .045687 | +.014295 |
| Fz | 7.656533 | 7.744788 | +.088255 |

因此需要检查体积响应、二维约束和局部变形的耦合；不能从“法向接触竖直反力较大”
直接推断接触势本身贡献了同等大小的额外耗能，也不能因表中体积差接近总差就宣称改K必然修复。

0.5 mm局部minJ为0.50064/0.45726，但全体积加权平均J为0.999470/0.999439。
33°的J<0.5只占初始总体积8.33×10⁻⁸；接触邻接单元平均J为0.91896/0.92672。
这些统计不能掩盖刀尖局部严重压缩，也不能把最坏单元说成整块材料体积损失。
当前证据不足以判定二维约束、体积能或P1离散各占多少误差。

### 进一步直接检验K，避免误把账本当原因

对两角度的0.4/0.5 mm，使用原完整非对称切线（无PSD投影、无PTC移位），
求解 `A_ff u_K = −∂r_free/∂logK`，再计算刀具反力导数。
四次PARDISO均无回退，原线性相对残差约3×10⁻¹⁴。
在logK扰动10⁻⁴、10⁻⁵、10⁻⁶的条件试探场中重新装配，反力差分支持下列数量级；
0°最小扰动受离散数值噪声影响，误差最大约0.75%，不宣称任意精度的导数收敛。

| 深度mm | 0° dFz/dlogK，N | 33° dFz/dlogK，N | 角度差的导数，N |
|---|---:|---:|---:|
| .4 | .517690 | .617864 | .100175 |
| .5 | .713571 | .806914 | .093342 |

这意味着在.4 mm，K变化约1%，Fz条件变化约.0052/.0062 N，角度差仅约.001 N；
当前FE与实验的角度差偏差约.558 N。**不支持靠小幅K调整消除当前偏差。**
这些是固定上一接受材料/摩擦历史时的瞬时条件灵敏度，并非重新跑完整历史的参数导数；
不能外推到K的大幅变化，更不能证明改变体积能形式、二维约束或压力离散没有作用。
试探方向、双历史、微扰残差和哈希保存在同一报告目录，没有接受新的加载状态。

## 3. 接触检查及已经写出的局部修正

在八个真实承载几何上，令全部接触表面共同刚体转动，保持形状、间隙和法向承载不变。
原生摩擦仍产生非零摩擦功；例如33°/0.5 mm共同转动0.01 rad时为7.6253×10⁻⁵ N·mm，
摩擦梯度范数1.6199 N。这是施加的运动学检查，不是实际加载中1.62 N的Fz误差。
实际该场摩擦内力合力矩约−.003240 N·mm；法向势力矩约机器精度零。
有限间隙客观性限制在真实接触几何中仍存在，但尚不能认定它解释全部实验差异。

`prototype/contact_controls.py::objective_edge_contact`现在将原局部滑移核补全为力与完整刷新切线：

- 对持续同一材料主边：`s=L(β−β_old)`，包含滑移的一阶、二阶几何导数。
- 摩擦力用 `μ N f′(s) ∇s`；切线包含正常承载更新、滑移正则和几何二阶导数。
- 有限间隙下保留主边上的力矩修正，而不是只改滑移数值、继续用旧的力分配。
- 检验共同有限转动、平移、纯法向运动、固定材料投影的边伸长、非零滑移协变、合力/力矩平衡，
  并用独立有限差分核对完整非对称切线。

本轮80项相关回归通过，无跳过，其中6项是新增局部接触力测试。
在真实场适用的局部对上，修正后的摩擦力矩降至约10⁻¹⁶ N·mm。

**这不是完整模型修复。** 函数只接受正权重、旧/新投影均严格位于同一条边内部的接触；
端点VV、跨边历史和带符号组合修正明确拒绝。八个真实场均仍有不覆盖的交互。
例如33°/0.4 mm仍有VV和跨边历史，不能绕过它们接入主线。
候选集合的计数包括可能的零权重项，不把计数当承载比例；报告另保留绝对权重承载量，后者也不是宏观力占比。
负组合权重不能直接当负接触面积，也不能像此前那样独立删项破坏力连续性。

在冻结场上只替换适用局部项，0°/33°的0.5 mm刀具竖直力差分别为−.4212/−.0792 N；
未重平衡、未处理其余项，**不能相减得出“修正后的Fz”**。这甚至没有直接支持“该修正必然恢复角度排序”，
所以它的资格依据是运动学和虚功，而不是朝实验数值方向变化。

## 4. 文献核对及下一步实现边界

以下为定向核查，不是系统综述，也没有把方法名称当作本项目成功证据。

| 来源与阅读范围 | 可参考之处 | 不能据此声称 |
|---|---|---|
| [Kratos官方摩擦接触说明](https://kratosmultiphysics.github.io/Kratos/pages/Applications/Contact_Structural_Mechanics_Application/Theory/Frictional_Contact.html)，搜索服务返回的官方正文；直接打开404 | 客观滑移需要当前/历史投影算子，局部速度投影不足以覆盖有限滑移 | 本轮实现了完整mortar或该库可直接跑当前材料 |
| [Du等，No Free Slide作者稿](https://crl.ethz.ch/papers/DeformableContact.pdf)，摘要、第3节及平滑表面讨论 | 分片接触可引入数值切向力；法向表面和切换必须同时检查 | 论文无摩擦，不能当现有库仑问题的直接解法，也不证明当前内核有力跳变 |
| [Li等，Convergent IPC作者摘要](https://arxiv.org/abs/2307.15908) | 接触离散应从连续势出发并验证空间收敛 | 单独增多刀鼻面片就足够，或其结论直接否定当前improved-max |
| [MOOSE官方摩擦mortar实现](https://mooseframework.inl.gov/source/constraints/ComputeFrictionalForceLMMechanicalContact.html)，方法及参数说明 | 加权法向间隙、加权切向速度、黏滑活动集及一致线性化可用作实现参照；边界贡献不能漏掉 | 官方也标为preliminary，不是迁移后必然稳健的承诺 |
| [Menga等2021作者摘要](https://arxiv.org/abs/2006.16133) | 有限厚度与固定基底可使法向/切向响应耦合 | 薄层粗糙滑动不是本刀具实验，不能定量证明本次33°反转 |

接下来的接触修正应以**连续表面材料坐标和当前/历史投影算子**为单位处理，统一法向、摩擦、端点和跨边历史，
而不是继续给单个EV或VV加开关。保留完整CCD与真实体积/残差验收；局部核作为应满足的极限测试。
材料和K保持共同值，先把接触表示改动的影响隔离出来。

进入长验证前必须依次满足：

1. 零相对运动/共同转动、力与力矩、法向压缩、真实滑动和耗散测试；跨边/端点力连续、历史身份连续。
2. 完整接触残差与切线的方向差分，法向/摩擦切换的两侧检查；不通过则保存反例并停止该候选。
3. 自己的新源码和从静止开始的双历史，小范围独立FE验算与新鲜审查；不把旧模型历史冒充新模型完整前缀。
4. 接触的空间/步长敏感性、失败位置与相邻连续增量通过，才启动有界更长路径；不放宽原残差、J、CCD、耗散和预算。

当前停在第1项的**完整表面覆盖**，没有合格的全局修正模型。因此本轮不新开长队列，
也不把局部核测试通过写成57°已修复。共同材料真实性、二维约束和体积离散还需在合格接触基础上继续分离验证。
