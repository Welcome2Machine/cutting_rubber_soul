# 当前任务要求

## 研究目标与范围

以同一套材料、界面和边界描述 0°、33°、57°橡胶斜向压入的 Fz—竖直刀具行程、表面运动和接触材料身份迁移。当前目标行程严格为 **2 mm**；不计算 3 mm，不启用断裂、损伤、CZM或裂后演算。实验断裂深度可用于查询理论接触材料位置，不在该深度切换模型。

各角度使用同一块或同属性橡胶；不按角度分别拟合材料、有效宽度或力倍率。实验浅层角度曲线允许短暂交叉，0°与33°早段接近本身不是模型缺陷。57°参与选参，不能称为独立验证。

## 数据与物理约束

- 授权力数据为 `docs/1008n0a2__Fz__curve_1.csv`、`1008n33a1__Fz__curve_2.csv`、`1014n57a1__Fz__curve_0.csv`。保留试次身份、原 N 值和零点，只作 μm→mm 单位转换；57°保留导出的 0.51 N 初值，不任意平移。用户确认同工况重复曲线可用，但文件身份不可改写。
- 后段已裂。0°约 1 mm 的估计来自 a1，不能直接赋给当前 a2；33°约 1.2–1.3 mm，57°未知。早段也不自动认证全部未裂；数值失败与斜率下降不能单独作为起裂判据。
- 底面粘接或夹紧、基本不滑动；前 0.5 mm 刀刃全宽紧密贴合。约 1–3 mm 下压时，沿刀刃宽度单侧外鼓不到约 1 mm，是定性观测，不是局部应变上限或位移硬约束。
- 光流只作辅助手段，不能阻塞力学主线。先筛选 `valid=1`；初态比较另需 `reference_frame_id=0`。实验室标定、机械首触及力—视频同步未确认时，不作假定。旧 V01 等原力通道不参与标定。模型接触估计不是直接观测真值。
- 区分参考材料位置偏移、当前位移与累计相对滑移；接触无解或多义时保留缺失/区间。

## 数值验收

保留真实自由力残差 ≤1e−4 N、正 J、完整刀具/本体 CCD、固定边界、非负耗散及准确双历史。材料内部变量与摩擦上一位置只在物理步接受后提交；PTC辅助时间不是材料时间。独立重组审查使用实际物理 Δt 和完整历史链。

当前基线与其割线→仿射同增量恢复一起固定，不将参数相同误当求解控制相同。每次尝试最多500次，原停滞和墙钟限制按显式运行配置执行。失败状态不提交、不能跨角度或跨物理签名恢复。
