## 起裂与切割预测

1. 不得把起裂点或裂纹路径预先固定在刀尖正下方；搜索整个试样，包括表面、内部和固定端附近。
2. 输出最大主应力、主伸长/应变等全域场及极值位置，并区分参考坐标和变形后坐标。应力度量必须与强度标定一致。
3. 预测首次可能起裂的位置、时间/位移区间和方向；区分单元尖峰、空间平均候选、损伤起始和实际裂纹扩展。
4. 最终模型需要描述自由裂纹萌生与推进，以及裂后刀具接触。仅有最大应力阈值筛查或预设 cohesive 界面，都不是任务完成。
5. 用实验的 Fz/Fx、压入到切割的刚度变化及可获得的裂纹图像交叉验证。不人为规定力曲线、裂纹出现时刻或为了匹配曲线随意改变材料参数。

## 文献与实现

对于反复失效，先用同一检查点、物理历史和离散配置定位可复现原因；确有装配、历史或求解缺陷则继续修复并验证。如果只能观察到停滞而无法证明根因，转向搜集并评价更成熟的有限元求解方法或计算框架，不继续把单次延后失效称为问题解决。替代方案同样需要保持目标物理、公开适用边界并通过独立对照。

查找当前前沿及必要的基础文献，优先出版方、作者预印本和官方代码；记录检索时间、查询、证据范围及选型理由。保留用户提供的 `references/2.pdf`，可以补充有用的公开论文。不同材料和斜切角定义不可直接移植。

先明确方法能否描述有限变形、近不可压缩性、强度与断裂能的独立作用、接触/摩擦、裂面形成和必要的耗散，再开展实现。数值测试、网格/步长敏感性与实验验证分开报告。当前路线与分阶段验收见 [建模路线](modeling_roadmap.md)。
