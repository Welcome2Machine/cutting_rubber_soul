## 为什么换离散结构

此前的材料形状和宏单元体积稳定化检查不能唯一解释早期反力曲率；单纯加稳定化系数也不能保证刀尖局部J准确。前一轮P2/P1补丁表明位移/压力空间会改变局部解，但其边界由旧场规定，不能当作新的接触平衡曲线。

采用 [Karabelas等，2020，§3.3–3.4及附录1.3](https://link.springer.com/article/10.1007/s00466-019-01760-w) 的MINI富集和内部自由度消元思路；其研究以三维单元/基准为主，不是本项目的直接复现。[Fu等，2025，§5.1](https://arxiv.org/html/2503.00989v2) 讨论了标准二维三次气泡MINI空间。这里实现二维平面应变版本，不采用四场主方法，也不继承文献平台的速度结论。

## 新离散与求解结构

每个原三角形的位移为：

`u(X) = Σ λ_i(X) u_i + 27 λ_1 λ_2 λ_3 b_e`。

`u_i`为原顶点位移；`b_e`为两个单元内部位移系数。气泡在所有边上为零，故IPC边界、面积权重、摩擦历史点和刀尖参考材料点定义都与原网格一致。内部系数不是新增真实材料节点，也不是可接触点。

压力采用同一原网格连续P1和一致质量矩阵：

`Π(u,p) = ∫ W_iso(F) dV + ∫ p(J−1) dV − ∫ p²/(2K) dV`。

`b_i = ∫ N_i(J−1)dV`，`M_ij = ∫ N_i N_j/K dV`，每次残差求值均精确解 `Mp=b`。因此非线性迭代采用消压力后的能量及真实残差，压力没有独立摩擦历史。p是体积比J的功共轭标量，不是刀面接触压力。

切线保留局部等容/压力几何项和非局部 `BᵀM⁻¹B`，但不形成稠密全局Schur矩阵。PTC增量系统为：

```
[ L + τ L_metric    Bᵀ           ] [δu] = [−r]
[ B                −M/(1+τ)      ] [δp]   [ 0]
```

该系统与物理切线加辅助度量移位严格等价。逐单元消掉2×2内部气泡块，求解顶点/压力系统后恢复内部增量。允许摩擦引起的非对称切线和可逆非正定气泡块；病态局部块回退完整稀疏系统，不用伪逆掩盖奇异。最终重新计算未移位物理方程残差，不能用线性求解成功代替加载态接受。

实现：`prototype/ipc_mini.py` 定义位移空间；`prototype/pressure_pairing.py` 共用一致压力积分；`prototype/mixed_system.py` 做消元/恢复；原IPC宿主显式接入新分支。P2诊断保留原公开接口，避免复制压力实现。

装配不再先得到全体积单元矩阵再二次修正，而是在积分点应力/切线层直接替换压力项，一次映射到单元自由度。压力耦合先在每个单元内积分再稀疏散布；积分点临时量分块分配。独立的原式 `bulk()+correct()` 保留作数值对照，防止提速引入另一套力学方程。

## 安全、状态与观测

2026-10-14更正：下述多项式正性推导是在精确算术下成立，本地浮点解析检查并非区间算术严格证明。实际失败试步已复现位移变量中正、回写绝对坐标后因舍入变负。现在PTC检查实际存储端点，并把富集元极小几何步长(<1e−6)转为可回退失败；几何步长<1e−3且残差改善不足1%时重试更稳定的方向，<.25时不因小模型误差继续降低移位。所有门限是求解控制，不改变最终J>0和1e−4 N验收，也不替代积分精度。只对富集元启用，默认P1公式不变。固定阶数积分仍可能漏掉局部近翻转区；本轮未实现R53的自适应求积和区间保证，候选未取得深段生产资格。

本轮后续增加内部边二分诊断 `--interior-refinement-levels 1/2` 与参考半径：原边界节点/边完全保留，仅增加内部节点和过渡三角形，无悬挂节点。这不是接触表面细化，也不宣称全域收敛。网格设置写入运行元数据，续算仍逐位核查参考布局。

混合线性求解增加可选 `--linear-solver reused-lu`，只将旧LU用作当前系统的GMRES预条件器；实际短程没有获得总体提速，深度研究继续选择direct。在两级细化中发现：即便新LU的混合系统残差约1.55e−12，消压力后的物理残差仍可能约2.02e−8 N，超过原1e−8 N线性门槛。小单元压力质量矩阵会放大压力方程的后向误差，故现在对**原位移凝聚残差**作至多两次稀疏残差修正；实测该例降到2.18e−12 N。没有放宽力学验收或改变PTC物理方程。该修正处理数值求解精度，不能解释实验曲率。

- 三次气泡使F为空间二次函数，但 `F=F_linear+b_e⊗∇bubble` 是秩一增量，在二维中J仍为空间二次函数。因此检查整个参考三角形的精确最小J，结合时间Bernstein系数保证直线更新的全路径J正性；不能只检查顶点或积分点。
- IPC仍对真实边界做CCD、非相交与正间隙验收；真实自由力残差门槛仍为1e−4 N，包含内部系数残差。摩擦功检查保持不变。
- 保存布局为“真实顶点；内部气泡系数；刀具顶点”。内部行的参考值和仿射加载增量为零，不能解释为空间坐标；`mini_*`元数据标识布局，续算核查内部系数及前态。压力可由保存的完整位移/系数场确定性重建。
- 刀尖接触追踪仅使用原上表面边，内部气泡不进入观测。参考材料点迁移仍不等于累计滑移。
- 旧P1可视化器不能直接渲染气泡内部曲线，应使用显式采样重建；当前CLI要求 `--no-visualize`，避免给出错误的P1内部应力图。旧版可视化不受影响。
