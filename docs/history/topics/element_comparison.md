## 选用的对照

原模型是 P1 三角形位移单元。新增 `--element p2-interior`：同一批参考三角形的每条**内部边**增加独立中点位移；外边中点位移精确约束为两端平均。于是内部使用 P2 插值，外边保持原 P1 插值。它是连续、相容的受限 P2 空间，包含原 P1 位移空间；不是 P2/P1 混合元，不声称在不可压缩极限免锁死。

选择理由：IPC 使用分段直线碰撞边。直接放开所有边中点，会同时改变接触面分片、接触权重及摩擦离散，难以隔离体内离散的影响。本轮保留全部外边原节点、线段、CCD、屏障与摩擦实现，仅丰富内部位移。外表面曲率误差仍存在，结果接近也不能排除表面离散问题。

二次三角形基函数参考 [DefElement 的 P2 Lagrange 三角形](https://defelement.org/elements/examples/triangle-lagrange-equispaced-2.html)。外边中点消元是本项目为了对照而施加的离散约束，不是该资料认证的切割方法。[COMSOL 混合公式说明](https://doc.comsol.com/6.3/doc/com.comsol.help.sme/sme_ug_modeling.05.101.html) 解释近不可压缩位移离散风险及混合元稳定性要求，不能作为本次切割已确认锁死的证据。

## 2026-10-06 性能排查

原高阶运行并非死锁：在 0.01 mm 重试很多，但试步比例一直为 1，残差继续下降，最终接受了该深度。不能把缓慢下降说成已保证后续收敛。原位移阶次提高使局部非线性响应改变，旧 PTC 算法需要较强稳定化；此次没有更改其物理残差、稳定化更新或验收门限。

在生产网格、同一个 0.01 mm 初始预测态上做耗时剖析，原未投影装配 9.154 s、投影装配 9.538 s、稀疏求解 3.806 s、一次试步力计算 0.979 s。主要开销是重复体内装配与低效张量收缩，而非 IPC 接触碰撞。已实施三项等价优化：

- P2 切线改成分块的两阶段张量收缩，保持全部 16 个积分点。
- 同一次材料计算生成精确切线与投影辅助矩阵，避免重复积分；不在不同位置或摩擦历史之间缓存。
- 求解用材料响应跳过未使用的应力场诊断，保持 P、能量、J、切线；应力输出接口默认仍返回全部字段。

同态复测配对装配 3.212 s、原稀疏求解 3.861 s、试步力计算 0.490 s，合计约 7.6 s，对照原约 23.5 s。该状态力残差完全一致，最大方向分量差约 1.3e−15 mm；速度是单次工作量实测，不是整条加载路径加速保证。MMD 稀疏重排序测试明显更慢，已舍弃，保留原 COLAMD。之后日志新增 `PERF_BEGIN`、`PERF_ASSEMBLY`、`PERF_RETRY` 区分装配、线性求解与试步力计算耗时。

材料源文件因输出优化产生新哈希，不能伪称源码相同。启动工具仅对这两个文件允许带证据的等价变更：从原基线冻结源码加载旧本构，在 128 个确定性的有限变形状态下比较 P、能量、J、切线（本轮最大差均为 0），记录旧/新哈希；几何和网格源仍要求哈希一致。另有快路径导数、非仿射 P2 新旧收缩、配对装配一致性测试。完整测试记录与局部计时在本地保留。

### 装配优化后仍慢：接触非线性与重复分解

进一步审查优化版日志的一个片段：43 次装配、66 次线性求解、24 次拒绝，累计装配 173.5 s、线性求解 358.3 s、试步力计算 44.45 s。线性求解占这些已计时项约 62%，不代表包含全部开销的占比。多数拒绝试步已降低力残差，但未满足原局部模型误差保护；不能直接放宽保护来宣称修复。

对保存的 0.02 mm 未接受态，分解完整 Newton 试步相对于线性模型的力误差：体内 0.005806 N、法向接触 0.244676 N、摩擦 0.085637 N；总误差 0.258198 N（向量相加，不是三个范数之和）。法向接触配对集合有 17 项变化。将同方向缩短至 1/16，法向误差降至 0.001119 N，配对变化降至 1 项。这个状态下主导误差来自法向接触响应，支持接触变化迫使 PTC 反复稳定化的判断；不能推断所有状态均如此，也不能据此宣布离散错误或材料错误。

新增 `--linear-solver reused-lu`：每次仍组装当前矩阵 `(A+shift*M)` 与当前力，只将同一加载步内以前的 LU 作为 GMRES 预条件。每个新加载步清空缓存。GMRES 最多两个 16 维循环，`rtol=1e-11, atol=1e-13`；时间预算为前次分解时间的一半、最低 0.05 s。非收敛、超时或真实 `b−Ax` 残差不合格时，重新 COLAMD 分解当前矩阵。所有返回解还须满足 `||b−Ax|| ≤ max(1e−10||b||, 1e−12 N)`；必要时直接解做最多两次残差修正。缓存绝不代替新方程，PTC 更新与 1e−4 N 非线性验收不变。

依据 [SciPy GMRES 文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.sparse.linalg.gmres.html) 的左预条件与真实残差验收定义，以及 [splu 文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.sparse.linalg.splu.html) 的分解/重复求解接口。该方法减少重复分解的成本，不保证降低非线性迭代数或解决全程收敛。日志 `LINEAR` 记录求解类型、迭代数、分解/求解耗时、真实线性残差及回退原因。

实际生产网格的同一 0.02 mm 未接受试算态，限定三次非线性更新：两组均有九次试步，残差轨迹相同（0.005324→0.004164 N），最大位置差 3.55e−15 mm。直接法总耗时 53.71 s、其中线性 34.34 s；复用法总耗时 33.30 s、其中线性 13.69 s。九次线性求解为一次分解加八次成功复用，最大真实线性残差 3.42e−14 N。总耗时降低约 38%，仅适用于该段同态测试；两组均因三次诊断预算结束，**不是已接受的加载步**。证据在本地 `ipc_element_study_fast_20261006/diagnostics/bounded_reuse_comparison.json`，不上传数值数据。

P2 接受前缀可通过 `--resume` 续算；核对离散、积分、参考网格、逐态边界规定位置、历史链及源指纹，并用末态原摩擦历史重新装配验收。不会恢复未接受试算态，也不从 P1 解生成 P2 历史。

## 数值核验

使用正权重 Duffy/Gauss 4×4 积分；本构为非多项式，不能声称有限个积分点给出精确能量。后处理在选定接受态用 6×6 重新装配，报告能量和体内力差；这不是重新平衡后的 Fz 误差估计。

P2 的 J 在三角形内是二次函数。每次检查其整个参考三角形上的最小值，不能只检查高斯点。步长保护使用时间方向三项 Bernstein 系数：三项均作为空间二次多项式检查正最小值，保证整条直线路径正 J，而非仅检查终点；该条件保守。

`tests/test_ipc_p2.py` 覆盖：积分多项式、有限仿射变形能量与旋转客观性、能量/力/切线有限差分、P1 子空间能量和力回映射一致性、原外边线性插值、隐藏中间翻转、刚体之外无额外零能模态、原生接触一致性、含摩擦有限压缩反力、检查点与渲染保护，以及对照数据校验。

同一细长梁小载荷平面应变验证（ν=0.49，解析弯曲+剪切参考）得到柔度比：P1/h=0.5 为 0.09538，内部 P2/h=0.5 为 0.91051，内部 P2/h=0.25 为 0.97318。这验证本离散能缓解该基准的过硬，并显示细化改善；不直接证明切割误差均来自锁死。

## 如何解释

若新离散明显改变 Fz 曲率，同时物理参数一致、接受态满足门限且积分审查合理，说明体内离散对偏差有实质贡献；仍需区分体积锁死、弯曲近似和局部形变分辨率。若变化小，说明仅增加内部自由度没有消除差异，不能反推材料、边界或接触已经正确。

后处理的初步积分筛查阈值为相对能量差 <0.5%、装配体内力差范数/Fz <1%。这仅是筛查，不是 Fz 精度证明；未通过时须增加积分并重新平衡，不能将该条结果当作已经收敛的高阶参考。即使通过，也不能把一次 P1/P2 对照视为完整网格收敛研究或实验验证。
