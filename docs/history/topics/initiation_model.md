## 材料与体单元

新增主线方案由 `quadratic_full` 和 `quadratic_integral` 选择。六节点 P2 三角形使用七点正权重积分，直接将实际 F 输入共享材料内核。平面应变嵌入 F33=1，参考体积为侧面面积乘 20 mm 厚度；全程有限应变，不是线性小变形。

当前 CB245NE 仍为给定 G=0.66 MPa、K=32.78 MPa 的弹性极限：

```text
W(F) = G/2 * (J^(-2/3)*trace(F^T F) - 3) + K/2*(J-1)^2
F = I + gradient(U), F33=1
```

等容能和体积能均完整积分，体积压力为 K(J−1)。输出 Cauchy/第一与第二 Piola 应力均来自同一实际 F，没有节点平均或压力投影修正。对二维 P2 位移，J 是二次多项式，体积能是四次多项式，七点规则可准确积分该体积项。等容项仍需空间/积分收敛检查。

独立平面应变梁基准在 ν=0.49、父单元 h=0.5/0.25/0.125 mm 时，完整积分 P2 的柔度分别约为含剪切修正参考值的 97.74%/98.83%/99.14%，原 P1 有明显锁死。因此对当前 ν 选择较简单的完整积分 P2；这不是对 ν→0.5、任意网格和所有大变形的免锁死保证。

材料内核对这一 Neo-Hookean 平面应变特例使用等价闭式计算，并与通用谱分解在随机有限变形上逐项核对。其他 Ogden、平面应力与 2023 论文材料仍使用通用内核，不移植 EPDM 参数。

除积分点检查外，在每个单元的顶点、边驻点及内部驻点求 J 的精确最小值；任一点 J≤0 均拒绝试值，不裁剪 J。

## 刀具接触

`quadratic_integral` 的位移沿整条边二次插值，法向/切向牵引在两条半边上连续一次插值。顶点、中点都有乘子，每半边四点 Gauss 积分，共八点；牵引形函数非负。正参考面积权重为每条边面积的 1/4、1/2、1/4，共享节点累加。当前刀具几何、法向及一致导数仍用解析圆弧和刀面。

对乘子形函数 N_i：

```text
w_i = integral(N_i dA0)
g_i = integral(N_i * penetration dA0) / w_i
s_i = integral(N_i * relative_increment . tangent dA0) / w_i
p_i = max(0, lambda_n_i + kn*g_i)
tau_i = clip(lambda_t_i + kt*s_i, -mu*p_i, mu*p_i)
p_i-lambda_n_i = 0; tau_i-lambda_t_i = 0
```

平衡方程使用独立乘子牵引，虚功和摩擦耗散使用同一积分与插值。μ=0.35、kn=kt=250 MPa/mm；增广参数不是材料刚度。连续非负一次牵引还保留半边内部的非负法向力和库仑锥。此实现是边界积分接触，不宣称复现 dual mortar 或继承其收敛定理。

粗 P1 乘子只对二次边界施加两个平均条件，会留下未约束的边界变形；半边 P1 空间增加中点乘子，使其与 P2 边界自由度匹配。与节点集中接触相比，积分合力分配到全部位移节点，而不是仅在采样节点施力。

弱条件不能代替几何验收。对整条当前二次曲边搜索圆刃距离驻点，并利用有符号距离的 1-Lipschitz 上界递归检查未采样区间，确认穿透不超过原有 1e-4 mm。不能证明满足时保守要求细化。

`quadratic_nodes` 是独立对照：在二次顶点和中点施加接触，使用每条边面积的 1/6、2/3、1/6 的正 Lobatto 权重计算力和功。仍采用完整积分 P2 体材料，仍检查节点之间的整曲边穿透；不能将节点约束通过等同于连续边界无穿透。

## 求解、细化与真实历史

原始接受条件不变：自由力残差 ≤0.001 N，未加机器精度分支保护的接触投影缺陷 ≤0.001 MPa，整边穿透 ≤1e-4 mm，非负法向力、库仑锥、有效 J 和摩擦耗散检查。构造可行乘子候选后重新检验原方程，不把剪裁或优化器返回当成成功。

采用稀疏牛顿、按实际容差归一化的残差回溯与有界阻尼方向。连续加载使用已接受路径的割线初值；失败仍回到原状态求解或细分增量，不跳过。

预测步、细化试解和重启中的有效失败试值按原方程误差排序，避免丢掉较好的近似平衡。接触几何重启可将正压力节点移回刀面，但只改变初值。完整积分 P2 还可用稀疏消元保留全部接触，只枚举最多六个不确定节点的开离/粘着/双向滑移组合；最多两组选点、每组 4096 种组合、八个预测解。所有预测解都必须重新通过原非线性方程。此有界搜索不保证找到全部分支，搜索失败也不等于物理上没有解。

检查点接续的目标位移按机器精度合并浮点重复值，防止同一位移被作为近零时间增量提交；不同的真实加载增量仍保留。

参考网格为连续尺寸场布点及 Delaunay 三角形，细化用最长边相容二分，然后重新生成 P2 中点。新节点精确插值旧父单元的二次位移场，共享节点一致性额外检查。初始局部细网格围绕首次接触处，但没有预裂纹，也不限制全域候选搜索。

空间细化同时保留两组独立数据：上一物理状态用于滑移参考；刚求出的粗网格平衡试解只作为细网格初值。两者分别插值，不把试解提交为新时间步，不把网格变化计成额外加载。检查点保存二次连接关系，恢复后不会误按线性三角形解释位移。

积分点 J 范围曾作为自动体网格细化的启发式指标，但接续对照没有改善连续稳定性，该选项和自动触发代码已删除。保留显式局部体网格细化供受控比较；它不改变允许的物理 J 范围，也不是应力误差估计。生产路径只按独立曲边穿透检查请求接触细化。

## 输出与断裂边界

每个单元的七个积分点均参加全域主应力、主伸长和名义强度筛查。结果记录采样编号和所属单元；旧的 centroid 字段在二次模型中代表采样坐标，另有明确 sampling 元数据。位置图显示每单元最大强度比，峰值标记使用实际采样坐标。空间平均先取积分加权单元均值，再做参考体积加权邻域平均。

`to_candidate` 在首次全域名义强度达到 4.4 MPa 或 3 mm 上限停止，默认将首次超限位移区间细分到 0.0001 mm；该区间不是空间精度。没有自由裂纹演化，也没有预先固定起裂位置。局部积分点极值仍需网格检查，缺失的多轴强度、高阶硬化、松弛和断裂能标定不能由求解收敛代替。

完整运行入口为 `python -m prototype.start_initiation`，后台保存日志、PID、配置、源码、状态和候选，只检查一次启动。实际默认方案和验收范围见 solver_status.md。

## 保留的比较与文献边界

原 P1、节点体积平均及稳定化是失败回归对照。P1-iso-P2/P1 与 P2/P1 一致压力混合元也保留为显式比较：压力由混合势精确消元，线性压力块与完整 Schur 算子一致，但部分网格存在明显局部 J/压力投影差异，不能据全局力残差推断局部应力准确。

逐点压力投影误差门限、增广位移外迭代、仅接触 Schur 阻尼均未通过各自有界探索，未作为主线修复保留。必要数据与 tests/fixtures 仅留本地，不随远程发布；当前代码不以这些尝试宣称稳定。

[Khandelwal、Porwal、Wadhawan 2022](https://arxiv.org/abs/2209.04906) 第 3 节在二次顶点和中点施加单边约束，并定义半边一次接触力空间；该文是线性无摩擦问题，本项目曲面有限应变干摩擦的积分扩展需独立验证。[Tian 等](https://arxiv.org/abs/2112.00294) 比较近不可压缩有限应变混合 P2/P1 与 Q1/P0，其算例偏向 Q1/P0；不能引用为本项目某种单元普遍更优。

[GetFEM 接触文档](https://getfem.org/userdoc/model_contact_friction.html) 提供节点与弱积分投影的参考；当前构形几何另参照[大滑移文档](https://getfem.org/userdoc/model_contact_friction_large_sliding.html)。本仓库一致切线、功、历史和连续路径测试独立承担验证，不继承文档中不同假设下的结论。
