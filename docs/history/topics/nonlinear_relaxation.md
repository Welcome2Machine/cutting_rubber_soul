# 共同材料的非线性松弛筛选（2026-10-16）

> Historical technical record. Obsolete outputs were retired on 2026-10-20; summary links do not include the original figures or full replay histories. See [current research status](../../research_status.md).

目的：判断同一套材料律在30°与60°不同的变形历史下，是否能减少30°过高的响应，保留60°现有的匹配。不得按角度分别拟合材料。本轮先做已完成0–.5 mm路径的材料历史回放；这不是新的有限元力曲线，也不包含断裂。

## 模型与依据

保留现有候选的G∞=.14、Gv=1.24 MPa、τ₀=1.7 s、K=23.34333333333331 MPa，以及原α=2、接触、刀具、固定底面和平面应变。此套模量和松弛时间仍是探索性假设，未被独立材料试验识别。2023复现和主线默认不改。

以支路Kirchhoff偏应力s及其Frobenius范数定义等体积黏性流动：

    c = 1/(2 Gv τ₀)
    dᵥ = c [1 + (s:s)/s₀²] s
    D = s:dᵥ = c [s:s + (s:s)²/s₀²] ≥ 0

支路应力较大时黏性流动加快；小应力线性化仍是原来的松弛时间。应力尺度s₀用MPa，取∞（原模型控制）、2、1、.5、.25 MPa，两个角度共用，不在看到结果后增加扫描范围。

这是文献框架下的简单光滑候选，**不是Bergström–Boyce完整复现**。Reese–Govindjee（1998）§2.1式20–25允许正的状态相关黏度，§3给出有限应变指数返回映射。此处选择的二次应力加速项是项目明确提出的假设；论文没有证明本橡胶采用该项，也没有提供本试样参数。

来源：[原论文全文](https://giref.ulaval.ca/~deteix/bois/documents_references/article4.pdf)，[出版记录](https://doi.org/10.1016/S0020-7683(97)00217-5)。Bergström–Boyce（2001）的平衡/非平衡网络及多轴响应仅作方向依据：[出版摘要](https://doi.org/10.1016/S0167-6636(01)00070-9)。

局部隐式积分：e−e_trial+Δt dᵥ(s(e))=0，保持原有限应变逆黏性度量。双势Ψ*=c(|s|²/2+|s|⁴/(4s₀²))为凸；收敛时原势Ψ=s:dᵥ−Ψ*=c(|s|²/2+3|s|⁴/(4s₀²))。增量势为W_eq+W_v+ΔtΨ，不能照搬原模型的半耗散表达式。代码对势导数、应力、一致切线、客观性、等体积流动、保载能量下降、小应变极限及时间细化做独立测试。

## 预先确定的证据链与退出条件

1. 独立模块通过上述物理检查；∞尺度必须复现现有材料核。
2. 逐一核查输入哈希，完整重放两角度各51态。候选从同一无应力初态出发，随后传播自己的材料历史，不在每一步借用控制材料的内部变量。控制重放须恢复保存的度量与应力。
3. 用原路径增量作为虚位移，计算ΔQ=∫(P候选−P控制):∂F/∂d dV。报告Q=Fz控制+ΔQ为**固定变形历史的虚功代理**；原几何不再平衡，它不是候选接触反力。记录自由节点残差改变，禁止将该代理当成求解完成。
4. 在.25和.5 mm同时要求30°代理降低至少15%，60°代理变化不超过5%，才值得进入共同材料的新有限元短程验证。阈值是成本筛选，不是实验误差界。还要检查角度比，而非只比较绝对降幅。60°原始实验CSV及30°截图估读直接保留作上下文；浅段匹配不能声称解释完整2 mm。
5. 若无候选通过，不启动昂贵新队列。记录否定证据与适用范围；不能推广为所有非线性材料律无效。对最接近筛选的一个有限尺度，使用已完成的独立半步长路径重放，核查结论是否只是时间离散造成。

所有数值、图和实验读数留在本地outputs，代码和方法文档可发布。0°和旧队列不动，不将该诊断接入生产默认。

## 实际结果

已完成304个状态的完整回放与哈希核验，32项相关测试通过，耗时414.797 s。四个尺度均未通过事先筛选，因此未启动新FE路径。最强候选在.5 mm同时降低30/60虚功代理16.69/14.24%，角度比只改善1.3835→1.3440。选定s₀=1的半步复核仍不通过；60°.25 mm代理变化相差3.13个百分点，不能声称全范围时间收敛。
