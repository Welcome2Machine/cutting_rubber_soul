## 4. A阶段：有界定位，不无限细化

先在现有代码建立可复用诊断，覆盖真实切割状态；小内核仅用于核对，不代替实际几何。

A1 初始状态与时间方法
- 从比最后接受态更早、最好早于第一次可疑激活的合格状态开始；先核查父路径的连续资格与源码身份。
- 同一种积分方法内做至少三档 dt 对照，再在相同分辨率比较方法；不要同时改方法/起点/参数后作单因素解释。
- 同初态分别保持候选连接和执行有明确标识的条件释放。所有位移、速度、材料内变量、损伤、摩擦接触历史一致继承。
- 回溯窗口只检验初态敏感性，不能将其后缀拼回不合格的旧路径。生产资格最终要求从自身一致初态形成完整历史链。
- 对照按绝对物理时间及相同刀位协议比较。若固定刀位，记录停刀边界转换及其功；不能混同继续压入。
- 不要求动态初态静力平衡，但必须满足其动力学/约束与历史定义；不能静力重平衡消掉真实速度，再称保留了初始状态。

A2 牵引、面积与拓扑交接
- 保存解除连接前的约束牵引/节点合力，激活后的内聚牵引及残差差值；检查界面法向、参考面积、半域/全域倍率、受力自由度和反力符号。
- 不预设所有瞬时力跳都错误：物理失稳可产生加速度。但必须能解释跳变来源，不能通过将强度改成当前反力来强行连续。
- 核查逐节点 tributary area 与真实界面积分、边暴露条件、接触权重、完整/部分失效状态是否一致。重点检查一个端点释放就暴露整条边的影响。
- 保存参考/当前面 ID、连通图、新生面积、表面连通裂长和刀具进入证据。角点接触不能当作刀具进入通道。
- 几何零间隙、无初始附加柔度、初始约束刚性和裂后非穿透需要分别验证；不能靠重新引入有限缝隙或软弹簧改善收敛。

A3 刚度与能量来源
- 核查真实质量单位、半域质量和最小节点质量；报告保守切线中体材料、内聚、屏障贡献及局部模态参与。
- 摩擦全 Jacobian 可非对称；不能用一个保守特征周期代表整个接触系统的全部稳定性。
- 只做小而有区分力的接触激活距离、屏障系数、摩擦速度平滑尺度对照，固定物性和几何，并记录其模型/数值含义。
- 改接触或正则设置的条件短窗只是条件响应；要证明完整过程不敏感，各组须从自身一致初态重算。
- 逐接触对分解刀具、自接触、镜像裂面约束的力、冲量、功；找出自接触大耗散发生在哪些区域。不能因占比大就删除接触对。
- 同时报告原始瞬时/算法平均Fz、累计冲量、各耗散和质量加权速度范数；保留最大节点速度及位置。禁止平滑、时移或滤波后冒充原始收敛。

A阶段决策门
先预登记比较量、误差尺度、三档 dt、共同窗口及停止条件。容差应足以分辨待判断的断裂能量余量与力学差异；不能事后放宽至通过。
最多完成一轮核心三档时间矩阵和一轮针对主导机制的复核；没有新增证据不继续盲目减半。

## 5. B阶段：明确界面模型并接入真实切割

优先保留并完善零间隙精确连接、外插型内聚分离、裂面单边接触及真实二维惯性。
推导并实现同一界面面元上的牵引与功积分，使连接状态、部分损伤、完全断开、接触表面暴露和参考面积有一致定义。
节点算法若继续保留，必须证明其与界面支撑/面积的对应关系，不能只因更易运行而作为最终断裂离散。

参考 Collins-Craft 等2022及混合模式作者代码，明确采用了哪些方程/卸载假设，哪些是本项目扩展。
先检查局部纯拉开、卸载再加载、闭合/再接触、混合模式与客观性、零开口激活、面积/细分一致性，以及守恒/耗散/回滚。
如果当前仍只实现0°镜像mode-I，明确一般裂面摩擦和混合模式为未实现；本轮无需为得到一个局部通过而宣称完成这些能力。

积分路线选择：
- 保留现有端点BE作耗散参考、保守离散力加端点摩擦作研究候选；完整接触/摩擦耦合已实现，不要重复包装为新成果。
- 如果明确证据表明屏障/摩擦正则化控制了不可接受的时间尺度，评估非光滑单边接触/摩擦冲量方法作为独立参考，例如Moreau–Jean相关路线。
- 这种替代需要接触与冲击律、有限变形/Maxwell耦合和能量推导；不能只换速度更新公式。新方法仍必须满足本工程的非穿透、正J和轨迹安全要求。
- 不通过质量缩放、人工阻尼、放松残差或删除接触实现“稳定”。任何数值耗散单独记账。
- 不立即全面迁移相场；仅在显式界面路线有具体、可核查瓶颈时提出有证据的替代比较。

## 6. C阶段：两条实际几何分支，逐门推进至2 mm

C1 有预裂口的实际切割控制
在远端真实试样、刀具、边界和速度下，构造几何明确、与表面连通的预裂口；长度是显式诊断输入，不由实验力选择。
预裂面从初态就是自由/接触表面，不重复支付其既有表面能；后续新扩展通过选定内聚律耗能。各支路有自身完整历史。
检查刀具实际进入、撑开裂口以及后续裂纹推进；不能以移到试样深处的刀具初态绕过加载历史。
目标为2 mm规定行程；先做短程实际几何先导与审查，通过后在剩余预算内推进。
这仅验证裂后计算能力，不能当作完整材料的起裂预测。不得调预裂长度、Gc或阻力让Fz接近实验。

C2 无预裂完整材料
在C1所需局部门通过后，从完整材料初态构建真正的连接→起裂→裂后路径。
保留强度—能量有限裂增量作为候选判据，与连续内聚区路线作明确区分；写清两者何时为替代理论、何时组合，避免叠加重复阈值/耗能。
起裂候选必须由当前状态及已定义判据决定，不预指定候选48、实验深度或强制连通裂口。
允许内部成核和表面扩展竞争，但必须使用一致候选面积/应力与驱动力定义，不能为了让刀具进入而强制改裂纹位置。
目标为2 mm含真实裂后段。未起裂的2 mm只授予完整体完成；未到2 mm或未进入裂口不授予完整切割资格。
一般斜切/自由裂路不应提前铺开。先完成当前控制，再列出推广所需的几何/接触能力。

## 7. 能量、时间和网格验证

统一写出所用物理模型的能量账本，至少包括：
W_ext = Δ(U_bulk + U_coh + U_contact + K) + D_bulk + D_coh + D_fric + R_num。
数值屏障储能、真实弹性储能、内聚可恢复能、体黏弹耗散、裂面耗散、摩擦功、动能及辅助功分列；明确每项单位和参考/当前面积定义。
采用内聚律支付的完全断裂耗能须与该律定义的GcA一致，不能再额外扣GcA。预存损伤与新增候选分开；若有混合摩擦/断裂能定义，明确是否已包含某项耗散，避免双计。
虚拟冻结历史与真实动态释放不是同一过程；Newton/PTC迭代路径不是物理路径。任何辅助加载的功不能隐去。
同时报告逐步误差、净累计误差、累计绝对误差、独立求积误差、时间离散误差；不能用正负抵消或小残差替代物理精度。

完整事件窗口应包含事件前、释放及事件后的可解释阶段；既有短窗口不能直接沿用为“完整”。
预登记结束判据，如动能/接触状态相对于加载背景稳定的持续区间，并核查窗口延长敏感性；持续振动时如实报告，没有自然衰减不得加阻尼制造结束。
时间比较至少三档，保持模型及起点一致；既报告共同绝对时间的瞬时量，也报告功和冲量。原始Fz不收敛时不得仅以积分量通过升级全部时间资格。
如需与仪器信号比较，必须有独立采样/带宽依据；没有就保留该项未知，不选择滤波器拟合曲线。

空间验证在时间可信的实际几何上进行：至少三档局部网格，保持物理界面参数不变，检查内聚区分辨率、起裂/扩展位置、Fz、能量及裂面接触身份。
刀具离散、接触数值距离和界面面元尺寸分别控制，不同时改变后宣称单因素收敛。
零参考间隙仍须验证损伤关闭时的附加柔度与完整体一致性；接触激活距离不等于参考缝隙。
固定裂路验证只证明该裂路控制；自由选路须另做候选方向/网格旋转或不同网格族，不能用一条直缝的加密代替。
预算不足时交付已完成层级与未完成矩阵，不补造完整验证。

## 8. 独立实验和科学问题

不得读取用户切割力数据进行参数识别，亦不得利用57°多次到2 mm未裂的观察反演强度/Gc。可在模型和参数冻结后作参考验证。
57°是工况级右删失约束，试次数和精确起裂点未知；不要写成2 mm起裂。
独立材料试验缺失时，强度/Gc的物理支持保持未知，数值通过不能升级为实验预测。

在既有独立试验计划中补齐最小可执行方案：
同批无缺口拉伸与松弛（明确速率、应变范围、重复、温度），独立强度试验和预缺口纯剪切/撕裂（区分速率相关总撕裂能与模型Gc、体耗散），刀具—橡胶不同法向载荷/速度的滑动试验（区分库仑与可能黏附）。
列出待测量、识别顺序、不确定性、哪些数据保留作验证；没有数据不填参数。
同步提出用视频检验裂口位置、表面连通、材料运动的观测定义，保留比例尺/同步/遮挡资格。
文章问题可围绕“斜向压入如何改变滑移、局部材料历史和裂纹驱动力”，这是待证伪假设，不预称首次发现。
