## 3. 单位、反力、零点、时间与摩擦核查

- 三个实验导出均声明 `Depth (μm)`、`Fz (N)`、`speed_um_s=200`。只将深度除1000，减力首值；
  0°/33°减0 N，57°减0.51 N。不改变源文件、不移动实验深度、不缩放力。
- 仿真使用实验室竖直刀具反力 `reaction_fz_n`，不是斜表面法向力，也不是合力Fyz。
  原式为刀具节点负势梯度竖直分量之和；20 mm宽度已进入积分，不再次乘宽度。
  仿真深度零点的力为0.054777/0.056559/0.045747 N，保留不扣除。
  这些小首值不足以解释早段约3–4 N偏差；真实机械首触与实验深度起点的对应仍缺独立核实。
- 初始净空按 `start=-2*dhat/cos(angle)`：0°/33°/57°为−0.005、−0.005961816、−0.009180392 mm。
  到深度0的首步已经历0.025、0.029809082、0.045901961 s材料历史；报告time_s=0是行程时间原点，
  不是材料从未加载。之后逐态检查time_s=d/0.2、Δt=实际增量/0.2均成立。
- 真正的摩擦是 `ipc_reference.py` 中 `FrictionPotential(BASELINE['friction_smoothing_mm'])`，
  即固定εu=1e-5 mm。名义Δt=.05 s时对应εv=.0002 mm/s；首步/回退步不自动等价。
  新桥接若选择固定速度平滑，双方必须用εu=εvΔt，标为新的共同设置。
  `signature.config` 中遗留的速度正则`.002`及最大行程`3`不是本路径的生效设置；实际目标为2 mm。
- `reaction_friction_fz_n=total−normal`，本次只作为**派生差值**保留。
  尚未独立重装配摩擦梯度，不把两分量相加等于总力叫作独立验证。
  刀尖材料接触地址也不是实际界面相对滑移，不能拿MMT名称互换。
