# 当前完整橡胶模型规格

更新2026-10-20。当前主线为原生P1/improved-max IPC与有限等容Maxwell，不启用断裂。
实验有效性与运行状态见[研究状态](research_status.md)。此处不把历史候选写作当前设置。

| 角度 | 0°、33°、57°；各角度同一材料 |
| 刀99755 | 厚0.245 mm、总楔角23°、对称双刃，几何来自用户截图 |

| 载荷 | 实验室竖直深度d、速度0.2 mm/s |

法向投影q=d cosθ、切向投影=d sinθ，因此法向/切向速度为0.2 cosθ/0.2 sinθ。
这些是刚体运动分量，不是真实界面滑程。历史固定法向速度0.1 mm/s算例是机理控制，不能当本实验路径。
单位mm、N、s、MPa=N/mm²。

## 材料

平衡能为

`W∞ = G∞/2 (Ī1 − 3) + K/2 (J − 1)²`，

其中`Ī1=J^(−2/3) tr(FᵀF)`，二维F嵌入三维平面应变。
非平衡支路采用乘法分解、等容有限Maxwell，对数主应变局部后向Euler更新。逆黏性度量为SPD且det=1；每个积分点保存自己的准确历史。原型P1每个三角形一个常应变材料点。

| 设置 | G∞ | Gv | τ | K |
|---|---:|---:|---:|---:|
| 共同参考候选 | .14 | 1.24 | 1.7 | 23.34333333333331 |
| soft诊断 | .098 | .868 | 1.7 | 同上 |
| fast诊断 | .14 | 1.24 | .85 | 同上 |
| partition诊断 | .414 | .966 | 1.7 | 同上 |

G和K为MPa，τ为s。这些参数是探索假设，不是测量值；57°参与参考参数的选择。
默认弹性G=.47 MPa仍用于既有基线，不能与共同Maxwell候选混称。

材料时间增量为真实`Δd/v`。PTC迭代时间不是材料时间；上一接受历史在Newton迭代中固定，物理步接受后才提交新度量及耗散。只松弛剪切、不松弛体积。二次J体积能在J→0不发散，必须报告局部压缩，不能仅展示平均J。

2023复现保留独立`paper2023`流动律及其参数/验收，不用该复现替当前`isochoric_maxwell`作材料验证。

## 接触、离散和求解

- 原生P1三角形；局部尺寸.05 mm、顶面.005 mm、细区半宽3 mm。
- IPC improved-max，激活距离dhat=.0025 mm，原生刀具和本体自接触；完整CCD与P1行列式路径界。
- 正则库仑μ=.35，滑移正则尺度1e−5 mm。μ不是本项目已独立测得的界面参数。
- 有摩擦采用刷新真实残差的PTC；接触几何/正常力刷新导数纳入非对称切线。PSD度量只正则化方向，不改变物理残差。
- 最近队列固定Δd=.01 mm、最大500次PTC、原40次进展停滞规则，不追加预算/缩步。其它历史CLI有不同诊断控制，不能默认等同。
- 最近后端为FP64 PARDISO8线程、IPC4、BLAS1、单线程材料装配。原线性残差必须通过；更多线程不保证更快。

物理接受要求：自由力残差≤1e−4 N、J>0、无边界相交、正确刀具/底面边界、准确材料与摩擦历史、非负耗散。
接受之后保存两套历史，再做独立新鲜装配审查。接受不是网格/时间收敛或实验有效性的证明。

## 观测

Fz是实验室竖直反力。`Fz=N cosθ+T sinθ`只是坐标分解，不能当摩擦因果贡献。
参考材料位置偏移Δs₀、当前表面位移与累积界面滑移是不同量。唯一刀尖接触点缺失时输出缺失或明确的鼻部邻近区间，不能用最近点替代接触真值。[观测定义](tip_contact.md)。
