# 当前二维切割模型规范

本文件的“实验工况”和“材料和界面参数”两节，以及 `docs/image.png`，是用户指定的建模目标。以下数值方法是实现状态，不能反过来修改实验目标。

## 实验工况

`N60A` 的含义为：

- `N`：无润滑；
- `60`：工件/切割面相对水平刚性基底的倾角；
- `A`：刀具编号。

工件侧面为长度 30 mm、高度 5 mm 的矩形，镜头方向尺寸为 20 mm。工件底面粘接或固定在刚性基底上，二维计算采用平面应变。落刀点位于上表面、距边缘 7 mm。

刀具在实验室坐标系中竖直向下移动。`indentation = 0` 定义为刀具尖端首次接触橡胶上表面，最大下压位移为 3 mm。3 mm 是强制位移边界，不能被模型内部变量替换为“有效深度”。

工件局部坐标为 `(s,n)`：`s` 沿 30 mm 长度方向，`n` 垂直于工件表面。工件整体绕镜头外方向旋转 60°。刀具竖直位移在 `(s,n)` 坐标中同时产生法向压入和沿长度方向的投影滑移。

出平面 20 mm 在平面应变计算中用于将单位宽度内力、cohesive 力和刀具接触力统一换算为总反力。实验记录的 `L/sliding` 是实验观测量；仿真不读取 baseline，当前代码输出的是刀具运动的几何滑移投影，后续再由 cohesive 损伤前沿提取实际切割点滑移。

## 材料和界面参数

| 参数 | 当前值 | 来源和状态 |
|---|---:|---|
| 材料 | CB245NE 软质氯丁橡胶 | 产品目录/实验材料记录 |
| Shore A 硬度 | 45 | Maxell Kureha 产品目录 |
| 静态剪切模量 `G` | 0.66 MPa | Maxell Kureha 产品目录 |
| 拉伸强度 | 4.4 MPa | Maxell Kureha 产品目录 |
| 断裂伸长率 | 320% | Maxell Kureha 产品目录 |
| 泊松比 `ν` | 0.49 | 近不可压缩数值取值，参考近期切削模型；待压缩数据替换 |
| 体积模量 `κ` | 32.78 MPa | 由 `G` 和 `ν` 计算，不独立拟合 |
| 切割断裂能 `Gc` | 2.15 N/mm | neoprene 刀具 puncture/cutting 文献先验，不是 CB245NE 实测值 |
| cohesive 特征张开量 `δc` | 0.18 mm | 由 `Gc=eσcδc` 与拉伸强度构造的初始相容值 |
| cohesive 峰值强度 `σc` | 4.39 MPa | 由 `Gc/(eδc)` 计算 |
| 无润滑摩擦系数 `μ` | 0.35 | 当前数值初值，借鉴近期 elastomer 切削模型，非 CB245NE 界面实测值 |
| cohesive 黏性正则化 `ηreg` | 0.05 s | 近期 elastomer 切削模型的初始正则化值 |

`Gc`、`μ`、`ηreg`、黏附剪切强度和刀具微观刃口半径仍属于需要独立实验确认的参数。它们没有通过当前力曲线反演；黏附剪切强度在代码中暂设为 0，仅代表缺少数据。`Gc=2.15 N/mm` 的单位换算为 `2.15 kJ/m² = 2.15 N/mm`。

2026-09-11 用户指定下一轮 60° 算例采用刃口半径 **0.02 mm**。这是本轮明确输入，不再沿用简化基线的 0.08 mm；未附独立测量方法或图纸，来源记录为用户指定。

- `prototype/model_config.py`：共用实验参数和参考网格结构；旧预设裂面求解器已删除，历史参数字段仅为输入/检查点兼容保留，不启用 cohesive 断裂。
- `prototype/ipc_reference.py`：当前完整体有限应变、刀具 IPC 接触与摩擦主入口，保存表面材料点、网格及原生 Fx/Fz；候选之后不改变材料刚度、连接或接触方程。
- `prototype/ipc_initiation.py`：在线/离线全域首次候选诊断，主判据为校准方向松弛 AT1 在 d=0 的单边稳定性，名义强度/主伸长分列；这是条件性起始判据，不是已验证的可见裂口。
- `prototype/interface_conditions.py`：记录干态/硅油界面情景及油品、温度元数据。硅油 μ_eff=0.10 未标定，未启用油膜流动、溶胀或温度本构。
- `tools/run_ipc_queue.py --study lubrication`：冻结源码后依次运行干态 60°、硅油 60°、硅油 30°，各自从零至 3 mm，成功或失败均进入下一组。这些是本轮扩展情景，不改写上文 N60A 实验记录；三组共同名义 25°C 仅作元数据，15–35°C 影响尚无法量化，也未证明可以忽略。
- `prototype/fracture_criteria.py`：客观应力度量转换与显式标定的多轴强度接口；缺失多轴标定时不自动补造参数。
- `prototype/run_initiation.py`、`prototype/febio_reference.py` 及已有裂后组件：历史诊断/独立研究入口，不作为本轮生产主线或完整裂后预测的证据。
