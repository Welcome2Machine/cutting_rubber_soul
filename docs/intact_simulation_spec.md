# 橡胶斜向压入仿真：任务、方法与参数

更新日期：2026-09-23。本文描述仓库当前**不启用断裂和损伤演化**时的仿真任务与实现，以 `prototype.ipc_reference` 为计算入口。可旁路预测首次起裂候选，之后仍保持完整材料继续至 3 mm。三工况使用 `tools/run_ipc_queue.py --study lubrication`；具体启动及完成状态见 [求解状态](solver_status.md)，本文的配置说明不代表运行完成。

实验目标以本地 `docs/image.png` 和 [current_model_spec.md](current_model_spec.md) 的“实验工况”“材料和界面参数”为准；实现细节以本次核对的代码为准。实验输入、数值假设、默认基线和实际算例配置在下文分别说明。

## 1. 仿真任务与输出目标

研究对象为 CB245NE 软质氯丁橡胶受到刚性刀具竖直压入的响应，比较干态与硅油等效边界润滑情景。试样相对实验室水平轴倾斜，因此刀具竖直运动同时包含相对于试样表面的法向压入和切向运动。

原始主要工况为 **N60A**：N 表示无润滑，60 表示工件倾角 60°，A 表示刀具编号。本轮三组为干态 60°、硅油 60°、硅油 30°；0° 仍可配置但不在本轮队列内。工件倾角不能与刀具楔角混淆。

本说明中的橡胶始终保持连续、完整的材料连接。计算要回答：

1. 刀具下压时，试样整体及刀尖附近如何发生有限变形。
2. 原上表面材料点如何移动，表面轮廓和材料点轨迹如何随加载改变。
3. 刀具受到的水平力 Fx、竖直力 Fz 如何随下压深度变化。
4. 全域应力、主伸长及局部体积变化如何分布，危险的网格畸变发生在哪里。
5. 在保持目标几何、材料和界面输入的情况下，数值求解能否满足力平衡和几何有效性检查。
6. 在整个试样中，首次条件性起裂判据在哪里、在哪两个接受深度之间触发；该诊断不反馈力学。

最大加载深度为 **3 mm**。这是规定的刀具位移上限，不是保证每个配置都能算到的深度。完整材料模型不能描述材料实际切开后的力和运动；实验一旦发生材料分离，对应深度之后的无断裂计算只能视为“材料保持完整时”的对照。

实验力数据及光流/DIC 数据由用户保留作独立验证，当前计算不读取这些数据来调出目标曲线。仿真材料点轨迹也不是从实验视频反演得到的轨迹。

## 2. 单位、坐标与几何

### 2.1 单位体系

| 量 | 单位 |
|---|---|
| 长度、位移、接触间距 | mm |
| 力、刀具总反力 | N |
| 应力、材料模量 | MPa，即 N/mm² |
| 总能量、增量功 | N·mm |
| 参考体积 | mm³ |
| 伸长、J、摩擦系数 | 无量纲 |

当前准静态计算不需要质量密度或惯性参数。程序耗时以秒记录，但耗时和求解器伪时间均不等于实验加载时间。

### 2.2 坐标定义

实验室二维坐标记为 `(x,z)`：x 向右，z 向上。代码中的二维数组第二列虽然在部分变量名中写作 `y`，物理含义仍为图像平面内的 z。出平面方向在本文记为 y。

工件局部坐标为 `(s,n)`：s 沿试样长度，n 沿试样厚度方向并指向原上表面外侧。按当前代码：

\[
\mathbf e_s=(\cos\theta,-\sin\theta),\qquad
\mathbf e_n=(\sin\theta,\cos\theta),
\]

\[
\mathbf X(s,n)=s\mathbf e_s+n\mathbf e_n.
\]

因此，正 s 方向在 60° 工况中指向右下方。刀具下移量为正的 δ 时：

\[
\Delta\mathbf x_{\rm tool}=(0,-\delta),\qquad
\Delta s=\delta\sin\theta,\qquad
\Delta n=-\delta\cos\theta.
\]

例如 θ=60°、δ=3 mm，对应刚体运动在局部坐标中的切向投影约 2.598 mm、法向投影 −1.5 mm。这只是刀具运动投影，**不等于橡胶相对刀面的实际滑移量**。

### 2.3 试样与刀具参数

| 参数 | 当前目标值 | 解释与来源 |
|---|---:|---|
| 试样局部长度 L | 30 mm | 实验几何 |
| 试样局部高度 H | 5 mm | 实验几何 |
| 出平面宽度 b | 20 mm | 实验几何；将平面应变计算转换为总力和总能量 |
| 当前主要倾角 θ | 60° | 工件相对水平轴的倾角 |
| 对照倾角 | 30°、0° | 可配置工况 |
| 初始落刀位置 | `(s,n)=(7,5)` mm | 原上表面上距局部 s=0 边缘 7 mm |
| 最大竖直下压 | 3 mm | 实验室坐标中的强制位移 |
| 刀片厚度 | 0.245 mm | 仓库保留几何输入，未宣称独立图纸标定 |
| 刀具全楔角 | 23° | 两侧楔面夹角；半角 11.5° |
| 刀尖圆角半径 r | **0.02 mm** | 用户指定；半径，不是直径 |
| 刀尖圆弧离散 | 64 段 | 当前目标算例所用数值配置，非物理参数 |

刀具为**刚体**，只施加竖直平移，不计算刀片弹性变形、水平自由移动或转动。几何包括圆角、两侧楔面及有限厚度的刀身；圆弧与楔面按相切关系构造。

当前 IPC 接触使用圆弧离散后的多边形，而不是解析圆弧接触。圆角半径属于几何输入，圆弧分段数属于接触几何分辨率。共享代码里虽然有解析圆角距离函数，不能据此把 IPC 主线称为解析刀尖接触。

在名义 δ=0 时，圆角中心由原落刀点加 `r e_n` 确定。倾斜表面上的圆弧切点通常不是刀具多边形的最低 z 点，后处理中的“相对最低刀尖位置”与“相对原始接触点位置”必须区分。

## 3. 运动学与边界条件

### 3.1 有限应变平面应变

全程使用有限应变、有限转动运动学，**没有从小应变阶段切换到大应变阶段的处理**。参考坐标 X 与当前坐标 x 满足：

\[
\mathbf x=\mathbf X+\mathbf u,\qquad
\mathbf F_2=\mathbf I_2+\nabla_X\mathbf u.
\]

计算材料响应时嵌入三维，以 `(x,z,y)` 排列：

\[
\mathbf F_3=
\begin{bmatrix}
F_{xx}&F_{xz}&0\\
F_{zx}&F_{zz}&0\\
0&0&1
\end{bmatrix},\qquad J=\det\mathbf F_3=\det\mathbf F_2.
\]

出平面伸长固定为 1，出平面应力一般不为零。因此应力后处理使用完整三维 Cauchy 应力，不能丢弃第三主应力或将该模型称为平面应力。

出平面 20 mm 作为积分宽度：参考三角形面积 A 对应参考体积 `V=bA`。体内力与接触力均使用相同宽度换算，输出为总 N，而不是 N/mm。

### 3.2 边界和加载

| 对象 | 条件 |
|---|---|
| 橡胶底面 n=0 | 所有底面节点 `u_x=u_z=0`，代表与刚性基底完全固定 |
| 橡胶原上表面及两端 | 没有额外外加表面载荷；与刀具发生接触时由接触力作用 |
| 刀具 | 全部刀具节点随规定深度一致竖直平移，横向位置和姿态固定 |
| 体力 | 当前未施加重力等体力 |
| 加载段 | 单调下压；本文不包含保持和回撤过程 |

物理目标中的零深度为刀具首次接触未变形原上表面。程序另设一个负深度初始位置，给刀具留出接近间隙：

\[
\delta_{\rm start}=-\frac{2\hat d}{\max(\cos\theta,0.1)}.
\]

θ=60°、接触激活距离 `dhat=0.0025 mm` 时，起始深度为 −0.01 mm；程序先求解到 0，再按正深度序列加载。

IPC 在正间距内已产生屏障作用，因此深度 0 的接受态可能已有很小的变形和反力。多边形刀尖还会引入很小的几何初接触偏移。导出同时保留原 `solver_depth_mm` 和按保存刀具多边形与未变形顶面平面确定的 `geometric_plane_depth_mm`；后者也不是由实验自动识别出的时间零点。

仓库共享配置保留速度 0.2 mm/s，但本入口是率无关材料的位移控制准静态路径，没有惯性和黏弹时间积分。不能把调整计算线程、伪时间或墙钟时限解释成改变实验加载速度。

在线诊断按 `model_time_s=depth_mm/0.2` 保存名义时间和首次候选区间，同时记录该速度尚未独立确认；它不是由视频或力数据识别的实验起裂时刻。

## 4. 橡胶材料模型

### 4.1 当前采用的本构

材料为可压缩的等体积/体积项分解 neo-Hookean 超弹性体，以近不可压缩参数计算。共享材料库可表示其他形式，但本入口实际选择单项 Ogden 的 α=2 特例，与下式一致：

\[
W(\mathbf F)=\frac G2\left(J^{-2/3}I_1-3\right)
+\frac K2(J-1)^2,
\qquad I_1=\operatorname{tr}(\mathbf F_3^T\mathbf F_3).
\]

W 是每单位参考体积的能量，单位 N/mm²。体积能类型在代码中为 `quadratic_j`。主线没有加载 Maxwell 黏弹支路，也没有塑性、永久变形、温升或 Mullins 软化参数。

第一 Piola 应力和 Cauchy 应力由同一能量得到：

\[
\mathbf P=GJ^{-2/3}\left(\mathbf F-
\frac{I_1}{3}\mathbf F^{-T}\right)
+K(J-1)J\mathbf F^{-T},
\]

\[
\boldsymbol\sigma=\frac1J\mathbf P\mathbf F^T.
\]

材料应力和一致切线采用解析实现；有限应变内力以参考构形积分。这里的 J 是局部体积比：J=1 表示体积不变，0<J<1 表示压缩，J≤0 为无效或翻转状态。

### 4.2 材料与界面输入

| 参数 | 数值 | 状态及作用 |
|---|---:|---|
| 材料名称 | CB245NE 软质氯丁橡胶 | 用户指定实验材料 |
| Shore A 硬度 | 45 | 目录信息；不是此有限元模型的直接输入变量 |
| 初始剪切模量 G | 0.66 MPa | 当前规范采用的目录输入 |
| 泊松比 ν | 0.49 | 近不可压缩数值假设，待独立压缩数据确认 |
| 体积模量 K | 32.78 MPa | 由 G、ν 推导，不另行拟合 |
| 小应变等效杨氏模量 E | 1.9668 MPa | `E=2G(1+ν)`，只供参数解释，不表示使用线弹性 |
| Ogden 指数 α | 2 | 当前 neo-Hookean 特例 |
| 刀具—橡胶摩擦系数 μ | 0.35 | 无润滑界面初值，非 CB245NE/当前刀具的独立实测标定 |
| 硅油情景 μ_eff | 0.10 | 未标定的等效低摩擦对照值，不由油黏度直接换算 |
| 名义环境温度 | 25°C | 三组共同元数据；当前没有温度本构或 μ(T) |
| 黏附 | 未启用 | 接触面不另设黏附拉力或独立黏附剪切强度 |

其中：

\[
K=\frac{2G(1+\nu)}{3(1-2\nu)}=32.78\ \mathrm{MPa}.
\]

有限 K 允许体积变化，不是严格的 J=1 约束。ν=0.49 也不能保证强压入时每个单元的 J 都接近 1。当前有限变形体积能与实际高压体积响应的符合程度尚未经过实验验证。

力学求解不使用损伤变量、强度或断裂能来改变承载。启用 `--initiation` 时，旁路诊断使用目录名义强度 4.4 MPa、断裂伸长率 320%、Gc=2.15 N/mm 和默认诊断长度 0.04 mm；Gc 和多轴外推仍是未独立标定的先验。共享字段的存在不表示其他断裂阶段物理已启用。

## 5. 刀具接触与摩擦

### 5.1 法向接触

接触几何和导数由官方 **IPC Toolkit（ipctk 1.6.0）** 提供，体有限元装配和非线性求解由仓库本地 Python 宿主实现；当前并非直接使用 PolyFEM 整体求解器。

法向采用距离屏障势。刀具与橡胶表面接近至激活范围后产生排斥作用，距离趋近零时屏障阻止穿透。当前启用表面面积权重，屏障参数按出平面宽度换算。

| 接触设置 | 当前目标配置 | 含义 |
|---|---:|---|
| 激活距离 `dhat` | 0.0025 mm | 正间隙内开始产生屏障力的距离尺度，不是允许穿透深度 |
| 屏障强度参数 | 6.6 MPa | 数值接触参数，不是橡胶模量或真实界面压缩刚度 |
| 传入屏障的宽度缩放 | 强度参数 × 20 mm | 与体积分的总力尺度保持一致；实际离散权重由 toolkit 处理 |
| 接触表面 | 橡胶外边界与刚体刀具多边形 | 接触约束随当前几何刷新 |
| 活动接触过滤 | 橡胶—刀具 | 当前未建立橡胶自接触反力模型 |
| 穿透控制 | 连续碰撞检测 CCD | 限制迭代更新步，避免一步跨过碰撞 |

本入口不使用旧增广拉格朗日接触变量或共享配置中的旧表面罚参数。有限屏障距离和刀尖多边形分段可能影响初始接触力及局部曲线，需要与网格共同检查。

### 5.2 切向摩擦

当前为**经过小滑移平滑的库仑摩擦**。在理想库仑解释下，切向阻力由法向接触力和 μ 控制，滑动时反向阻碍相对切向运动；程序通过 toolkit 的切向势及其导数计算。

平滑长度为 **1×10⁻⁵ mm**，作用于相对上一个已接受加载态的位移增量。它是数值长度尺度，不是实验滑移速度，不是材料黏性系数；有限平滑也意味着不能把该实现描述为完全精确的静摩擦互补条件。

法向力、切向基底、最近点位置都随变形更新。一个加载增量内，各次非线性迭代共用同一个上步接受态，不把每次试探位移都当作新的摩擦历史。

程序记录的 `friction_work_n_mm` 是接受态摩擦势梯度与本步相对位移的内积。它用于检查摩擦增量功符号，不直接等于沿未知真实路径积分的摩擦热；含摩擦的 `energy_n_mm` 也包含求解势，不应直接称为可恢复弹性能。

### 5.3 硅油与温度的本轮处理

`--interface dry` 默认 μ=0.35，`--interface silicone_oil` 默认 μ_eff=0.10，可显式指定系数并记录其来源。单一系数均匀作用于刀具与原橡胶边界的活动接触；本入口没有橡胶自接触或新生裂面。油牌号、黏度及涂油等待时间可作为元数据保存，未知则留空。涂油情景保持法向 IPC、刀尖几何和体材料不变，没有计算油膜流动、动压/挤压膜、黏性油膜剪切或溶胀；`dhat` 不代表油膜厚度。

物理上，界面剪切减少可能改变表面滑移、堆积与拉伸集中，但 Fz 不按 μ 成比例变化，起裂也未必延后。[界面和温度文献笔记](../references/lubrication_temperature.md) 给出原始资料及跨材料限制。CB245NE 是 CR 而非硅橡胶；另一 CR 配方的温度拉伸数据不能直接作为本配方的 G(T)，硅油黏度比也不能当作 μ(T)。15–35°C 对本试样的影响仍无法量化，不能因本轮未建模就称其可忽略。三组先以相同名义 25°C 比较；修改 `--temperature-c` 只改变记录，不生成热力学预测。

## 6. 有限元离散与网格

### 6.1 当前主线离散

标准配置 `volumetric_discretization=element` 使用二维三节点线性三角形 P1 位移单元。每节点有两个平面位移自由度，单元内变形梯度及材料应力为常值。均匀材料下，P1 单元常值体能/内力以参考面积乘宽度积分。

参考节点与三角形连接关系固定，节点随材料运动。当前入口没有运行中的自动重划网格、单元删除或拓扑更新。所谓“网格细化”指生成初始网格时增加局部分辨率，不等于计算过程中发生自适应重网格。

网格在工件局部坐标中生成，用分级尺寸场控制局部密度，再作 Delaunay 三角剖分。刀尖附近和原上表面使用更密网格，并向远场逐渐过渡。参数给出的是尺寸场目标，实际边长和三角形质量取决于网格生成过程，并非每条边都精确等于输入尺寸。

### 6.2 当前工况与旧默认的区分

| 设置 | 已有完整 60° 含摩擦无断裂历史 | 后续更细局部网格设置 | 固定旧基线 |
|---|---:|---:|---:|
| 刀尖半径 | 0.02 mm | 0.02 mm | 0.08 mm |
| μ | 0.35 | 0.35 | 0 |
| 远场网格尺度 | 1.0 mm | 1.0 mm | 1.0 mm |
| 局部网格参数 | 0.05 mm | 0.02 mm | 0.2 mm |
| 原表面网格参数 | 0.005 mm | 0.005 mm | 0.1 mm |
| 表面细化区半宽 | 3 mm | 3 mm | 1 mm |
| 刀尖圆弧分段 | 64 | 64 | 32 |
| `dhat` | 0.0025 mm | 0.0025 mm | 0.01 mm |
| 正深度加载步长 | 0.01 mm | 0.01 mm | 0.025 mm |

第一列是本次应用后处理实际使用的完整无断裂历史配置；第二列只是后续开发使用过的更细局部设置，不能据第一列的完成记录声称第二列也已完成同样的无断裂全程。

本轮三工况沿用第一列的刀尖、网格、屏障和增量参数，只按工况改变倾角及上述界面系数。采用已有完成记录的配置不保证新源码或 30° 路径必然全程收敛。

第一列保存的橡胶网格为 **24,955 个节点、48,466 个三角形**，不包括刚体刀具节点。301 个接受态对应深度 0 至 3 mm、步长 0.01 mm。实际网格数以相应算例报告和状态文件为准。

`prototype/ipc_baseline.json` 的 `ipc-frictionless-v1` 保存第三列。CLI 不带参数时也不会自动切换到第一列目标；一般入口还默认短程深度 0.5 mm 和 180 s 时间预算。运行目标工况应显式写出相关参数，不能只看“baseline”名称判断物理条件。

### 6.3 可选混合位移—压力对照

代码另有 `--volumetric-discretization macro_mixed`。它使用细网格 P1 位移与粗父网格 P1 压力的 P1-iso-P2/P1 构造，并采用行和集总压力质量、压力消元及非局部压力切线；不是简单把每个局部单元的压力改成平滑显示值。

其离散体积能可以写为：

\[
E_{\rm vol}^{h}=\frac K2\sum_a V_a(\bar J_a-1)^2,
\qquad \bar J_a=(S\mathbf J)_a,
\]

其中 a 为压力空间自由度，S 是由参考积分权重构造的投影。等体积材料项保持原形式，混合压力引起的非局部切线必须同时进入力学求解。该选项不改变 G、K 或均匀变形下的材料响应，但改变了非均匀体积约束的空间离散。

这是近不可压缩体离散的**可选对照**，不是已有完整 60° 历史所使用的配置。目前已有粗网格 0→0.02 mm 短程通过记录，不能据此认定强压入稳定性已解决。不能把 `element` 检查点直接当成 `macro_mixed` 的已平衡历史续算；后处理必须使用与该离散一致的保存应力。

## 7. 加载与非线性求解方法

### 7.1 平衡方程

每个规定刀具深度求解橡胶自由节点的准静态平衡：

\[
\mathbf R(\mathbf x;\delta,\mathbf x_{k-1})
=\mathbf g_{\rm bulk}+\mathbf g_{\rm normal}
+\mathbf g_{\rm friction}=\mathbf0.
\]

这里各 g 为程序统一符号下的内力/接触势梯度，`x_(k-1)` 是上一加载步的接受态。底面和刀具的规定自由度不进入自由节点残差范数。

### 7.2 含摩擦：耦合伪瞬态延续

μ>0 时使用耦合伪瞬态延续。每次重新计算当前接触和摩擦，再求搜索方向：

\[
(\mathbf A+s\mathbf M)\Delta\mathbf u=-\mathbf R,
\qquad \mathbf A=\frac{\partial\mathbf R}{\partial\mathbf u}.
\]

其中 A 包括法向力、切向基底和接触几何变化引起的导数，通常非对称；不把这一真实 Jacobian 强行投影为正定矩阵。M 由投影 Hessian 等构造，s 只调整迭代稳定化强度。

该伪瞬态不引入真实质量或黏性。最终验收检查原始 R，而不是用 `sM` 的辅助量抵消未平衡力。辅助迭代允许残差暂时上升，但试探更新必须符合局部力模型误差控制、CCD 和正 J 条件。

| 数值参数 | 当前值 | 作用 |
|---|---:|---|
| 全局自由力残差容限 | 1×10⁻⁴ N | 自由自由度残差的 L2 范数，不是每节点单独容限 |
| 每加载步最大含摩擦更新次数 | 500 | 目标算例显式参数；不是收敛保证 |
| 初始稳定化系数 s | 0.1 | 仅用于迭代方向 |
| 局部模型误差比例 | 0.25 | 控制实际力变化与线性化预测偏差 |
| 伪时间增长控制 | 1.2 | 用于更新稳定化系数 |
| 每次模型重试上限 | 18 | 超限报失败，不接受未平衡态 |
| 搜索位移分量幅度限制 | 刀尖半径的 0.5 倍 | r=0.02 mm 时对应 0.01 mm；CCD/J 可能进一步缩短 |
| 度量矩阵对角正则项 | 1×10⁻⁹ N/mm | 数值搜索稳定化，不是弹簧材料参数 |
| 行列式限步安全系数 | 0.9 | 与 CCD 一起限制更新步 |

独立无断裂 CLI 默认仍为 `--predictor affine --friction-linear-solver direct`。本轮队列显式改用 `--predictor secant --friction-linear-solver retry-gmres`：割线只构造初值，经路径几何与新鲜力残差筛选，不满足条件则退回仿射初值；GMRES 只尝试复用同一非线性状态重试中的 LU，失效回退直解。接受残差、接触几何和摩擦历史不改变。

固定网格的稀疏散射结构现在缓存复用，已收敛试态不再为下一轮重复装配切线，独立接受检查仍执行。真实细网格两个增量 2.08→2.10 mm 的局部对照，原策略 32.907 s、仅新增缓存/切线消重 30.130 s、再加上述初值/线性选项 3.125 s；主要收益来自割线。不能将这一局部结果外推为全程速度或稳定性保证，证据见 [建模路线](modeling_roadmap.md)。

### 7.3 无摩擦对照

μ=0 时求解体弹性能与法向屏障势，使用能量 Newton 方法、Armijo 线搜索及几何限步。可选择 `projected`、`hybrid`、`regularized` Hessian 模式；Armijo 系数为 1×10⁻⁴，线搜索最多 30 次。

`--hessian-mode regularized` 主要控制无摩擦求解路径。含摩擦时仍采用上一节的耦合伪瞬态方法，不能仅根据报告中出现 regularized 就将其解释为相同的能量最小化算法。

### 7.4 实际增量流程与接受条件

1. 从上一接受态开始，对刀具施加下一个规定深度，构造加载初值。
2. 保持底面固定，在当前构形更新单元变形、内力和刀具接触。
3. 按相应求解器计算方向，用 CCD 和正 J 条件限制步长。
4. 含摩擦时刷新摩擦力并继续迭代；物理摩擦历史保持为上一接受态。
5. 用最新接触和摩擦复查自由力残差、间距、几何相交、J 和摩擦增量功。
6. 通过后保存接受态；可选在线诊断读取该接受态，再进入下一深度。机械失败记录错误与试探态；诊断异常单独记录，不改变已接受的机械解。

接受条件包括：残差有限且不超过 1×10⁻⁴ N；最小接触距离为正；所有单元 J>0；几何相交检查通过；摩擦增量功不得小于 −1×10⁻¹² N·mm。

正 J 只排除了局部翻转，不能证明单元形状良好或体积响应可信。当前无断裂入口按显式固定深度序列推进，机械失败后停止该组；它没有自动加载二分。三工况监管队列随后进入下一组，不跳过失败增量继续同一组。

## 8. 输出定义与验证方式

### 8.1 刀具反力

Fx/Fz 定义为**橡胶对刀具的力**，实验室 +x 向右、+z 向上。由刀具节点上的总势梯度计算：

\[
\mathbf F_{\rm rubber\to knife}=-\sum_{i\in\rm knife}\mathbf g_i.
\]

刀具向下压入时，Fz 通常为正，即橡胶对刀具的向上阻力；保持刀具运动所需执行器力符号相反。与实验曲线比较前必须统一测力传感器的作用对象和正方向。

新代码直接保存 `reaction_fx_n` 与 `reaction_fz_n`。部分旧历史只有 Fz：导出时原生 Fx 保持缺失，可以另外从底面参考内力恢复 Fx。恢复仅适用于相同材料实现、相同边界、底面无刀接触的工况，并要求同式恢复的 Fz 与原生 Fz 在残差求和误差界内一致；恢复值不会冒充原始保存值。

### 8.2 表面材料点与场量

原顶面点通过参考局部坐标 n=H 识别，按 s 排列，材料节点 ID 在整个历史中固定。记录参考位置 X、当前位置 x、位移 `u=x-X`，以及加载深度；不能每帧重新找一个轮廓点就当作同一材料点。

完整体节点场仍保留在原接受态。默认应用导出只复制表面轨迹和力，避免重复保存整套体网格数据。

| 输出 | 定义或用途 |
|---|---|
| `reaction_fx_n` / `reaction_fz_n` | 刀具受橡胶的总力，N |
| `residual_n` | 自由力残差 L2 范数，N |
| `min_j` / 单元 J | 体积变化与局部翻转诊断 |
| `minimum_distance_mm` | 记录的最小接触间距 |
| Cauchy 应力 | 3×3 应力张量，含出平面分量 |
| 最大主拉应力 | `max(三维 Cauchy 最大特征值,0)`，MPa |
| 主伸长 | 三维 F 的奇异值；平面应变包含出平面伸长 1 |
| 表面轨迹/轮廓 | 原顶面固定材料点的真实位移，无放大 |
| 迭代与失败日志 | 深度、残差、限步、稳定化、异常和最后接受深度 |

单元应力图按 P1 单元常值显示，默认不做空间平滑。固定色标和真实位移有助于比较过程；动画帧率只是播放设置，不等于实验速度。二维平面应变运动与相机观测自由侧表面的 DIC 还需进行坐标、尺度和边界假设核对。

### 8.3 首次起裂候选的旁路诊断

`--initiation` 仅支持从零开始的 element 无损伤路径，不能把旧损伤或混合压力历史直接套入局部本构。主判据为校正后的方向松弛 AT1 在 d=0 的单边第一变分，默认 16 个方向；按同一本构的自由三维单轴路径校准最大方向释放能阈值，并在全试样的节点支撑域做参考体积加权诊断。搜索不限定于刀尖下方，固定边界也参与。名义强度和最大主伸长作为独立诊断分列。

首次主事件锁定并保存其前后接受深度、模型时间区间、参考/当前坐标和场量文件；之后只退休昂贵的方向搜索，不把后续热点改写成首次起裂。应力/伸长统计继续。判据尚有目录强度多轴迁移、方向离散和网格依赖限制，只能给条件性候选，不能证明可见裂纹已经出现。

候选不会改变位移解、刚度、连接、摩擦或加载终点；后段全部为完整体假想延续。默认力曲线用虚线区分候选后的部分。`initiation/result.json` 与主 `result.json` 分别保留诊断和机械状态；诊断失败不冒充成功，机械完成也不等于起裂预测已验证。

### 8.4 已有数值证据与限制

本地已有 60°、μ=0.35、0.02 mm 刀尖、局部参数 0.05 mm 的完整无断裂 0→3 mm 接受历史。本记录只证明该离散算例通过当时程序的数值验收，不能证明实验中材料仍完整，也不能证明全部深度的力和应力准确。

既有强压入状态存在极端局部体积压缩和网格畸变。网格锁死/离散误差、有限体积模量下的材料响应、屏障距离与表面分辨率的共同影响仍需区分。细网格、混合压力、其他倾角与不同源码版本的结果不能相互替代验收。

目前至少还需要核对：

- 实际橡胶大应变应力—伸长和体积响应与所用 neo-Hookean 模型的差异。
- μ=0.35 及摩擦平滑长度、`dhat` 对力和表面运动的敏感性。
- 刀尖分段、网格尺度/排列、加载步长对局部场与总反力的收敛性。
- 20 mm 宽试样的三维端部效应，以及相机自由侧面与平面应变近似之间的差异。
- 实验与计算的接触零点、坐标注册及力符号。

## 9. 运行配置与结果保存

本轮完整队列入口如下；冻结源码后串行尝试干态 60°、硅油 60°、硅油 30°，每组成功或失败均继续下一组。统一启用旁路起裂诊断和上述提速选项，不保证三组都能完成。

```powershell
python tools/run_ipc_queue.py --output outputs/ipc_lubrication_new --study lubrication --oil-friction 0.10 --temperature-c 25 --threads 2 --seconds 0 --detach
```

队列根目录保存实际命令、冻结源码、PID、stdout/stderr、`queue.json` 和日志；每组子目录保存下面列出的力学/诊断输出。`finished` 只表示队列尝试结束，应逐组查看机械完成、起裂诊断和后处理状态。

以下为独立干态命令，明确选择已有完整历史所对应的**物理/网格参数组合**，并启用本轮在线诊断；使用当前源码从零计算，不保证逐位重现历史源码的数值路径。

```powershell
python -m prototype.ipc_reference `
  --case oblique `
  --output outputs/intact60_r002_mu035_new `
  --inclination 60 --depth 3 --increment 0.01 `
  --interface dry --friction 0.35 --temperature-c 25 --tip-radius 0.02 `
  --local-spacing 0.05 --surface-spacing 0.005 `
  --fine-halfwidth 3 --nose-facets 64 `
  --dhat 0.0025 --volumetric-discretization element `
  --hessian-mode regularized --max-iterations 500 `
  --initiation --initiation-length 0.04 --initiation-directions 16 `
  --predictor secant --friction-linear-solver retry-gmres `
  --threads 2 --seconds 0 --detach
```

输出目录必须使用未占用的新路径。`--seconds 0` 只取消墙钟时间上限，不取消收敛、碰撞或几何验收。`--threads 2` 是本地资源设置，可按机器调整，不是物理参数。需要更细局部网格时显式改 `--local-spacing 0.02`，同时保留其为另一数值配置的标识。

完整算例应后台运行，启动后检查一次即可，不需持续盯守。当前入口保存：

- 目录同级的 `.launch.json`、`.stdout.log`、`.stderr.log`：启动命令、PID 与进程输出。
- 目录内的 `result.json`、`baseline_config.json`、`source/`：实际配置、源码指纹与副本、接受历史和运行状态。
- `run.log`：力学迭代及接受/失败信息。
- `states/0000.npz` 等：参考坐标、当前位置、前一物理状态、三角形、深度等；混合配置另存一致应力/压力。
- `failed_trial.npz`：失败试探态，不得混入接受历史。
- `initiation/result.json` 与首次候选 NPZ：启用诊断时的独立状态、候选区间、参数来源及首次场量。
- 结束后按入口设置生成的可视化及对应日志；失败时仅绘制已核验接受前段，并标记未完成。主候选后的无断裂力曲线改用虚线；MP4 导出需要 ffmpeg。

当前独立无断裂 `--detach` 从工作区启动进程，由运行入口保存源码副本；它不是在启动前建立完全隔离代码环境的运行器。为保持可追溯性，运行期间不要修改它正在使用的相关源文件。恢复已有路径需使用 `--resume` 并通过几何、物理参数、离散、源码和历史平衡检查。

本轮 `run_ipc_queue --detach` 则从冻结副本执行三组，和上述独立入口的启动方式区分。在线首次候选要求从零连续记录，因此 `--initiation` 不与 `--resume` 混用。

已有历史可用以下命令导出，不调用力学求解器：

```powershell
python tools/export_cutting_history.py `
  --source outputs/intact60_r002_mu035_new `
  --output outputs/intact60_observables --recover-fx

python tools/visualize_ipc.py --observables `
  --source outputs/intact60_observables `
  --output outputs/intact60_figures
```

停止/失败历史需明确加 `--allow-incomplete-prefix`，仅处理已接受部分；运行中的历史不可直接作为完整导出。新数据已有原生 Fx 时不必要求恢复。`forces.csv`、`top_surface.csv`、`surface_history.npz` 和 `manifest.json` 给出数值与来源；全部体节点默认通过原状态文件访问。

当前 `requirements.txt` 固定 NumPy 2.2.6、SciPy 1.15.3、threadpoolctl 3.6.0、Matplotlib 3.10.6、ipctk 1.6.0。这里记录仓库依赖版本，不表示这些软件的最新版本；toolkit 版本和实际二进制指纹也应由算例报告核对。
