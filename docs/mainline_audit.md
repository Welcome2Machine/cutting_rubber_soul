# 主线理论与实现核查

更新2026-10-20。结果和结论边界见[研究状态](research_status.md)，当前参数见[规格](current_model_spec.md)。
本页说明方程对应的代码与已有检查，区分实现一致性、数值可用性和实验有效性。

## 已经排查过什么

1. 原生材料保存场检查没有发现可解释跨角度偏差的应力切线、坐标旋转、黏性历史提交或时间定义错误。13个实际状态材料局部差分和客观性证据见[材料核查](../references/native_material_audit_20261018.md)。该结论不是材料参数真实或场精度已收敛。
2. 当前基线0/33/57各2 mm完整，1.5 mm范围另有准确历史与锚点复核。深处存在很低局部J；不能将数值平衡当三维约束或可压缩性验证。
3. 较早解析刀具Gauss积分在深处漏近接触区；恢复原生IPC解决了那一离散问题的工作路径，但早期力偏差仍在，不能用深积分失败解释全部实验差异。
4. AL/P2弱接触约束可能满足残差而未满足整边几何。该候选已停止晋级；不是继续加Newton次数可自动解决的问题。
5. 最新共同参数方向能大幅调整0/33力幅值，但斜率关系尚不符合实验。57°选参偏向已确认，不能再拿它作为独立材料验证基准。
6. soft/fast的57°失败场有准确历史、正J和无相交，却在刀尖附近十个节点保留约99%的残差平方和。具体分支/导数/全局化原因未唯一识别，不能宣称物理无解或摩擦规律必然错误。

## 本轮结构整理

`PardisoDirection`从AL/P2候选模块移到`prototype/pardiso.py`；原位置兼容导出。当前原生主线不再为导入线性后端加载AL/P2模型。

材料算例构造、签名、准确历史恢复和审查从CLI移到`prototype/material_case.py`。CLI兼容导出旧函数；当前共同材料队列直接调用共享模块。七个移出函数/类的AST主体逐项一致，未修改物理方程、时间步或验收。实际回归结论记录在[整理记录](cleanup_log.md)。

`ipc_reference.py`仍包含求解与旧CLI，`initiation.py`仍有旧模块和当前网格共用依赖。没有在未验证的条件下大范围拆开几何或改接触算法。旧替代方法保留技术用途，但不列为当前推荐入口。

源文件布局变化后，不放宽源哈希保护来接旧冻结路径。历史有效算例保存的源码不改；新计算使用新冻结快照。

## 下一步证据链

准确失败增量与成功邻近场 → 接触对/几何分支与方向差分 → 有界修复 → 原增量验收及观测量检查 → 独立短路径 → 三角度实验幅值和斜率 → 深度扩展。

条件末态重平衡、单一端点吻合和某个角度算通都不能替代这条验证链。旧负结果已汇入[研究状态](research_status.md)、[历史技术索引](history/README.md)及本地退役摘要。
