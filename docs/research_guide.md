# 橡胶斜压研究导读

更新：2026-10-25。本文说明完整体计算能回答的问题、已有证据和可检验研究路线；运行状态以[研究状态](research_status.md)为准，具体方程与验收以[模型规格](current_model_spec.md)为准。文献阅读范围统一记录在[references/README.md](../references/README.md)，本导读不将摘要或已有阅读记录升级为全文复核。

## 1. 研究对象与适用范围

研究变量为刀具截面形状、锋利度、界面摩擦条件和试样倾角；同一轮因素比较保持橡胶材料、试样尺寸、夹持与竖直速度一致。速度固定为 **0.2 mm/s**，最大竖直行程为 **2 mm**。当前模型计算完整橡胶的有限变形压入，不预测起裂时刻、裂纹路径或裂后切削力。

“材料相同”表示各工况使用完全相同的材料配置，并从各自初态建立历史；不表示允许沿用另一角度或另一刀具的内部变量。改变材料时形成新的共同候选，不能按角度分别选材料、有效宽度或力倍率。

| 配置类别 | 物理意义 | 当前能力与边界 |
|---|---|---|
| 刀具配置 | 厚度、总楔角、几何类型及尺寸来源 | 支持刚性对称双刃圆鼻楔；配置切换不等于支持任意 CAD、单刃或齿形 |
| 锋利度 | 圆鼻半径 | 半径是曲率参数；与直线倒角长度不同。圆鼻面片数属于离散参数 |
| 界面条件 | 正则库仑系数 μ，干燥/油润滑等条件标签 | 油润滑仅以给定 μ 近似；标签自身不添加油膜方程 |
| 倾角 θ | 初始材料表面对实验室水平的倾斜 | 刀具仍竖直运动；不是沿刀刃宽度方向拉切 |
| 材料配置 | G∞、Gv、τ、K 与材料模型标识 | 当前为单支路有限应变等容 Maxwell；参数仍是研究候选 |
| 数值配置 | 体/表面网格、刀具离散、物理增量及资源预算 | 改变数值配置需要对照；不能作为材料或刀具真实性的调节器 |

99755 的厚度 **0.245 mm**、对称双刃及总楔角 **23°**来自实验刀具截图；当前圆鼻半径 **0.02 mm**是建模假设，尚无该刀片实测依据。刀具磨损、沿刃半径不均匀、刃口毛刺与涂层微观作用均未直接建模。

## 2. 理论与计算流程

1. 读取材料、刀具和任务配置，生成倾斜试样及刚性圆鼻刀具。试样参考截面为 30 × 5 mm，面外参考宽度为 20 mm；底面两个面内方向固定。
2. 在 P1 三角形上计算 `F = I + Grad(u)`，嵌入三维平面应变 `F33=1`，由 `J=det(F)` 评价体积变化。
3. 平衡等容支路与非平衡 Maxwell 支路并联；体积能为 `K/2 · (J−1)²`，不松弛。当前两支路的等容弹性采用 neo-Hookean 形式。
4. 非平衡支路采用乘法分解和局部后向 Euler 积分。每个材料点保存逆黏性度量；其对称正定性、等容性与耗散需通过验收。
5. improved-max IPC 对完整刀具/材料 EV、VV 特征及本体自接触建立法向屏障与正则库仑摩擦；CCD 和正 J 限制试探方向。
6. PTC 使用当前物理残差与耦合切线迭代求平衡；伪时间和稳定化只影响求解路径，不增加材料真实时间。
7. 物理步通过后才提交材料和摩擦双历史，保存接受态；独立重组检查通过后才给出合格路径范围。

参考共同材料为 `G∞=0.14 MPa、Gv=1.24 MPa、τ=1.7 s、K=23.34333333333331 MPa`，`G0=G∞+Gv`，`q=G∞/G0`。该配置是可计算基线，不是样品的独立标定结论。

固定 K 而改变 G0/q 会同时改变剪切与体积约束的相对强度。基线小应变泊松响应由瞬时约 0.471 变为长期约 0.497，不能将配置中的单一泊松比解释为整个黏弹过程的常数。大变形分支松弛也不能由总力乘 `exp(−t/τ)` 替代。

当前名义增量 `Δd=0.01 mm` 对应 `Δt=0.05 s`。固定摩擦位移平滑尺度 `εu=1e−5 mm` 时，等效速度尺度为 `εu/Δt`；缩小物理步会同时改变材料积分和摩擦平滑区，必须报告实际接受步长。非线性线搜索的 α 不是物理时间步。

## 3. 力、角度和滑动的正确解释

对外结果采用 `Fy` 表示截面内横向刀具反力，对应历史代码的 `reaction_x_n`；`Fz` 为向上的竖直刀具反力，正行程 d 表示刀具向下运动。`Fyz = sqrt(Fy²+Fz²)` 是合力大小，失去横向正负号；它不是额外力分量。

令初始表面切向 `es=(cosθ,−sinθ)`、外法向 `en=(sinθ,cosθ)`。对同一个刀具反力向量 `(Fy,Fz)` 定义：

```text
N =  Fy sinθ + Fz cosθ
T = −Fy cosθ + Fz sinθ
Fz = N cosθ + T sinθ
```

其中 T 沿 `−es` 为正。这是相对初始表面的坐标投影；与当前变形界面上逐接触特征的 IPC 法向/摩擦力分解不同，不能对整体投影直接设 `T=μN`。

同等竖直行程的名义法向、切向运动大小分别为 `d cosθ`、`d sinθ`。倾角增加会降低名义法向压入和速度，但实际 Fz 还受切向传力、接触位置、材料历史、几何约束及两项投影共同影响。因此，角度增大不构成每个浅层采样点 Fz 必须严格减小的定理。

可同时采用两种比较，分别回答不同问题：

- 同一竖直行程 d：对应当前实验和装置输入，加载时间相同。
- 同一名义法向行程 `dn=d cosθ`：比较压入几何尺度；不同角度的实际 d 和材料加载时间不同，不能视为消除了黏弹差异。

刀具横向速度为零时，横向反力仍可通过摩擦约束改变变形，但外部刀具功不能用 `Fyz·Δd` 计算。竖直输入功依据 `∫Fz dd`；摩擦耗散与材料黏性耗散需分别从对应局部增量累计。

必须分开记录三类量：刀尖接触材料在初始表面的参考偏移、材料当前位移、材料与刀具之间累计相对滑动。接触参考偏移进入平台不等于滑移停止；缺失或多义接触不能以最近材料节点强行补齐。正则库仑中的近黏着也不等于化学黏附，本模型没有黏附牵引定律。

数值来源及实际参数签名见[研究状态](research_status.md)和[研究历史](research_history.md)。同一表内材料候选保持 K、μ、速度及主要几何一致；刀具和网格离散差异仍以各结果配置为准，不跨来源拼接历史。

已知接触限制包括有限屏障间隙下的共同转动表观摩擦功、受压连续边界上的相邻 VV 排斥。直接删除相邻 VV 曾产生有限力跳变，未成为有效修复。它们应作为误差机制检验，不能由改变材料参数掩盖。

### 待检验机制与研究问题

- **接触材料迁移—局部加载历史—松弛耦合：** 刀具接触不同材料后，各材料点的分支弹性状态可能不同。需将接触身份、局部支路能量和局部变形历史共同追踪；仅凭 Fz 或接触偏移平台不能确认因果。
- **几何与摩擦的交互：** 半径/楔角改变接触长度、局部法向和约束，μ 的作用可能随刀形和角度改变。应比较因素交互，不能预设“涂油一定按固定比例降力”。
- **相同 Fz、不同内部响应：** 力接近的候选可能具有不同应力分布、局部压缩、耗散和接触身份。需以保存场约束解释，避免把拟合当成机制确认。
- **有限宽与体积约束：** 平面应变固定 F33=1；20 mm 仅作为积分宽度。全宽贴合不证明沿宽均匀，简单改全域平面应力也不代表有限宽试样。
- **材料可辨识性：** 单速度下 G0/q/τ 可以相互补偿；已有局部敏感性中 q 与 τ 高度相关。当前固定速度研究可以比较工况，不能据此声称唯一识别完整松弛谱。

这些是可检验问题，尚未形成经独立验证的首次发现。新增理论的必要条件是已有模型在合格离散与共同参数下持续出现明确的响应偏差，并有新增观测区分替代解释。

## 5. 刀具与油润滑研究的限制

钝化对完整体反力、局部峰值应力和真实起裂深度是三个不同问题。圆鼻变钝可扩大接触区域并降低应力集中，同时改变排开的材料体积；当前模型只可计算前两类场量及完整体反力，不给出“更容易切断”的结论。最大拉应力或伸长比热图不是断裂预测结果。

油润滑在本阶段表示相同库仑模型下的有效 μ 对照，不包含油膜压力、流体流动、黏度/速度依赖、润滑剂渗入或橡胶溶胀。干燥/油润滑 μ 必须附选择依据；未实测时标为假设范围。同样 μ 和其他物理配置下，仅更改标签应产生相同力学结果。

当前 Maxwell 摩擦宿主要求 μ>0。真正 μ=0 需要同材料历史下的无摩擦路径接通和验收，不能静默改为小正数。单独弹性无摩擦入口不能充当 Maxwell 的无摩擦对照。润滑使求解更难或更易均是数值观察，不能据此推断真实油润滑不稳定。

## 6. 可复用研究流程

1. **定义基准任务。** 选择共同材料配置、刀具配置、μ、角度、行程、物理步、网格和预算。保存配置来源、版本及指纹；显示物理配置与数值配置的区别。
2. **建立短窗口资格。** 新刀形、半径或网格从独立初态运行；检查准备态、接触初始几何、正 J、残差、CCD、边界和材料/摩擦历史。接受前缀与最终完成分别标识。
3. **做针对性离散对照。** 独立改变表面网格、体网格、圆鼻面片或直刃分段，再比较同一物理点的 Fz/Fy、分段斜率、接触参考位置及局部场。物理增量对照另列；不要同时改变所有离散后归因。
4. **以成对因素比较进入研究。** 先固定材料和刀形比较 μ×角度；再在代表角度/μ 下比较圆鼻半径与楔角。只有主效应和数值误差可区分后，再补几何×摩擦×角度的交互组合。
5. **扩展合格行程。** 将有希望的配置推进到事先规定且不超过 2 mm 的行程；各工况从自身接受态续算，失败不自动追加预算或改参数。
6. **共同评价和解释。** 报告各角度误差、最差角度、区间斜率及有符号角度差；同时检查场和能量证据。不用三个独立调参结果代替同材料规律。

细网格不能自动解决困难。P1 近不可压约束、表面边长与刀具积分权重、网格形状和接触切换共同影响方程条件；细化后失败不证明粗解正确，也不证明无物理解。高阶或混合方法只有完成几何有效性和物理加载检查后才可作为精度对照。

## 7. 输出与科学分析约定

| 输出 | 优先分析 | 不允许的解释 |
|---|---|---|
| Fz/Fy/Fyz—d | 同行程/同法向行程叠图、可隐藏曲线、区间割线、角度差 | 用合力冒充 Fz；仅凭斜率下降认定起裂 |
| 位移与变形网格 | 真实比例动画、固定参考区域位移及变形模式 | 以夸大位移图直接解释实际接触几何 |
| 应力、应变与 J | 明确 Cauchy/Green 等量和参考系；原始单元场、面积加权分位及极值位置 | 平滑后的节点颜色当原始 FE 精度；平均 J 掩盖局部强压缩 |
| 接触身份与支撑区间 | 原始表面材料坐标、接触区扩展、缺失区间 | 身份迁移当累计滑移；无接触信息当零 |
| 储能、耗散、外功 | 平衡/非平衡储能、黏性与摩擦增量、累计及账目残差 | 摩擦竖直力占比当耗散占比；屏障能当橡胶储能 |
| 求解与审查 | 接受态残差、min J、实际步长、迭代/拒绝次数、阶段耗时及完整审查 | 退出码 0、终点文件或单次下降当物理路径合格 |

P1 单元应变在单元内为常量，云图默认显示原始单元值；任何插值或显示裁剪均单独标记。跨工况云图使用相同单位、色标和显示范围；动画的视频时间与物理时间分开记录。分析只使用接受且合格的状态，未完成区间不外推。

材料应力必须由各状态自己的准确材料历史恢复；不能用纯弹性应力代算 Maxwell 场。最大主拉应力须说明是否取三维嵌入张量，以及是否将负值裁为零；裁零值仅是显示量，不是完整主应力。

实验曲线保留原始试次和单位，当前比较目标减去各自首个 Fz 值；57°原值偏置为 0.51 N，原 CSV 不改写。首触零点、参考材料坐标零点和数值屏障激活分开。实验起裂后数据不能直接标定完整体；未确认的区间保持未知，不能将全部 2 mm 都宣称为前裂验证。

## 8. 计算质量与下一阶段决策

物理验收保留自由力残差 **≤1e−4 N**、正 J、完整 CCD/无穿透、固定边界、非负耗散和准确双历史。先割线再同增量仿射恢复，各尝试最多 500 次；仿射没有 40 次停滞早退。控制器和预算写入结果，不以更宽门槛换完成标签。

非线性失败需保存实际失败位置、该次尝试的上一接受位置、上一材料度量、真实 Δt、目标行程及残差/限制原因。检查线性求解误差、预测与实际残差、有效位移和 CCD/J 限制后再决定修改方向；失败既不证明材料模型不可能，也不能证明物理分支变化。

效率优化以阶段计时为依据。已有案例材料评估占主要成本，PARDISO 或更多线程并不自动解决无效非线性迭代。材料分批的历史重现已出现过严格审查差异；性能策略变更须保留数值等价检查。每项任务有明确行程、墙钟预算和失败停止条件，后台日志与 HTML 持续记录，不复活旧队列。

阶段结论分为：**计算完成且合格、完成但拟合不足、仅有合格前缀、审查未通过**。只有前两类可用于完整窗口的因素比较。共同参数仍不能解释结果时，按持续偏差选择体积响应/跨变形模式、有限宽约束或接触状态依赖的隔离对照；不预设增加本构复杂度，也不以单条曲线拟合成功结束机制研究。
