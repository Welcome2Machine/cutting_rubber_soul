唯一参数来源为 [ipc_baseline.json](../prototype/ipc_baseline.json)，入口为 `python -m prototype.ipc_reference --baseline --output outputs/new_baseline --detach`。固定模式拒绝改变加载、摩擦和求解预算；诊断变体省略 `--baseline`，报告不带基线 ID。实验目标与简化差异见 [模型规范](current_model_spec.md) 和 [路线](modeling_roadmap.md)。

本地完整结果位于 `outputs/ipc_baseline_3mm_extended`：**completed，119.64 s，121 个接受状态及检查点齐全**。末态 Fz=**77.5604 N**、残差 **9.07392e-5 N**、Jmin=**0.385483**、最小间隙 **0.000640845 mm**。独立重新装配确认末态力平衡和无相交，整体合力误差约 5e-14 N。全部记录的力残差和正 J 检查通过。

上述耗时仅是本地记录，不是跨机器或与旧离散同条件的性能基准。它使用官方接触内核与本地静态宿主，**不是完整 PolyFEM**。粗网格的锁死/接触误差、较大的局部体积变化、屏障预载和未标定刀尖半径仍需检查；不能用这条全程无损伤反力曲线宣称实验验证通过。
