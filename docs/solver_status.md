## 已确认问题与结果

Python P2 所查失败试值的体/接触切线与线性后向误差很小；全 Newton 步改变开闭状态，使投影缺陷急增，回溯需缩至约 1/1024。这证明该状态受接触分支切换阻碍，不能归结为所有失效都由本构或线性求解错误造成。局部网格细化曾帮助推进，后续接续最后接受至 0.49875 mm，未完成 0.5 mm。

独立 FEBio 4.13 确认三处切线问题：摩擦容量对法向压力的导数遗漏、切向试算量遗漏罚参数、正法向牵引但负间隙时跳过摩擦切线。补丁不改变力方程。固定平面刚性接触面上实际力函数差分误差从约 0.33035 降至 9.40e-10；不外推为任意可变形曲面的证明。

## 剩余验收

1. 目标 Linux 节点实编译并通过解析压缩/滑移 patch，核对线程与内存。
2. 连续越过 0.3–0.5 mm 区间，再检查加载上限；补充逐步几何/力审计及两套网格的反力、局部应力比较。
3. 独立参考通过后迁移主求解器和全域候选输出；随后实现强度与断裂能独立控制的自由萌生及裂面接触。

当前 FEBio 只审计末态几何及必要力平衡，无候选停止、自由断裂或已验证的断点接续。力残差 0.001 N、投影 0.001 MPa、穿透 1e-4 mm 门限保持，另需正 J、库仑锥和耗散。正常结束、短前缀和测试通过均不构成实验验收。
