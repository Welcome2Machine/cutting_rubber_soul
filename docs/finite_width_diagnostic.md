# 有限宽面外相容性条件诊断

2026-10-21。平面应力对照降低0/33°幅值，却同时使57°偏低加重。
本轮检查这种释放在20 mm有限宽、连续位移场下能保留多少；不将平面应力直接晋级。

## 方程与适用范围

在原平面应变受载场的准确上一接受材料/摩擦历史上，采用
`x=(x1(X,Y), x2(X,Y), Z+w(X,Y,Z))`。面内位移跨宽一致；w关于宽度中心反对称，
在面内三角形和半宽分层上分别采用连续P1插值。真实三维F包含`w,X`、`w,Y`、`1+w,Z`。
所以空间变化的厚度伸长伴随剪切，不再逐材料点独立释放。

新增三维材料核共享原主能量、等容Maxwell后向Euler流动、K、G∞、Gv、τ和准确历史。
先检验完整切线/增量势导数、旋转协变、历史SPD/det=1、耗散、二维PE一致性及PS凝聚一致性。
不修改主线二维材料实现或生产求解器。

条件增量方程是原面内接触切线与新增面外块的耦合：

`[Auu B; Bᵀ Kww] [du; dw] = [0; -rw]`。

其中rw是将三维体强制保持面外零位移所需的虚拟约束反力；释放比例ε=0处的方向才是输出。
`dFz/dε`不能直接加到原Fz后称为新平衡，更不是完整重新加载的实验预测。
没有面外摩擦、宽度方向变化的面内位移或完整三维自接触，故该诊断也不是完整三维自由端解。

## 有界检查矩阵

- 0/33/57°各取原生已接受.16/.5 mm，共六场，先准确历史新鲜审查。
- 半宽10 mm分别用1/4/8层，靠自由端加密；保留20 mm物理宽度与共同材料。
- 主诊断将原底面固定延伸为面外固定；.5 mm另做底面面外自由控制，说明该未知边界的影响。
  两种底面条件均对三个角度相同，不按角度选择。
- 4层主方向在ε=1e−4和3e−5重新积分三维材料并刷新原面内接触；真实残差线性余项及
  Fz方向误差均须小于2%，两档均通过才称方向合格。检查面内CCD/J及三维正J/历史。
- 4→8层导数变化大于5%则标记未空间稳定；最多这三档，不自动追加层数、预算或切割长线。
- 每场900 s诊断预算，在阶段间检查；原子线性调用不在调用中强行中断。逐场失败继续，保存方向和失败信息。

本轮零新增加载态；禁止将条件线性方向、释放后的未平衡场或材料点响应当作实验曲线。
即使小角度降力较大，也需确认大角度和模型缺失项，不能据此宣称sim2real问题已解决。
所有输出独立保存在`outputs/finite_width_probe_20261021`，冻结源码、原输入和方案；HTML为结果入口。

## 文献依据及阅读范围

1. [Bleyer，FEniCSx广义平面应变数值教程](https://bleyerj.github.io/comet-fenicsx/tours/linear_problems/generalized_plane_strain/generalized_plane_strain.html)。
   已核对位移假设、整体面外应变自由度及合力约束正文。教程是小应变线弹性；说明相容位移和整体约束的区别，
   不提供当前有限宽切割的修正系数。本轮使用连续面外位移，比该教程的常数面外应变更一般，但仍限制面内跨宽变化。
2. [Ahmadi等，2024，Plane stress finite element modelling of arbitrary compressible hyperelastic materials](https://arxiv.org/abs/2410.22562)。
   仅核对摘要关于积分点面外应变消去和局部Newton的说明。局部σ33=0本身不保证当前三维几何/边界适用；
   该论文不验证本项目Maxwell或摩擦历史。未将其作为完整三维切割方法复现。

## 执行结果及新增实验信息

六场诊断于2026-10-21 21:59:01 JST全部结束；21个条件方向、12次实际小扰动检查。
六个4层主方向均合格；最大残差余项相对误差.4761%、力方向误差.1973%；4→8层变化.4007–.5410%。
64份冻结源码、715个原输入哈希复核通过，六场准确历史新鲜验收通过。18项相关回归无跳过。
没有新增加载态或新切割队列。[HTML结果与图](../outputs/finite_width_probe_20261021/review/index.html)。

在.5 mm，底面面外固定的4层`dFz/dε`分别为−.6500/−.6720/−.4741 N；
按各自原Fz归一化为−5.660/−5.772/−5.223 %/单位ε。它们是释放比例零附近的导数，不是释放后的实际降力。
这组受限相容模式没有明显的小角度专属释放；不能用平面应力的大幅降力直接替代有限宽响应。
面内跨宽翘曲及面外摩擦尚缺，故也不能据此排除所有三维效应或给出完整三维反力界。

用户随后确认：底面粘接或夹紧、基本不能滑动；下压约1–3 mm时，沿刀刃宽度方向单侧外鼓不到约1 mm。
后续模型以底面不滑动为装夹前提，底面自由控制不作候选。
对20 mm参考宽度，若两侧近似对称且中心不动，该观测对应半宽平均伸长小于约10%；
它不是每个积分点λ33≤1.1，也不是.5 mm观测。角度、测量位置、刚体位移与误差尚未量化。
保留为侧表面运动的独立验证条件，不作为拟合出的材料参数、强制位移截断或已通过的当前模型验证。

下一步有限宽候选需共同包含跨宽面内翘曲、面外摩擦和同一底面固定条件；
同时检验力、面内滑移与侧面外鼓，不能只按力值挑选约束。当前候选不晋级，不启动新的三角度长加载。
