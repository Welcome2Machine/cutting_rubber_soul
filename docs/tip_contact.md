# 刀尖接触材料坐标

本轮在 main 的完整体、无断裂模型上增加观测量：给定下压深度 `d`，找出刀尖对应的原始上表面材料点，记录该点沿初始表面相对初始落刀位置的距离。用户随后用独立实验断裂深度查询该量。本轮不求起裂判据，不加入 CZM，也不计算裂后演化。

2026-10-11新增整刃支撑区间观测，用于区分“最低点对应材料几乎不变”和“整个接触区都不变”。材料输入按用户授权更新为G=0.47 MPa，刀具采用99755的0.245 mm厚度/23°双面全刃角，0.02 mm圆鼻半径仍为用户指定值；该几何观测不依赖选择哪一种本构候选。

## 坐标与取点

试样参考表面沿局部 `s` 方向，初始落刀材料坐标 `s₀ = drop_s = 7 mm`。刀尖取参考几何中最低的圆弧顶点，并固定其身份随刚体刀具运动；不是每步重新选材料表面最低点。试样倾角为 `θ` 时，参考表面正方向为实验室坐标中的 `(cos θ, −sin θ)`。

对一条原始上表面边，参考端点为 `Xᵢ, Xⱼ`，当前端点为 `xᵢ, xⱼ`。把当前刀尖 `x_tip` 投影到当前线段：

```text
α = clamp(((x_tip − xᵢ) · (xⱼ − xᵢ)) / |xⱼ − xᵢ|², 0, 1)
x_contact = (1 − α) xᵢ + α xⱼ
X_contact = (1 − α) Xᵢ + α Xⱼ
Δs₀ = s(X_contact) − drop_s
```

在全部**原始上表面边**中选最近材料位置。它是材料坐标回溯；即使表面已经旋转、拉伸或弯折，也不把当前水平距离或变形后弧长当作 `Δs₀`。正值表示沿初始表面 `s` 增大方向的材料，负值表示反方向；另输出 `|Δs₀|`。

IPC 以正间隙屏障近似接触。只有最近间隙 `< dhat` 才把该点列为本观测的接触候选；超出时 `no_tip_contact`，偏移为缺失值。不同材料坐标等距时为 `ambiguous`，保留候选而不任意挑一个。两条相邻边共享同一材料端点不算两个不同材料点。每行同时给数值间隙，不能把 `< dhat` 理解成实验上的严格零间隙接触。

`unique` 只表示最近投影唯一，不能证明整个 `< dhat` 范围内没有距离稍大的其他接触支路；发生卷曲时还需结合圆鼻区间和网格查看。

最低刀尖可能尚未接触，而圆弧侧面已接触斜面。因此另求原始上表面与**整个刀尖圆弧**距离 `< dhat` 的参考材料区间 `nose_reference_intervals_mm`，并给相对 `s₀` 的 `nose_offset_intervals_mm`。这些区间可以不连续；不跨越空隙合并，也不把刀具直侧面接触算作圆弧接触。区间端点表示严格激活集合的边界闭包，边界本身的屏障贡献可以为零。

该点不是压力加权接触中心，区间也不是接触压力分布。当前网格与刀尖圆弧均是分段线性离散，精确到该离散几何不等于真实刀尖几何已收敛。材料点定义及代码与求解器平衡计算分离；观测器不改材料、摩擦系数、滑移历史、残差门限或接受态。

## 整刃支撑区间（2026-10-11）

`TipContactTracker.observe_footprint(positions, depth_mm)`在相同原始上表面上计算距整个刚体刀具边界`< dhat`的材料区间，单独保存为`steps[*].blade_contact_footprint`。原`tip_contact`字段和最低点定义不变。该观测包括圆鼻`nose`、左右楔面`left_flank/right_flank`、左右平行刀身`left_shank/right_shank`，并将远端闭合边`top_cap`列入几何完整性检查。

每条变形后材料边与刀具线段的胶囊邻域做精确参数裁剪；即使两个材料端点都在阈值之外，也能捕获边中部的局部支撑。输出：

- `reference_s_intervals_mm`和`reference_offset_intervals_mm`：参考表面材料区间及相对7 mm落刀点的偏移；间断区间不被假连成一段。
- `supported_reference_length_mm`：区间并集在参考表面的总长度。
- `supported_current_length_mm`：同一支持子段在变形后材料表面上的总长度，并非刀具弧长。
- `supporting_top_edge_count`与`parts`：涉及的原表面边数及各刀具部分的相同统计。

`status`为`no_support/connected/disconnected`。相邻刀具段在共享顶点附近的阈值邻域可以重叠，因而`parts`长度不能直接相加；整刃汇总先对每条材料边的区间取并集，再计算长度，避免重复计数。全部结果是有限`dhat`的几何邻近支撑，不是压力分布、严格零间隙接触、实际黏着区或累计滑移。它也不是offset-geometric接触核的逐模板作用集合；切换接触离散后，观测的几何定义保持一致。

旧G=0.66 MPa、60°/μ=0.35接受态审计给出具体解释边界：0.4→1 mm最低点材料偏移只从约0.219变到0.226 mm，但整刃支撑材料范围的包络从约[-0.007,0.230]变到[-0.145,0.255] mm，变形后支持总长从0.291增加到0.634 mm。包络只用于说明范围，实际区间有间断；因此不能把最低点平台称为整刃“黏死”。左楔支撑约0.75 mm深度才触及刃肩/刀身，不能用刃肩单独解释0–0.4 mm已经出现的上升曲率。依据是本地`outputs/current_revision_20261011/contact_audit/audit.json`和`footprint_check.json`，没有新平衡求解或实验验证。

同次审计还发现局部相邻上表面节点压缩至小于`dhat`后产生自接触屏障：0.4 mm时相邻参考间距0.005 mm的两个节点当前距离约0.002275 mm。纯接触核矩形检查在无边界相交、均匀压缩状态也能复现这种近邻排斥。它是需隔离检验的离散附加刚度来源，不能从其存在直接推断已解释所有Fz差异，更不能通过把全部自接触关闭来掩盖问题。复现位于同一本地目录的`self_contact_check.py/json`。

## 下压零点

保留主线 `depth_mm` 定义：理想圆刀尖相对初始未变形平面的名义首触为零。求解器从分离位置进入深度零；有限 `dhat` 可在严格几何相触前产生接触力。圆弧多边形与理想圆的首触亦有小差异，元数据单独记录。不要把初始求解位置、屏障开始作用位置和实验视频中的首触帧混为一个零点。

本输出不自动修正实验深度。实验与数值的下压方向和首触定义应先一致；`Δs₀` 的原点固定在名义初始落刀材料点，不随之后接触区迁移。

2026-10-07初始接触核查：60°、dhat=0.0025 mm时，分离初态为depth=−0.01 mm。原始静止材料、刀具尚在−0.006/−0.005 mm处的只读力装配均给出法向力=0、摩擦力=0，接触坐标为空；没有把算法迭代累计为滑程。整个圆鼻的离散屏障约在−0.0049923 mm开始激活，此时最低点仍可能没有接触。当前候选B首接受态depth=0已有Fz=0.024785 N、最大材料位移0.002581 mm；它不是严格无载静止态，而是有限间隙接触平衡。IPC的[激活距离与摩擦定义](https://ipctk.xyz/tutorials/getting_started.html)说明接触会在正间隙内起作用。

同时存在首接触步的时间/加载离散近似：第一步由−0.01直接走到0，摩擦对按当前接触几何构造，而相对位移取整个`x−previous`；没有截断至该接触对首次进入屏障区的时刻。因此新接触对的首次增量可能包含分离阶段运动，不能把它解释为严格的接触后滑程。它对后续接触坐标的影响尚未通过首次接触步长/初始间距敏感性排除；本次只核查并澄清标签，未改摩擦方程或重置已接受历史。证据在本地`outputs/ipc_fast_accuracy_20261007/diagnostics/initial_contact_audit.json`。

日志现同时显示最低点的`status`与整个圆鼻的`nose_status`，图中用“Lowest blade point”代替容易误解的“Tip contact”。既有冻结作业保留原标签和源码。首个唯一最低点接触即使给出非零Δs₀，也表示相对名义初始圆鼻落刀点的材料坐标距离，不表示接触之前已累积滑移。

## 新版本运行入口

以下仅记录完整运行入口，不表示本轮已启动或恢复任何暂停队列。在仓库根目录、已安装依赖的 Python 环境执行，输出目录需为新的空目录：

```sh
python -u -m prototype.ipc_reference --current --output outputs/NEW_CURRENT_RUN --detach
```

`--current`保留30×5 mm侧面、20 mm出平面宽度、ν=0.49和底面固定，显式选择60°/μ=0.35/0.02 mm刀尖、当前细P1网格、自适应加载和接触观测，G=0.47 MPa、默认α=2。μ=0.35尚未由独立实验标定；可选`--ogden-alpha 1`是保持G的未标定本构对照。OGC存在已证实的特征切换不连续，`--contact-formulation offset-geometric`与`--current`不兼容，仅保留独立诊断入口。`--seconds 0`取消墙钟预算，不取消原数值失败检查。`--track-tip-contact`只适用于斜切刀具模型，不能用于接触补丁模型。历史冻结`--baseline`及既有G=0.66 MPa结果保留原配置，不能与新参数直接混称同物理对照。

完整算例后台运行，持久保存配置、源码指纹、标准输出/错误、逐接受态和 `result.json` 状态。只检查一次启动，不持续轮询。启动成功不表示 3 mm 已算完，实际进展见 [求解状态](solver_status.md) 与运行目录。

## 输出与查询

| 输出 | 用途 |
|---|---|
| `result.json` 中 `steps[*].tip_contact` | 每个接受深度的观测值、原表面边/插值系数、候选及区间 |
| `result.json` 中 `steps[*].blade_contact_footprint` | 新增整刃原表面支撑区间、参考/变形后支持长度及刀具分区；历史结果可以没有此字段 |
| `contact_trace.csv` | 逐深度可读表；无接触/多义时不填伪偏移，区间以 JSON 数组保存 |
| 离线目录 `contact_trace.json` | 从已有接受态派生的观测及来源信息 |
| `tip_contact_offset.png` | 偏移随深度与接触区间图；缺失/多义处保留断点 |

单值主要字段为 `status`、`reference_offset_mm`、`absolute_reference_offset_mm`、`reference_s_mm`、`reference_point_mm`、`current_point_mm`、`gap_mm`。圆弧状态另用 `nose_status`，区分无圆弧接触、单个连通区间和多个不连通区间。必须先读状态再读数值，不能将缺失值替成零或沿上一深度续填。

观测异常记为 `error`，并将 `tip_contact_tracking.status` 标为 `partial`；不会把已接受的力学状态改成未收敛。绘图失败另记 `visualization.status`，不能只根据力学 `completed` 判断接触表或图是否完整。

已有完整算例可直接从保存的接受态生成同一定义的观测，无需为了增加这个量重算力学。离线导出目录必须独立于来源：

```sh
python -m prototype.contact_trace export --source outputs/EXISTING_COMPLETE_RUN --output outputs/NEW_CONTACT_TRACE
python -m prototype.contact_trace query --source outputs/NEW_CONTACT_TRACE --depth 1.5
python -m prototype.contact_trace query --source outputs/tip_contact_20261006/run60 --depth 1.5
```

查询默认给出精确接受深度，或上下两个接受深度的记录；不默认插值，也不向接受历史之外外推。若某个返回状态为无接触或多义，就没有可直接使用的唯一偏移。离线表继承原计算配置与接受历史，是新后处理结果，不是重新计算、独立收敛验证或实验验证。

| 对照 | 固定量 | 改变量 | 主要输出 |
|---|---|---|---|
| 摩擦敏感性 | 60° | μ=0、0.05、0.10、0.20、0.35 | Δs₀–深度，附 Fz–深度 |

## 解释边界与依据

实验断裂深度只用于查表，不会使模型在该处断裂。因此起裂后的结果代表“材料保持完整”这一假想分支，不能用于解释真实裂纹生长、切断后力或裂面恢复。理论材料点偏移是否能对应实验切点，还取决于力学模型、空间离散、屏障尺度和实验零点是否适合；本功能不预先保证这一对应。

[IPC Toolkit Getting Started](https://ipctk.xyz/tutorials/getting_started.html) 支持二维边接触及 `dhat` 近接触激活的定义。参考材料坐标插值与最低刀尖取点是本项目公开采用的观测定义，不声称来自该教程的断裂理论。依据与限制同时记录于 [建模路线](modeling_roadmap.md) 和 [参考索引](../references/README.md)。
