## 理论模型与实现

当前网络是**平衡Neo-Hookean支路与一个等容有限Maxwell支路并联，另有不松弛的体积响应**。
它不是纯串联Maxwell，也不是小变形材料。主线两个Ogden指数均为2；代码中2023复现的流动分支与主线显式区分。

```text
同一共同材料 + 每角度几何 + 竖直位移/速度
    ↓  Δt = Δd / 0.2，读取上一接受位置 x_n 与逆黏性度量 M_n
有限应变 F，主线 F33=1
    ├─ 平衡等容能：G∞/2 [J^(-2/3) tr(FᵀF) − 3]
    ├─ 非平衡等容能：Gv/2 [Je^(-2/3) tr(FeᵀFe) − 3]
    │    返回映射 e − e_trial + Δt dev(τv)/(2 Gv τ) = 0
    └─ 体积能：K/2 (J−1)²，无体积松弛
    ↓  第一Piola应力、一致切线、参考体积装配
完整原生法向屏障 + 正则库仑摩擦 + 本体自接触
    ↓  求自由节点平衡；真实残差/J/CCD/边界/耗散验收
接受后提交 M_(n+1) 与 x_(n+1)
    ↓
实验室竖直反力 Fz + 表面运动 + 原材料接触身份
```

## 判别路径

1. 先验证从静止传播准确双历史的参数方向，本轮优先补τ；未合格处停止，不外推。
2. 后续至少联合G0、q、τ三个共同方向，用各角度Fz及斜率误差检查共同改善方向和相关性。
   单个τ方向或某点Jacobian秩不足，都不能判整个参数族不可拟合。
3. 仅对合格方向提出一个有界有限参数变化，再独立从rest计算三个角度同一窗口，保留原验收。
   新57°加载仍须满足接触资格门槛；本轮不自动启动该组。
4. 如果完整路径证实共同改善，说明参数选择有实质贡献，尚不等于独立材料验证。
   若多个合格共同方向及有限对照仍存在同一跨角度残差模式，再针对该模式检查分支形状、接触或三维约束。
   如果路径因数值失效缺失，结论是本次不可判定，不能转写为物理模型无能力。

目前不扩大刀尖/网格扫描，不改材料默认，不将未完成的联合反演描述为完成。
一次完整共同参数成功能证明参数贡献；少量局部或数值失败不能证明整类模型没有能力。

## 实际历史传播检查

保存状态满足`R_n(x_n,x_(n-1),M_(n-1),p)=0`，材料更新为`M_n=U_n(x_n,M_(n-1),p)`。
对于共同参数logτ，令x'、M'为参数导数：

`R_x x'_n = -(R_p + R_previous_x x'_(n-1) + R_previous_M M'_(n-1))`。

力导数使用全矩阵的刀具行，材料导数由同一return map递推。
当前原生摩擦没有另存牵引历史；依赖当前几何/法向力/μ及上一位置。原屏障刚度保持固定，PTC稳定化不进入物理切线。
从无应力rest和identity度量的零导数开始，包含各角度原rest→0准备时间，逐步读取准确保存的双历史。
此为已有离散路径附近的局部导数，不是跨接触分支的有限参数变化或新平衡。

- 独立输出：`outputs/model_identifiability_audit_20261021/history_tau`。
- 0/33/57°各从rest至最多.5 mm；每角度900 s诊断预算，阶段间检查，不新增FE加载。
- 两套logτ扰动1e−4、3e−5分别递推；每步重新审查原状态、用新鲜非对称切线解同一参数方向。
- 使用保持SPD/det的度量retraction，记录切投影修正；不隐瞒导数偏离等容约束。
- 两符号当前/上一几何扰动、三维材料正性、反力和真实残差线性余项检查；两个尺度均须通过2%门槛，
  切投影相对修正须小于1%。两链比较反力、位置与度量导数。若原加载直弦安全，扰动后直弦也必须安全；
  原直弦不安全时该项标为不适用，不把分段原迭代判为无效。它不等同已完成非线性新加载。
- 固定旧历史的单尺度导数只作为未独立资格的对照偏导，不用于参数提案。
- 任一步未合格，保留失败方向、停止该角度传播，继续其它角度；不降门槛或自动加预算。
- 材料点历史递推另与独立改变参数后重新积分比较。未通过完整FE前缀，不用局部结果进行联合拟合。
